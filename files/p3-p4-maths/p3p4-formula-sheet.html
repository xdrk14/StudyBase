(a + bx)ⁿ — step 1

Validity (combined)

05 Partial Fractions & Differential Equations
Partial Fraction Forms
Distinct linear
\(\dfrac{f(x)}{(ax+b)(cx+d)} \equiv \dfrac{A}{ax+b} + \dfrac{B}{cx+d}\)
Repeated linear
\(\dfrac{f(x)}{(ax+b)^2} \equiv \dfrac{A}{ax+b} + \dfrac{B}{(ax+b)^2}\)
Improper fraction
If deg(num) ≥ deg(denom): divide first → get quotient + proper fraction → then decompose
Log Laws (used when integrating partial fractions)
Product → sum
\(\ln A + \ln B = \ln(AB)\)
Division → difference
\(\ln A - \ln B = \ln\!\left(\dfrac{A}{B}\right)\)
Power
\(n\ln A = \ln(A^n)\)
Differential Equations — Separation of Variables
Method
\(\dfrac{dy}{dx} = f(x)\,g(y) \;\;\Rightarrow\;\; \displaystyle\int\frac{1}{g(y)}\,dy = \int f(x)\,dx\)
Particular solution
Substitute boundary condition \((x_0,\,y_0)\) into general solution to find \(c\)
Standard Models
Growth
\(\dfrac{dN}{dt} = kN \;\;\Rightarrow\;\; N = N_0\,e^{kt}\)  \((k > 0)\)
Decay
\(\dfrac{dN}{dt} = -kN \;\;\Rightarrow\;\; N = N_0\,e^{-kt}\)  \((k > 0)\)
Newton's Cooling
\(\dfrac{d\theta}{dt} = -k(\theta - \theta_0)\)
06 Vectors
Magnitude & Unit Vector
|a| in 2D
\(\sqrt{a_1^2 + a_2^2}\)
|a| in 3D
\(\sqrt{a_1^2 + a_2^2 + a_3^2}\)
Unit vector
\(\hat{\mathbf{a}} = \dfrac{\mathbf{a}}{|\mathbf{a}|}\)
Vector AB
\(\overrightarrow{AB} = \mathbf{b} - \mathbf{a}\)
Line Equation & Intersection
Line equation
\(\mathbf{r} = \mathbf{a} + \lambda\,\mathbf{d}\)
Through A and B
\(\mathbf{r} = \mathbf{a} + \lambda(\mathbf{b} - \mathbf{a})\)
Intersection test
Equate components → solve two equations → check 3rd for consistency
Skew lines
Not parallel AND 3rd equation inconsistent (no solution)
Scalar (Dot) Product
Geometric form
\(\mathbf{a}\cdot\mathbf{b} = |\mathbf{a}||\mathbf{b}|\cos\theta\)
Component form
\(\mathbf{a}\cdot\mathbf{b} = a_1b_1 + a_2b_2 + a_3b_3\)
Find angle
\(\cos\theta = \dfrac{\mathbf{a}\cdot\mathbf{b}}{|\mathbf{a}||\mathbf{b}|}\)
Perpendicular
\(\mathbf{a}\cdot\mathbf{b} = 0\)
Parallel
\(\mathbf{a} = k\mathbf{b}\) for some scalar \(k\)
Position Vectors & Section Formula
Midpoint
\(\dfrac{\mathbf{a}+\mathbf{b}}{2}\)
Divides m : n
\(\overrightarrow{OP} = \dfrac{n\,\mathbf{a} + m\,\mathbf{b}}{m+n}\)
Non-parallel coeffs
If \(p\mathbf{a}+q\mathbf{b} = r\mathbf{a}+s\mathbf{b}\) then \(p=r\) and \(q=s\)
07 Parametric Equations & Coordinate Geometry
Circle
\(x = a + r\cos t,\;\; y = b + r\sin t \;\;\Rightarrow\;\; (x-a)^2+(y-b)^2 = r^2\)
Ellipse
\(x = a\cos t,\;\; y = b\sin t \;\;\Rightarrow\;\; \dfrac{x^2}{a^2}+\dfrac{y^2}{b^2} = 1\)
Cartesian conversion
Rearrange one equation for \(t\) → substitute into other. Use trig identities where needed.
Domain rule
Domain of Cartesian = range of \(x(t)\) over the given parameter domain
