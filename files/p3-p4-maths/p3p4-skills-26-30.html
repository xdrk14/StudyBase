Skill 26

Completing the Square

What It Is

Completing the square is a method of rewriting a quadratic expression \(ax^2 + bx + c\) into the equivalent form \(a(x+p)^2 + q\). Instead of leaving the quadratic in its expanded form, you force it into a perfect-square bracket plus a leftover constant.

The technique is important because the completed-square form immediately reveals the minimum (or maximum) value of the quadratic and the value of \(x\) at which that occurs. It also lets you solve quadratics that do not factorise neatly and is used when integrating certain expressions.

Every quadratic can be completed-square — there are no exceptions. The process is entirely algebraic: no trial and error is required.

The Rule
General Result (leading coefficient = 1)
$$x^2 + bx + c = \left(x + \frac{b}{2}\right)^2 - \left(\frac{b}{2}\right)^2 + c$$
General Result (leading coefficient \(a \neq 1\))
$$ax^2 + bx + c = a\!\left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a} + c$$
Key shortcut — half the \(x\)-coefficient, then square it

Take the coefficient of \(x\), halve it, put it inside the bracket with \(x\), square the bracket, then subtract that square outside the bracket to compensate.

When To Use It

Solving quadratics that cannot be factorised: rewrite in completed-square form, then isolate \(x\).

Finding the vertex of a parabola: the form \(a(x+p)^2+q\) gives vertex \((-p,\,q)\) directly.

Integration: expressions like \(\dfrac{1}{x^2+4x+13}\) must be completed-square before using the standard \(\arctan\) integral.

Proving results: e.g.\ showing a quadratic is always positive by writing it as a perfect square plus a positive constant.

Worked Examples

Example 1 — Leading coefficient 1

Write \(x^2 - 6x + 11\) in the form \((x+p)^2 + q\).

Step 1 — Halve the \(x\)-coefficient

The coefficient of \(x\) is \(-6\). Half of \(-6\) is \(-3\). So the squared bracket will be \((x-3)^2\).

Step 2 — Expand the bracket to find what it equals

\((x-3)^2 = x^2 - 6x + 9\)

Step 3 — Find the correction constant

We have \(x^2-6x+11\) but the bracket gives \(x^2-6x+9\). The difference is \(11-9=2\). So we write:

$$x^2 - 6x + 11 = (x-3)^2 + 2$$
Step 4 — State the result
$$\boxed{(x-3)^2 + 2}$$

Minimum value is \(2\), occurring at \(x=3\).

Example 2 — Leading coefficient \(\neq 1\)

Write \(2x^2 + 12x - 5\) in the form \(a(x+p)^2 + q\).

Step 1 — Factor out the leading coefficient from the \(x\)-terms only
$$2x^2 + 12x - 5 = 2\!\left(x^2 + 6x\right) - 5$$
Step 2 — Complete the square inside the bracket

Half of \(6\) is \(3\). So \(x^2+6x = (x+3)^2 - 9\).

$$= 2\!\left[(x+3)^2 - 9\right] - 5$$
Step 3 — Expand the factor of 2
$$= 2(x+3)^2 - 18 - 5$$
Step 4 — Collect the constants
$$\boxed{2(x+3)^2 - 23}$$

Minimum value is \(-23\), occurring at \(x = -3\).

Practice Questions
  1. Write \(x^2 + 8x + 3\) in the form \((x+p)^2 + q\). State the minimum value.
  2. Write \(x^2 - 10x + 30\) in completed-square form.
  3. Write \(3x^2 + 12x - 1\) in the form \(a(x+p)^2 + q\).
  4. Write \(2x^2 - 8x + 9\) in completed-square form. Hence state the minimum value and the value of \(x\) at which it occurs.
  5. Show that \(x^2 - 4x + 7 > 0\) for all real \(x\). (Hint: complete the square.)
  6. Write \(x^2 + 5x + 4\) in completed-square form, then solve \(x^2 + 5x + 4 = 0\) using the completed-square form.
  7. Write \(-x^2 + 6x - 2\) in the form \(a(x+p)^2 + q\). Hence state the maximum value of the expression.
Fully Worked Solutions

  1. Half of \(8\) is \(4\). So \((x+4)^2 = x^2+8x+16\).

    \(x^2+8x+3 = (x+4)^2 - 16 + 3\)

    $$\boxed{(x+4)^2 - 13}$$

    Minimum value: \(-13\) at \(x=-4\).

  2. Half of \(-10\) is \(-5\). So \((x-5)^2 = x^2-10x+25\).

    \(x^2-10x+30 = (x-5)^2 - 25 + 30\)

    $$\boxed{(x-5)^2 + 5}$$

  3. Factor out \(3\) from \(x\)-terms: \(3(x^2+4x)-1\).

    Half of \(4\) is \(2\). \(x^2+4x=(x+2)^2-4\).

    \(= 3[(x+2)^2-4]-1 = 3(x+2)^2-12-1\)

    $$\boxed{3(x+2)^2 - 13}$$

  4. Factor out \(2\) from \(x\)-terms: \(2(x^2-4x)+9\).

    Half of \(-4\) is \(-2\). \(x^2-4x=(x-2)^2-4\).

    \(= 2[(x-2)^2-4]+9 = 2(x-2)^2-8+9\)

    $$\boxed{2(x-2)^2 + 1}$$

    Minimum value: \(1\) at \(x=2\).

  5. Half of \(-4\) is \(-2\). \(x^2-4x+7=(x-2)^2-4+7=(x-2)^2+3\).

    Since \((x-2)^2 \geq 0\) for all real \(x\), we have \((x-2)^2+3 \geq 3 > 0\).

    $$\boxed{x^2-4x+7 > 0 \text{ for all real } x.}$$

  6. Half of \(5\) is \(\dfrac{5}{2}\). So \(x^2+5x = \left(x+\dfrac{5}{2}\right)^2 - \dfrac{25}{4}\).

    \(x^2+5x+4 = \left(x+\dfrac{5}{2}\right)^2 - \dfrac{25}{4}+4 = \left(x+\dfrac{5}{2}\right)^2 - \dfrac{9}{4}\)

    Setting this equal to zero: \(\left(x+\dfrac{5}{2}\right)^2 = \dfrac{9}{4}\)

    \(x+\dfrac{5}{2} = \pm\dfrac{3}{2}\)

    \(x = -\dfrac{5}{2}+\dfrac{3}{2} = -1\) or \(x = -\dfrac{5}{2}-\dfrac{3}{2} = -4\)

    $$\boxed{x = -1 \text{ or } x = -4}$$

  7. Factor out \(-1\) from all terms: \(-(x^2-6x+2)\).

    Half of \(-6\) is \(-3\). \(x^2-6x=(x-3)^2-9\).

    \(x^2-6x+2=(x-3)^2-9+2=(x-3)^2-7\).

    So \(-x^2+6x-2 = -[(x-3)^2-7]\)

    $$\boxed{-(x-3)^2 + 7}$$

    Maximum value: \(7\) at \(x=3\). (Maximum because the bracket is subtracted.)

Skill 27

Logarithm Laws

What It Is

A logarithm answers the question: "What power do I raise the base to in order to get this number?" Written \(\log_a x = n\) means \(a^n = x\). The base \(a\) must be positive and not equal to 1.

The logarithm laws are rules that let you manipulate and simplify logarithmic expressions — combining two logs into one, splitting one log into two, or moving a power out in front of a log. These rules follow directly from the corresponding index laws.

In A-level work you mainly meet \(\log_{10}\) (written \(\log\)) and \(\ln\) (the natural logarithm, base \(e\)). All the laws work identically for any base.

The Rules
Multiplication Law
$$\log_a(xy) = \log_a x + \log_a y$$
Division Law
$$\log_a\!\left(\frac{x}{y}\right) = \log_a x - \log_a y$$
Power Law
$$\log_a(x^k) = k\log_a x$$
Special Values
$$\log_a 1 = 0 \qquad \log_a a = 1 \qquad \log_a a^n = n$$
Change of Base
$$\log_a x = \frac{\log_b x}{\log_b a}$$
When To Use It

Simplifying expressions: combining several log terms into a single log, or expanding a single log into separate terms.

Solving equations: taking logs of both sides when the unknown is an exponent, or converting a log equation into an exponential one.

Linearising data: in modelling, taking logs transforms power-law and exponential relationships into straight-line graphs (covered in Skill 28).

Integration and differentiation: recognising log forms to apply standard results.

Worked Examples

Example 1 — Write as a single logarithm

Express \(3\log 2 + \log 5 - \log 4\) as a single logarithm.

Step 1 — Apply power law to the first term

\(3\log 2 = \log 2^3 = \log 8\)

Step 2 — Apply the multiplication law

\(\log 8 + \log 5 = \log(8 \times 5) = \log 40\)

Step 3 — Apply the division law

\(\log 40 - \log 4 = \log\!\left(\dfrac{40}{4}\right) = \log 10\)

Step 4 — Evaluate using special value

\(\log_{10} 10 = 1\)

$$\boxed{1}$$

Example 2 — Expand and simplify

Write \(\ln\!\left(\dfrac{e^3 x^2}{\sqrt{y}}\right)\) in terms of \(\ln x\) and \(\ln y\).

Step 1 — Apply the division law

\(= \ln(e^3 x^2) - \ln\!\left(\sqrt{y}\right)\)

Step 2 — Apply the multiplication law to the numerator term

\(= \ln e^3 + \ln x^2 - \ln y^{1/2}\)

Step 3 — Apply the power law to all terms

\(= 3\ln e + 2\ln x - \dfrac{1}{2}\ln y\)

Step 4 — Use \(\ln e = 1\)
$$\boxed{3 + 2\ln x - \tfrac{1}{2}\ln y}$$
Practice Questions
  1. Write \(\log 6 + \log 3 - \log 2\) as a single logarithm and evaluate it.
  2. Write \(2\ln 3 - \ln 6 + \ln 2\) as a single logarithm.
  3. Write \(\log_2 48 - \log_2 3\) as a single value (no logarithm in the answer).
  4. Express \(\log\!\left(\dfrac{x^3}{100\sqrt{x}}\right)\) in the form \(a\log x + b\).
  5. Given \(\log_a 2 = p\) and \(\log_a 3 = q\), express \(\log_a 18\) in terms of \(p\) and \(q\).
  6. Show that \(2\log_3 6 - \log_3 4 = 1 + 2\log_3 3^{1/2} + \log_3 9 - \log_3 4\) simplifies to \(1 + \log_3 9 - \log_3 4 + \log_3 3\). Hence evaluate exactly. (Simplify \(2\log_3 6 - \log_3 4\).)
  7. Write \(\ln\!\left(\dfrac{\sqrt{x+1}}{e^2(x-1)}\right)\) in terms of \(\ln(x+1)\) and \(\ln(x-1)\).
Fully Worked Solutions

  1. \(\log 6 + \log 3 - \log 2 = \log\!\left(\dfrac{6\times 3}{2}\right) = \log 9\)

    $$\boxed{\log 9}$$

  2. Power law: \(2\ln 3 = \ln 9\).

    \(\ln 9 - \ln 6 + \ln 2 = \ln\!\left(\dfrac{9 \times 2}{6}\right) = \ln 3\)

    $$\boxed{\ln 3}$$

  3. \(\log_2 48 - \log_2 3 = \log_2\!\left(\dfrac{48}{3}\right) = \log_2 16 = \log_2 2^4\)

    $$\boxed{4}$$

  4. \(\log\!\left(\dfrac{x^3}{100\sqrt{x}}\right) = \log x^3 - \log 100 - \log x^{1/2}\)

    \(= 3\log x - 2 - \dfrac{1}{2}\log x\)

    $$\boxed{\frac{5}{2}\log x - 2}$$

  5. \(\log_a 18 = \log_a(2 \times 3^2) = \log_a 2 + \log_a 3^2 = \log_a 2 + 2\log_a 3\)

    $$\boxed{p + 2q}$$

  6. \(2\log_3 6 - \log_3 4 = \log_3 6^2 - \log_3 4 = \log_3 36 - \log_3 4 = \log_3\!\left(\dfrac{36}{4}\right) = \log_3 9\)

    \(\log_3 9 = \log_3 3^2 = 2\)

    $$\boxed{2}$$

  7. \(\ln\!\left(\dfrac{\sqrt{x+1}}{e^2(x-1)}\right) = \ln\sqrt{x+1} - \ln e^2 - \ln(x-1)\)

    \(= \dfrac{1}{2}\ln(x+1) - 2 - \ln(x-1)\)

    $$\boxed{\tfrac{1}{2}\ln(x+1) - \ln(x-1) - 2}$$
Skill 28

Exponential and Logarithmic Equations

What It Is

An exponential equation is one where the unknown appears in the exponent, for example \(3^x = 20\). A logarithmic equation is one where the unknown appears inside a logarithm, for example \(\log_2(3x-1) = 4\).

The key idea is that logarithms and exponentials are inverses of each other. To "undo" an exponential, take a log; to "undo" a log, raise the base to a power. This pair of inverse operations lets you isolate the unknown in any such equation.

Always check your solutions back in the original equation: logarithms are only defined for positive arguments, so apparent solutions that make the argument zero or negative must be rejected.

The Rules
Solving \(a^x = b\) — take log of both sides
$$x = \frac{\ln b}{\ln a} \qquad \text{(or equivalently } x\ln a = \ln b\text{)}$$
Solving \(\log_a x = b\) — convert to exponential form
$$x = a^b$$
Inverse identities (always valid for correct domains)
$$e^{\ln x} = x \quad (x>0) \qquad \ln(e^x) = x$$
Hidden quadratic — when \(e^{2x}\) and \(e^x\) appear together

Substitute \(u = e^x\) (or \(u = a^x\)), turning the equation into a quadratic in \(u\).

When To Use It

Exponential growth/decay models: solving \(P_0 e^{kt} = P\) for \(t\).

Equations with the unknown in the exponent: any time you see \(a^x = \text{number}\), take \(\ln\) (or \(\log\)) of both sides.

Equations with logs on one or both sides: convert to exponential form, or use log laws to combine everything into a single log first, then convert.

Hidden quadratics: when \(e^{2x}\) and \(e^x\) appear together, substitute \(u=e^x\) and solve the resulting quadratic in \(u\).

Worked Examples

Example 1 — Solve an exponential equation

Solve \(5^x = 17\), giving your answer to 3 significant figures.

Step 1 — Take \(\ln\) of both sides
$$\ln 5^x = \ln 17$$
Step 2 — Apply the power law
$$x \ln 5 = \ln 17$$
Step 3 — Divide both sides by \(\ln 5\)
$$x = \frac{\ln 17}{\ln 5} = \frac{2.8332\ldots}{1.6094\ldots}$$
Step 4 — Evaluate
$$\boxed{x \approx 1.76}$$

Example 2 — Exponential equation forming a quadratic

Solve \(e^{2x} - 5e^x + 6 = 0\).

Step 1 — Recognise the hidden quadratic

Note that \(e^{2x} = (e^x)^2\). Let \(u = e^x\). The equation becomes:

$$u^2 - 5u + 6 = 0$$
Step 2 — Factorise the quadratic
$$(u-2)(u-3) = 0 \implies u = 2 \text{ or } u = 3$$
Step 3 — Replace \(u\) with \(e^x\) and solve each case

Case 1: \(e^x = 2 \implies x = \ln 2\)

Case 2: \(e^x = 3 \implies x = \ln 3\)

Step 4 — State the solutions
$$\boxed{x = \ln 2 \quad \text{or} \quad x = \ln 3}$$
Practice Questions
  1. Solve \(4^x = 11\), giving your answer to 3 s.f.
  2. Solve \(2^{x+1} = 30\), giving your answer to 3 s.f.
  3. Solve \(\log_3(2x-1) = 4\).
  4. Solve \(\log_2 x + \log_2(x-3) = 2\). (Reject any invalid solutions.)
  5. Solve \(e^{2x} - 3e^x - 10 = 0\), giving exact answers.
  6. Solve \(3\ln x - \ln(x^2) = 2\), giving your answer in exact form.
  7. A population grows according to \(P = 500\,e^{0.04t}\). Find the value of \(t\), to the nearest year, when the population first reaches 2000.
Fully Worked Solutions

  1. \(x\ln 4 = \ln 11 \implies x = \dfrac{\ln 11}{\ln 4}\)

    $$\boxed{x \approx 1.73}$$

  2. Take \(\ln\): \((x+1)\ln 2 = \ln 30\)

    \(x+1 = \dfrac{\ln 30}{\ln 2} \approx \dfrac{3.4012}{0.6931} \approx 4.907\)

    \(x \approx 3.907\)

    $$\boxed{x \approx 3.91}$$

  3. Convert: \(2x-1 = 3^4 = 81\)

    \(2x = 82 \implies x = 41\)

    $$\boxed{x = 41}$$

  4. Multiplication law: \(\log_2[x(x-3)] = 2 \implies x(x-3) = 4\)

    \(x^2 - 3x - 4 = 0 \implies (x-4)(x+1) = 0\)

    \(x = 4\) or \(x = -1\). But \(x = -1\) gives \(\log_2(-1)\) which is undefined.

    $$\boxed{x = 4}$$

  5. Let \(u = e^x\): \(u^2 - 3u - 10 = 0 \implies (u-5)(u+2)=0\)

    \(u = 5\) or \(u = -2\). Since \(e^x > 0\), reject \(u = -2\).

    \(e^x = 5 \implies x = \ln 5\)

    $$\boxed{x = \ln 5}$$

  6. Apply power law: \(\ln x^3 - \ln x^2 = 2 \implies \ln\!\left(\dfrac{x^3}{x^2}\right) = 2 \implies \ln x = 2\)

    $$\boxed{x = e^2}$$

  7. \(500\,e^{0.04t} = 2000 \implies e^{0.04t} = 4\)

    \(0.04t = \ln 4 \implies t = \dfrac{\ln 4}{0.04} \approx \dfrac{1.3863}{0.04} \approx 34.66\)

    $$\boxed{t \approx 35 \text{ years}}$$
Skill 29

The Identity \(\sin^2\theta + \cos^2\theta = 1\) and Its Derived Forms

What It Is

The fundamental Pythagorean trigonometric identity states that for any angle \(\theta\), the square of sine plus the square of cosine always equals exactly 1. This is a direct consequence of Pythagoras' theorem applied to a point on the unit circle.

By dividing this identity through by \(\cos^2\theta\) or by \(\sin^2\theta\), you generate two further identities involving the reciprocal functions \(\sec\) and \(\cosec\) and the co-function \(\cot\). These three identities together are the backbone of almost all trigonometric manipulation at A-level.

Unlike a formula you have to derive fresh each time, these are identities: they are true for every value of \(\theta\) for which the functions are defined, and you use them by substituting one side for the other wherever it helps simplify an expression or equation.

The Identities
Fundamental Identity
$$\sin^2\theta + \cos^2\theta \equiv 1$$
Divide through by \(\cos^2\theta\)
$$\tan^2\theta + 1 \equiv \sec^2\theta$$
Divide through by \(\sin^2\theta\)
$$1 + \cot^2\theta \equiv \cosec^2\theta$$
Useful rearrangements (learn these)
$$\sin^2\theta = 1 - \cos^2\theta \qquad \cos^2\theta = 1 - \sin^2\theta$$ $$\sec^2\theta - 1 = \tan^2\theta \qquad \cosec^2\theta - 1 = \cot^2\theta$$
When To Use It

Solving quadratic trig equations: if an equation contains both \(\sin\) and \(\cos\) (or \(\tan\) and \(\sec\)), substitute the identity to reduce it to one ratio only, then solve as a quadratic.

Proving identities: when one side of a proposed identity contains a squared trig function, substitute using \(\sin^2\theta + \cos^2\theta = 1\) to match the other side.

Integration: replace \(\sin^2\theta\) or \(\cos^2\theta\) using the identity before integrating.

Simplifying expressions: whenever you see \(1 - \sin^2\theta\), recognise it immediately as \(\cos^2\theta\), and so on.

Worked Examples

Example 1 — Solve a quadratic trigonometric equation

Solve \(2\sin^2\theta + \cos\theta - 1 = 0\) for \(0 \leq \theta \leq 360°\).

Step 1 — The equation has both \(\sin^2\theta\) and \(\cos\theta\). Replace \(\sin^2\theta\)

Use \(\sin^2\theta = 1 - \cos^2\theta\):

$$2(1-\cos^2\theta) + \cos\theta - 1 = 0$$
Step 2 — Expand and collect
$$2 - 2\cos^2\theta + \cos\theta - 1 = 0$$ $$-2\cos^2\theta + \cos\theta + 1 = 0$$

Multiply by \(-1\):

$$2\cos^2\theta - \cos\theta - 1 = 0$$
Step 3 — Factorise the quadratic (let \(c = \cos\theta\))
$$(2\cos\theta + 1)(\cos\theta - 1) = 0$$ $$\cos\theta = -\tfrac{1}{2} \quad \text{or} \quad \cos\theta = 1$$
Step 4 — Solve each case in the given range

\(\cos\theta = 1 \implies \theta = 0°, 360°\)

\(\cos\theta = -\frac{1}{2} \implies \theta = 120°, 240°\)

$$\boxed{\theta = 0°,\; 120°,\; 240°,\; 360°}$$

Example 2 — Prove an identity

Prove that \(\dfrac{\sin^2\theta}{1 + \cos\theta} = 1 - \cos\theta\).

Step 1 — Work with the left-hand side (LHS)
$$\text{LHS} = \frac{\sin^2\theta}{1+\cos\theta}$$
Step 2 — Replace \(\sin^2\theta\) using the identity
$$= \frac{1 - \cos^2\theta}{1+\cos\theta}$$
Step 3 — Factorise the numerator as a difference of two squares
$$= \frac{(1-\cos\theta)(1+\cos\theta)}{1+\cos\theta}$$
Step 4 — Cancel the common factor
$$= 1 - \cos\theta = \text{RHS} \qquad \blacksquare$$ $$\boxed{\text{Identity proved.}}$$
Practice Questions
  1. Solve \(\cos^2\theta + \sin\theta + 1 = 0\) for \(0 \leq \theta \leq 360°\).
  2. Solve \(2\tan^2\theta - \sec\theta - 1 = 0\) for \(0° \leq \theta < 360°\).
  3. Simplify \(\dfrac{\cos^2\theta - 1}{\sin\theta}\).
  4. Prove that \(\dfrac{\tan^2\theta}{\sec\theta - 1} = \sec\theta + 1\).
  5. Solve \(3\sin^2\theta = 2\cos\theta + 2\) for \(0 \leq \theta \leq 2\pi\), giving answers in exact form.
  6. Prove that \((\sin\theta + \cos\theta)^2 = 1 + 2\sin\theta\cos\theta\).
  7. Solve \(\cosec^2\theta - \cot\theta = 3\) for \(0° < \theta < 360°\).
Fully Worked Solutions

  1. Replace \(\cos^2\theta = 1-\sin^2\theta\):

    \((1-\sin^2\theta)+\sin\theta+1=0 \implies -\sin^2\theta+\sin\theta+2=0\)

    Multiply by \(-1\): \(\sin^2\theta - \sin\theta - 2 = 0\)

    Factorise: \((\sin\theta-2)(\sin\theta+1)=0\)

    \(\sin\theta = 2\) is impossible (range is \([-1,1]\)).

    \(\sin\theta = -1 \implies \theta = 270°\)

    $$\boxed{\theta = 270°}$$

  2. Use \(\tan^2\theta = \sec^2\theta - 1\):

    \(2(\sec^2\theta-1)-\sec\theta-1=0 \implies 2\sec^2\theta-\sec\theta-3=0\)

    Factorise: \((2\sec\theta-3)(\sec\theta+1)=0\)

    \(\sec\theta = \frac{3}{2} \implies \cos\theta = \frac{2}{3} \implies \theta \approx 48.2°, 311.8°\)

    \(\sec\theta = -1 \implies \cos\theta = -1 \implies \theta = 180°\)

    $$\boxed{\theta \approx 48.2°,\; 180°,\; 311.8°}$$

  3. \(\cos^2\theta - 1 = -(1-\cos^2\theta) = -\sin^2\theta\)

    So \(\dfrac{\cos^2\theta-1}{\sin\theta} = \dfrac{-\sin^2\theta}{\sin\theta} = -\sin\theta\)

    $$\boxed{-\sin\theta}$$

  4. LHS: \(\dfrac{\tan^2\theta}{\sec\theta-1} = \dfrac{\sec^2\theta-1}{\sec\theta-1} = \dfrac{(\sec\theta-1)(\sec\theta+1)}{\sec\theta-1} = \sec\theta+1\) = RHS \(\quad\blacksquare\)

    $$\boxed{\text{Identity proved.}}$$

  5. Replace \(\sin^2\theta = 1-\cos^2\theta\):

    \(3(1-\cos^2\theta)=2\cos\theta+2 \implies 3-3\cos^2\theta=2\cos\theta+2\)

    \(3\cos^2\theta+2\cos\theta-1=0 \implies (3\cos\theta-1)(\cos\theta+1)=0\)

    \(\cos\theta = \frac{1}{3}\): no exact standard angle, so \(\theta = \arccos\!\left(\frac{1}{3}\right)\) and \(\theta = 2\pi - \arccos\!\left(\frac{1}{3}\right)\).

    \(\cos\theta = -1 \implies \theta = \pi\)

    $$\boxed{\theta = \pi,\quad \theta = \arccos\!\!\left(\tfrac{1}{3}\right),\quad \theta = 2\pi - \arccos\!\!\left(\tfrac{1}{3}\right)}$$

  6. LHS: \((\sin\theta+\cos\theta)^2 = \sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta\)

    \(= (\sin^2\theta+\cos^2\theta) + 2\sin\theta\cos\theta = 1 + 2\sin\theta\cos\theta\) = RHS \(\quad\blacksquare\)

    $$\boxed{\text{Identity proved.}}$$

  7. Use \(\cosec^2\theta = 1+\cot^2\theta\):

    \(1+\cot^2\theta - \cot\theta = 3 \implies \cot^2\theta-\cot\theta-2=0\)

    Factorise: \((\cot\theta-2)(\cot\theta+1)=0\)

    \(\cot\theta=2 \implies \tan\theta=\frac{1}{2} \implies \theta\approx 26.6°, 206.6°\)

    \(\cot\theta=-1 \implies \tan\theta=-1 \implies \theta=135°, 315°\)

    $$\boxed{\theta \approx 26.6°,\; 135°,\; 206.6°,\; 315°}$$
Skill 30

Double Angle Formulae

What It Is

The double angle formulae express \(\sin 2\theta\), \(\cos 2\theta\), and \(\tan 2\theta\) in terms of \(\sin\theta\), \(\cos\theta\), and \(\tan\theta\). They are special cases of the addition formulae, obtained by setting both angles equal: \(\sin(A+B)\) with \(A=B=\theta\).

Crucially, \(\cos 2\theta\) has three equivalent forms. You choose the version that matches the other terms already present in the equation or expression you are working with — choosing the right form saves huge amounts of work.

These formulae appear constantly when solving trigonometric equations that mix a double angle with a single angle, when integrating \(\sin^2\theta\) or \(\cos^2\theta\), and when eliminating a parameter from parametric equations.

The Formulae
Sine double angle
$$\sin 2\theta = 2\sin\theta\cos\theta$$
Cosine double angle — three equivalent forms
$$\cos 2\theta = \cos^2\theta - \sin^2\theta$$ $$\cos 2\theta = 2\cos^2\theta - 1$$ $$\cos 2\theta = 1 - 2\sin^2\theta$$
Tangent double angle
$$\tan 2\theta = \frac{2\tan\theta}{1-\tan^2\theta}$$
Rearranged forms for integration (memorise these)
$$\cos^2\theta = \frac{1+\cos 2\theta}{2} \qquad \sin^2\theta = \frac{1-\cos 2\theta}{2}$$
When To Use It

Solving equations: when an equation contains \(\sin 2\theta\) and \(\sin\theta\) (or \(\cos 2\theta\) and \(\cos\theta\)), substitute the double angle formula to get everything in one trig ratio, then factorise.

Choosing the right \(\cos 2\theta\) form: if the other terms in the equation contain only \(\sin\theta\), use \(\cos 2\theta = 1-2\sin^2\theta\); if only \(\cos\theta\), use \(2\cos^2\theta-1\); if both, use \(\cos^2\theta-\sin^2\theta\).

Integration: to integrate \(\sin^2\theta\) or \(\cos^2\theta\), rewrite using the rearranged forms above first.

Eliminating parameters: in parametric equations where \(x=\cos\theta\) and \(y=\cos 2\theta\), substitute \(\cos 2\theta = 2\cos^2\theta-1 = 2x^2-1\) to get the Cartesian form directly.

Worked Examples

Example 1 — Solve a double angle equation

Solve \(\sin 2\theta = \sin\theta\) for \(0 \leq \theta \leq 360°\).

Step 1 — Replace \(\sin 2\theta\) using the double angle formula
$$2\sin\theta\cos\theta = \sin\theta$$
Step 2 — Bring everything to one side
$$2\sin\theta\cos\theta - \sin\theta = 0$$
Step 3 — Factorise — take out the common factor \(\sin\theta\)
$$\sin\theta\,(2\cos\theta - 1) = 0$$
Step 4 — Solve each factor

\(\sin\theta = 0 \implies \theta = 0°, 180°, 360°\)

\(2\cos\theta - 1 = 0 \implies \cos\theta = \dfrac{1}{2} \implies \theta = 60°, 300°\)

Step 5 — Collect all solutions
$$\boxed{\theta = 0°,\; 60°,\; 180°,\; 300°,\; 360°}$$

Example 2 — Equation with \(\cos 2\theta\) and \(\sin\theta\)

Solve \(\cos 2\theta + 3\sin\theta - 2 = 0\) for \(0 \leq \theta \leq 2\pi\).

Step 1 — The other terms contain \(\sin\theta\), so use \(\cos 2\theta = 1-2\sin^2\theta\)
$$(1-2\sin^2\theta) + 3\sin\theta - 2 = 0$$
Step 2 — Collect terms
$$-2\sin^2\theta + 3\sin\theta - 1 = 0$$

Multiply by \(-1\):

$$2\sin^2\theta - 3\sin\theta + 1 = 0$$
Step 3 — Factorise
$$(2\sin\theta - 1)(\sin\theta - 1) = 0$$ $$\sin\theta = \tfrac{1}{2} \quad \text{or} \quad \sin\theta = 1$$
Step 4 — Solve in the given range \(0 \leq \theta \leq 2\pi\)

\(\sin\theta = 1 \implies \theta = \dfrac{\pi}{2}\)

\(\sin\theta = \dfrac{1}{2} \implies \theta = \dfrac{\pi}{6},\;\dfrac{5\pi}{6}\)

$$\boxed{\theta = \frac{\pi}{6},\quad \frac{\pi}{2},\quad \frac{5\pi}{6}}$$
Practice Questions
  1. Solve \(\sin 2\theta = \cos\theta\) for \(0° \leq \theta \leq 360°\).
  2. Solve \(\cos 2\theta = \cos\theta\) for \(0 \leq \theta \leq 2\pi\). Give exact answers.
  3. Solve \(\cos 2\theta + \sin\theta = 0\) for \(-180° \leq \theta \leq 180°\).
  4. Given that \(\sin\theta = \dfrac{3}{5}\) and \(\theta\) is acute, find the exact values of \(\sin 2\theta\) and \(\cos 2\theta\).
  5. Prove that \(\dfrac{\sin 2\theta}{1 - \cos 2\theta} \equiv \cot\theta\).
  6. Solve \(3\cos 2\theta + \cos\theta + 2 = 0\) for \(0° \leq \theta \leq 360°\).
  7. Solve \(\tan 2\theta = 3\tan\theta\) for \(0° < \theta < 180°\), giving answers to 1 decimal place where not exact.
Fully Worked Solutions

  1. Replace \(\sin 2\theta = 2\sin\theta\cos\theta\):

    \(2\sin\theta\cos\theta - \cos\theta = 0 \implies \cos\theta(2\sin\theta-1)=0\)

    \(\cos\theta=0 \implies \theta=90°,270°\)

    \(\sin\theta=\frac{1}{2} \implies \theta=30°,150°\)

    $$\boxed{\theta = 30°,\; 90°,\; 150°,\; 270°}$$

  2. Other terms contain \(\cos\theta\): use \(\cos 2\theta = 2\cos^2\theta-1\).

    \(2\cos^2\theta-1=\cos\theta \implies 2\cos^2\theta-\cos\theta-1=0\)

    \((2\cos\theta+1)(\cos\theta-1)=0\)

    \(\cos\theta=-\frac{1}{2} \implies \theta=\dfrac{2\pi}{3},\;\dfrac{4\pi}{3}\)

    \(\cos\theta=1 \implies \theta=0,\;2\pi\)

    $$\boxed{\theta = 0,\;\frac{2\pi}{3},\;\frac{4\pi}{3},\;2\pi}$$

  3. Use \(\cos 2\theta = 1-2\sin^2\theta\) (other term has \(\sin\theta\)).

    \(1-2\sin^2\theta+\sin\theta=0 \implies 2\sin^2\theta-\sin\theta-1=0\)

    \((2\sin\theta+1)(\sin\theta-1)=0\)

    \(\sin\theta=-\frac{1}{2} \implies \theta=-30°,-150°\)

    \(\sin\theta=1 \implies \theta=90°\)

    $$\boxed{\theta = -150°,\;-30°,\;90°}$$

  4. \(\sin\theta=\frac{3}{5}\), so from Pythagoras \(\cos\theta=\frac{4}{5}\) (acute).

    \(\sin 2\theta = 2\sin\theta\cos\theta = 2\cdot\frac{3}{5}\cdot\frac{4}{5} = \frac{24}{25}\)

    \(\cos 2\theta = \cos^2\theta-\sin^2\theta = \frac{16}{25}-\frac{9}{25} = \frac{7}{25}\)

    $$\boxed{\sin 2\theta = \frac{24}{25},\quad \cos 2\theta = \frac{7}{25}}$$

  5. LHS: \(\dfrac{\sin 2\theta}{1-\cos 2\theta} = \dfrac{2\sin\theta\cos\theta}{1-(1-2\sin^2\theta)} = \dfrac{2\sin\theta\cos\theta}{2\sin^2\theta} = \dfrac{\cos\theta}{\sin\theta} = \cot\theta\) = RHS \(\quad\blacksquare\)

    $$\boxed{\text{Identity proved.}}$$

  6. Use \(\cos 2\theta = 2\cos^2\theta - 1\):

    \(3(2\cos^2\theta-1)+\cos\theta+2=0 \implies 6\cos^2\theta+\cos\theta-1=0\)

    \((3\cos\theta-1)(2\cos\theta+1)=0\)

    \(\cos\theta=\frac{1}{3} \implies \theta\approx 70.5°,289.5°\)

    \(\cos\theta=-\frac{1}{2} \implies \theta=120°,240°\)

    $$\boxed{\theta \approx 70.5°,\;120°,\;240°,\;289.5°}$$

  7. Replace \(\tan 2\theta = \dfrac{2\tan\theta}{1-\tan^2\theta}\):

    \(\dfrac{2\tan\theta}{1-\tan^2\theta} = 3\tan\theta\)

    If \(\tan\theta \neq 0\): divide both sides by \(\tan\theta\):

    \(\dfrac{2}{1-\tan^2\theta}=3 \implies 2=3(1-\tan^2\theta)=3-3\tan^2\theta\)

    \(3\tan^2\theta=1 \implies \tan^2\theta=\frac{1}{3} \implies \tan\theta=\pm\frac{1}{\sqrt{3}}\)

    In \(0°<\theta<180°\): \(\tan\theta=\frac{1}{\sqrt{3}}\implies\theta=30°\); \(\tan\theta=-\frac{1}{\sqrt{3}}\implies\theta=150°\).

    Also check \(\tan\theta=0\): \(\theta=0°\) and \(\theta=180°\) are excluded by the open interval.

    $$\boxed{\theta = 30°,\;150°}$$
