Skill 06

Differentiating \(\ln(x)\) and \(\ln(f(x))\)

What It Is

The natural logarithm \(\ln(x)\) is the inverse function of \(e^x\). Just as every function has a derivative, so does \(\ln(x)\), and it turns out to be beautifully simple: just \(\dfrac{1}{x}\). This result comes directly from implicit differentiation of \(e^y = x\), and you will prove it in Skill 10.

When the argument is not simply \(x\) but a more complicated function — such as \(\ln(3x^2 + 1)\) — we must use the Chain Rule (differentiate the outer \(\ln\), then multiply by the derivative of the inside). This gives the general result \(\dfrac{f'(x)}{f(x)}\).

This skill appears constantly in A-Level: in integration (reverse direction), in exponential models, and whenever a question involves quantities inside logarithms.

The Rule

$$\frac{d}{dx}\bigl[\ln(x)\bigr] = \frac{1}{x}, \qquad x > 0$$
$$\frac{d}{dx}\bigl[\ln(f(x))\bigr] = \frac{f'(x)}{f(x)}$$
$$\frac{d}{dx}\bigl[a\ln(f(x))\bigr] = \frac{a\,f'(x)}{f(x)}$$

The second rule is simply the Chain Rule applied: differentiate \(\ln(\square)\) to get \(\frac{1}{\square}\), then multiply by the derivative of \(\square\).

When to Use It

  • Any time you see \(\ln(\text{something})\) and need to differentiate.
  • When finding the gradient of a curve whose equation contains a natural log.
  • When solving optimisation problems involving logarithmic functions.
  • In implicit differentiation when a term like \(\ln(y)\) or \(\ln(xy)\) appears.
  • As the first step before applying the Product or Quotient Rule when combined with other functions (e.g. \(x^2 \ln x\)).

Worked Examples

Example 1
Differentiate \(y = \ln(4x^3 - 5x)\).
1
Identify the structure. This is \(\ln(f(x))\) where \(f(x) = 4x^3 - 5x\). We apply the rule \(\dfrac{f'(x)}{f(x)}\).
2
Find \(f'(x)\). Differentiate \(f(x) = 4x^3 - 5x\) term by term: $$f'(x) = 12x^2 - 5$$
3
Apply the rule. Place \(f'(x)\) on top and \(f(x)\) on the bottom: $$\frac{dy}{dx} = \frac{12x^2 - 5}{4x^3 - 5x}$$
4
Final answer (no further simplification possible): $$\boxed{\dfrac{dy}{dx} = \dfrac{12x^2 - 5}{4x^3 - 5x}}$$
Example 2
Differentiate \(y = 3\ln(\sin x)\).
1
Identify the structure. This is \(a\ln(f(x))\) with \(a = 3\) and \(f(x) = \sin x\).
2
Find \(f'(x)\). The derivative of \(\sin x\) is \(\cos x\), so \(f'(x) = \cos x\).
3
Apply the rule. Multiply the constant \(a = 3\) by \(\dfrac{f'(x)}{f(x)}\): $$\frac{dy}{dx} = 3 \cdot \frac{\cos x}{\sin x}$$
4
Simplify. Recall that \(\dfrac{\cos x}{\sin x} = \cot x\): $$\boxed{\dfrac{dy}{dx} = 3\cot x}$$

Practice Questions

  1. Differentiate \(y = \ln(7x)\).
  2. Differentiate \(y = \ln(x^2 + 3x)\).
  3. Differentiate \(y = \ln(e^x + 1)\).
  4. Differentiate \(y = 5\ln(2x^3 - x)\).
  5. Differentiate \(y = \ln(\cos x)\).
  6. Differentiate \(y = \ln\!\left(\sqrt{x^2+1}\right)\). Hint: use log laws first.
  7. Find the gradient of the curve \(y = \ln(x^2 - 4)\) at the point where \(x = 3\).

Fully Worked Solutions

Solution to Q1
\(y = \ln(7x)\)
1
Here \(f(x) = 7x\), so \(f'(x) = 7\).
2
Apply the rule: \(\dfrac{dy}{dx} = \dfrac{7}{7x} = \dfrac{1}{x}\).
3
$$\boxed{\dfrac{dy}{dx} = \dfrac{1}{x}}$$ (This is the same as \(\ln x\) — the constant inside the log disappears upon differentiation, which is consistent with the log law \(\ln(7x) = \ln 7 + \ln x\).)
Solution to Q2
\(y = \ln(x^2 + 3x)\)
1
\(f(x) = x^2 + 3x\), so \(f'(x) = 2x + 3\).
2
Apply the rule: \(\dfrac{dy}{dx} = \dfrac{2x+3}{x^2+3x}\).
3
$$\boxed{\dfrac{dy}{dx} = \dfrac{2x+3}{x^2+3x}}$$
Solution to Q3
\(y = \ln(e^x + 1)\)
1
\(f(x) = e^x + 1\), so \(f'(x) = e^x\).
2
$$\boxed{\dfrac{dy}{dx} = \dfrac{e^x}{e^x + 1}}$$
Solution to Q4
\(y = 5\ln(2x^3 - x)\)
1
\(f(x) = 2x^3 - x\), so \(f'(x) = 6x^2 - 1\).
2
Multiply the constant 5 by \(\dfrac{f'(x)}{f(x)}\): \(\dfrac{dy}{dx} = \dfrac{5(6x^2-1)}{2x^3-x}\).
3
$$\boxed{\dfrac{dy}{dx} = \dfrac{30x^2-5}{2x^3-x}}$$
Solution to Q5
\(y = \ln(\cos x)\)
1
\(f(x) = \cos x\), so \(f'(x) = -\sin x\).
2
\(\dfrac{dy}{dx} = \dfrac{-\sin x}{\cos x}\).
3
Since \(\dfrac{\sin x}{\cos x} = \tan x\): $$\boxed{\dfrac{dy}{dx} = -\tan x}$$
Solution to Q6
\(y = \ln\!\left(\sqrt{x^2+1}\right)\)
1
Use the log law: \(\ln\!\left(\sqrt{x^2+1}\right) = \dfrac{1}{2}\ln(x^2+1)\).
2
Now \(f(x) = x^2 + 1\), so \(f'(x) = 2x\).
3
\(\dfrac{dy}{dx} = \dfrac{1}{2} \cdot \dfrac{2x}{x^2+1}\).
4
$$\boxed{\dfrac{dy}{dx} = \dfrac{x}{x^2+1}}$$
Solution to Q7
Gradient of \(y = \ln(x^2 - 4)\) at \(x = 3\).
1
\(f(x) = x^2 - 4\), so \(f'(x) = 2x\).
2
\(\dfrac{dy}{dx} = \dfrac{2x}{x^2 - 4}\).
3
Substitute \(x = 3\): \(\dfrac{dy}{dx} = \dfrac{2(3)}{9-4} = \dfrac{6}{5}\).
4
$$\boxed{\text{Gradient} = \dfrac{6}{5}}$$
Skill 07

Differentiating \(\sin x\), \(\cos x\), and \(\tan x\)

What It Is

The three primary trigonometric functions — sine, cosine, and tangent — each have well-known derivatives that you must memorise. These are standard results proved using first principles (via small angle approximations) and the quotient rule for tangent.

A critical rule: all trigonometric differentiation must be done with angles measured in radians, not degrees. The derivatives break down entirely if you use degrees.

When the argument is not simply \(x\) but \(f(x)\) (e.g. \(\sin(3x^2)\)), you apply the Chain Rule: differentiate the outer trig function, then multiply by the derivative of the inside. These are the most frequently examined results in A-Level differentiation.

The Rules

$$\frac{d}{dx}[\sin x] = \cos x \qquad \frac{d}{dx}[\sin(f(x))] = f'(x)\cos(f(x))$$
$$\frac{d}{dx}[\cos x] = -\sin x \qquad \frac{d}{dx}[\cos(f(x))] = -f'(x)\sin(f(x))$$
$$\frac{d}{dx}[\tan x] = \sec^2 x \qquad \frac{d}{dx}[\tan(f(x))] = f'(x)\sec^2(f(x))$$

Memory aid: The derivative of a "co-" function always picks up a minus sign. Sine and cosine cycle into each other; tangent goes to \(\sec^2\).

When to Use It

  • Any time you differentiate a function containing \(\sin\), \(\cos\), or \(\tan\) of any expression.
  • Finding stationary points of wave-like functions (e.g. displacements in SHM).
  • Combined with Product Rule when multiplied by another function (e.g. \(e^x \sin x\)).
  • As the inner result when applying Chain Rule to compound trig expressions.
  • When verifying that a parametric curve satisfies a particular gradient condition.

Worked Examples

Example 1
Differentiate \(y = \cos(5x^2 - 3)\).
1
Identify the structure. Outer function: \(\cos(\square)\). Inner function: \(f(x) = 5x^2 - 3\).
2
Differentiate the inner function. \(f'(x) = 10x\).
3
Apply Chain Rule for cosine. The derivative of \(\cos(\square)\) is \(-\sin(\square)\), multiplied by \(f'(x)\): $$\frac{dy}{dx} = -\sin(5x^2 - 3) \times 10x$$
4
Write the final answer. $$\boxed{\dfrac{dy}{dx} = -10x\sin(5x^2 - 3)}$$
Example 2
Differentiate \(y = \tan(e^{2x})\).
1
Identify the structure. Outer: \(\tan(\square)\). Inner: \(f(x) = e^{2x}\).
2
Differentiate the inner function using the chain rule for exponentials: \(f'(x) = 2e^{2x}\).
3
Apply Chain Rule for tangent. The derivative of \(\tan(\square)\) is \(\sec^2(\square)\), multiplied by \(f'(x)\): $$\frac{dy}{dx} = \sec^2(e^{2x}) \times 2e^{2x}$$
4
$$\boxed{\dfrac{dy}{dx} = 2e^{2x}\sec^2(e^{2x})}$$

Practice Questions

  1. Differentiate \(y = \sin(6x)\).
  2. Differentiate \(y = \cos(x^3)\).
  3. Differentiate \(y = \tan(4x - 1)\).
  4. Differentiate \(y = 3\sin(2x^2 + x)\).
  5. Differentiate \(y = \cos^2(x)\). Hint: write as \([\cos(x)]^2\) and use the Chain Rule.
  6. Differentiate \(y = \sin(x)\cos(x)\). Use the Product Rule.
  7. Find the gradient of \(y = \tan(3x)\) at \(x = \dfrac{\pi}{12}\).

Fully Worked Solutions

Solution to Q1
\(y = \sin(6x)\)
1
\(f(x) = 6x\), so \(f'(x) = 6\).
2
$$\boxed{\dfrac{dy}{dx} = 6\cos(6x)}$$
Solution to Q2
\(y = \cos(x^3)\)
1
\(f(x) = x^3\), so \(f'(x) = 3x^2\).
2
Derivative of cosine picks up a minus sign: $$\boxed{\dfrac{dy}{dx} = -3x^2\sin(x^3)}$$
Solution to Q3
\(y = \tan(4x - 1)\)
1
\(f(x) = 4x-1\), so \(f'(x) = 4\).
2
$$\boxed{\dfrac{dy}{dx} = 4\sec^2(4x-1)}$$
Solution to Q4
\(y = 3\sin(2x^2 + x)\)
1
\(f(x) = 2x^2+x\), so \(f'(x) = 4x+1\).
2
Multiply the constant 3 through: \(\dfrac{dy}{dx} = 3(4x+1)\cos(2x^2+x)\).
3
$$\boxed{\dfrac{dy}{dx} = (12x+3)\cos(2x^2+x)}$$
Solution to Q5
\(y = \cos^2(x) = [\cos(x)]^2\)
1
Let \(u = \cos(x)\), so \(y = u^2\).
2
\(\dfrac{dy}{du} = 2u\) and \(\dfrac{du}{dx} = -\sin x\).
3
Chain Rule: \(\dfrac{dy}{dx} = 2\cos(x) \times (-\sin x) = -2\sin x \cos x\).
4
Using the double angle identity \(\sin(2x) = 2\sin x\cos x\): $$\boxed{\dfrac{dy}{dx} = -\sin(2x)}$$
Solution to Q6
\(y = \sin(x)\cos(x)\) — Product Rule
1
Let \(u = \sin x\) and \(v = \cos x\).
2
\(u' = \cos x\) and \(v' = -\sin x\).
3
Product Rule: \(\dfrac{dy}{dx} = u'v + uv' = \cos x \cdot \cos x + \sin x \cdot (-\sin x) = \cos^2 x - \sin^2 x\).
4
Using the double angle identity \(\cos(2x) = \cos^2 x - \sin^2 x\): $$\boxed{\dfrac{dy}{dx} = \cos(2x)}$$
Solution to Q7
Gradient of \(y = \tan(3x)\) at \(x = \dfrac{\pi}{12}\).
1
\(f(x) = 3x\), \(f'(x) = 3\). So \(\dfrac{dy}{dx} = 3\sec^2(3x)\).
2
Substitute \(x = \dfrac{\pi}{12}\): the argument becomes \(3 \times \dfrac{\pi}{12} = \dfrac{\pi}{4}\).
3
\(\cos\!\left(\dfrac{\pi}{4}\right) = \dfrac{1}{\sqrt{2}}\), so \(\sec\!\left(\dfrac{\pi}{4}\right) = \sqrt{2}\) and \(\sec^2\!\left(\dfrac{\pi}{4}\right) = 2\).
4
$$\boxed{\text{Gradient} = 3 \times 2 = 6}$$
Skill 08

Differentiating \(\sec x\), \(\operatorname{cosec} x\), and \(\cot x\)

What It Is

The reciprocal trigonometric functions — secant, cosecant, and cotangent — are defined as \(\sec x = \dfrac{1}{\cos x}\), \(\operatorname{cosec} x = \dfrac{1}{\sin x}\), and \(\cot x = \dfrac{\cos x}{\sin x}\). Their derivatives are derived using the Quotient Rule applied to these definitions.

You do not need to re-derive these each time; the results are standard and must be memorised. Notice the pattern: the derivatives of the "co-" forms (cosec, cot) carry a negative sign, just as \(\dfrac{d}{dx}[\cos x] = -\sin x\).

These results combine with the Chain Rule when the argument is a function of \(x\). They also appear in integration questions (worked in reverse) and in proving trigonometric identities.

The Rules

$$\frac{d}{dx}[\sec x] = \sec x \tan x$$
$$\frac{d}{dx}[\operatorname{cosec}\, x] = -\operatorname{cosec}\, x\cot x$$
$$\frac{d}{dx}[\cot x] = -\operatorname{cosec}^2 x$$

With Chain Rule: replace each \(x\) with \(f(x)\) and multiply the whole result by \(f'(x)\). For example, \(\dfrac{d}{dx}[\sec(f(x))] = f'(x)\sec(f(x))\tan(f(x))\).

When to Use It

  • When differentiating expressions that directly contain \(\sec\), \(\operatorname{cosec}\), or \(\cot\).
  • In implicit differentiation where \(\sec(y)\) or similar terms appear.
  • In reverse, these results tell you what integrates to give \(\sec x \tan x\) or \(\operatorname{cosec}^2 x\).
  • In parametric differentiation where coordinates are defined with reciprocal trig functions.

Worked Examples

Example 1
Differentiate \(y = \sec(3x^2)\).
1
Identify the structure. Outer: \(\sec(\square)\). Inner: \(f(x) = 3x^2\), so \(f'(x) = 6x\).
2
Apply Chain Rule with the sec derivative. The derivative of \(\sec(\square)\) is \(\sec(\square)\tan(\square)\), then multiply by \(f'(x)\): $$\frac{dy}{dx} = 6x \cdot \sec(3x^2)\tan(3x^2)$$
3
$$\boxed{\dfrac{dy}{dx} = 6x\sec(3x^2)\tan(3x^2)}$$
Example 2
Differentiate \(y = \cot(e^x)\).
1
Identify the structure. Outer: \(\cot(\square)\). Inner: \(f(x) = e^x\), so \(f'(x) = e^x\).
2
Apply Chain Rule with the cot derivative. The derivative of \(\cot(\square)\) is \(-\operatorname{cosec}^2(\square)\), then multiply by \(f'(x)\): $$\frac{dy}{dx} = e^x \times \bigl(-\operatorname{cosec}^2(e^x)\bigr)$$
3
$$\boxed{\dfrac{dy}{dx} = -e^x\operatorname{cosec}^2(e^x)}$$

Practice Questions

  1. Differentiate \(y = \operatorname{cosec}(x)\).
  2. Differentiate \(y = \cot(5x)\).
  3. Differentiate \(y = \sec(x^2 + 1)\).
  4. Differentiate \(y = 4\operatorname{cosec}(3x)\).
  5. Differentiate \(y = \cot^2(x)\). Write as \([\cot(x)]^2\) and use the Chain Rule.
  6. Differentiate \(y = \sec(x)\operatorname{cosec}(x)\). Use the Product Rule.
  7. Find the gradient of \(y = \cot(2x)\) at \(x = \dfrac{\pi}{4}\).

Fully Worked Solutions

Solution to Q1
\(y = \operatorname{cosec}(x)\)
1
This is the standard result directly. The inner function is \(f(x) = x\), \(f'(x) = 1\).
2
$$\boxed{\dfrac{dy}{dx} = -\operatorname{cosec}(x)\cot(x)}$$
Solution to Q2
\(y = \cot(5x)\)
1
\(f(x) = 5x\), so \(f'(x) = 5\).
2
$$\boxed{\dfrac{dy}{dx} = -5\operatorname{cosec}^2(5x)}$$
Solution to Q3
\(y = \sec(x^2 + 1)\)
1
\(f(x) = x^2+1\), so \(f'(x) = 2x\).
2
$$\boxed{\dfrac{dy}{dx} = 2x\sec(x^2+1)\tan(x^2+1)}$$
Solution to Q4
\(y = 4\operatorname{cosec}(3x)\)
1
\(f(x) = 3x\), so \(f'(x) = 3\).
2
\(\dfrac{dy}{dx} = 4 \times 3 \times (-\operatorname{cosec}(3x)\cot(3x))\).
3
$$\boxed{\dfrac{dy}{dx} = -12\operatorname{cosec}(3x)\cot(3x)}$$
Solution to Q5
\(y = \cot^2(x) = [\cot(x)]^2\)
1
Let \(u = \cot(x)\), so \(y = u^2\).
2
\(\dfrac{dy}{du} = 2u\) and \(\dfrac{du}{dx} = -\operatorname{cosec}^2(x)\).
3
Chain Rule: \(\dfrac{dy}{dx} = 2\cot(x) \times (-\operatorname{cosec}^2 x)\).
4
$$\boxed{\dfrac{dy}{dx} = -2\cot(x)\operatorname{cosec}^2(x)}$$
Solution to Q6
\(y = \sec(x)\operatorname{cosec}(x)\) — Product Rule
1
Let \(u = \sec x\) and \(v = \operatorname{cosec} x\).
2
\(u' = \sec x\tan x\) and \(v' = -\operatorname{cosec} x\cot x\).
3
Product Rule: \(\dfrac{dy}{dx} = \sec x\tan x\cdot\operatorname{cosec} x + \sec x\cdot(-\operatorname{cosec} x\cot x)\).
4
Factor \(\sec x\operatorname{cosec} x\): \(\dfrac{dy}{dx} = \sec x\operatorname{cosec} x(\tan x - \cot x)\).
5
$$\boxed{\dfrac{dy}{dx} = \sec x\operatorname{cosec} x(\tan x - \cot x)}$$
Solution to Q7
Gradient of \(y = \cot(2x)\) at \(x = \dfrac{\pi}{4}\).
1
\(f(x) = 2x\), \(f'(x) = 2\). So \(\dfrac{dy}{dx} = -2\operatorname{cosec}^2(2x)\).
2
At \(x = \dfrac{\pi}{4}\), the argument is \(2 \times \dfrac{\pi}{4} = \dfrac{\pi}{2}\).
3
\(\sin\!\left(\dfrac{\pi}{2}\right) = 1\), so \(\operatorname{cosec}\!\left(\dfrac{\pi}{2}\right) = 1\) and \(\operatorname{cosec}^2\!\left(\dfrac{\pi}{2}\right) = 1\).
4
$$\boxed{\text{Gradient} = -2 \times 1 = -2}$$
Skill 09

Differentiating Non-\(x\) Terms: \(y^2\), \(\sin y\), \(e^y\), etc.

What It Is

When an equation mixes both \(x\) and \(y\) terms together — such as \(x^2 + y^2 = 25\) — we sometimes want \(\dfrac{dy}{dx}\) (the gradient) without first solving for \(y\). To do this, we differentiate every term with respect to \(x\), including the \(y\) terms.

Here is the key idea: \(y\) is itself a function of \(x\). So when you differentiate a function of \(y\) with respect to \(x\), you must use the Chain Rule: differentiate with respect to \(y\) as normal, then multiply by \(\dfrac{dy}{dx}\).

This technique is the foundation of Skill 10 (Implicit Differentiation). Think of it as: differentiate the expression in \(y\), then tag on a \(\dfrac{dy}{dx}\).

The Rule

$$\frac{d}{dx}\bigl[g(y)\bigr] = g'(y) \cdot \frac{dy}{dx}$$

Applied to specific cases:

$$\frac{d}{dx}\bigl[y^n\bigr] = ny^{n-1}\frac{dy}{dx}$$
$$\frac{d}{dx}\bigl[\sin y\bigr] = \cos y\,\frac{dy}{dx} \qquad \frac{d}{dx}\bigl[\cos y\bigr] = -\sin y\,\frac{dy}{dx}$$
$$\frac{d}{dx}\bigl[e^y\bigr] = e^y\frac{dy}{dx} \qquad \frac{d}{dx}\bigl[\ln y\bigr] = \frac{1}{y}\frac{dy}{dx}$$

The rule is identical to differentiating with respect to \(x\), except \(x\) is replaced by \(y\), and you multiply the result by \(\dfrac{dy}{dx}\).

When to Use It

  • Whenever you need to differentiate a power of \(y\), or a trig/exp/log function of \(y\), with respect to \(x\).
  • This is a prerequisite step before performing full Implicit Differentiation (Skill 10).
  • In rates of change problems where you differentiate a formula (e.g. volume) in terms of another variable.
  • Whenever \(y\) appears in an equation alongside \(x\) and you need the gradient.

Worked Examples

Example 1
Find \(\dfrac{d}{dx}\bigl[y^4 + \sin y\bigr]\).
1
Differentiate \(y^4\) with respect to \(x\). Apply the power rule on \(y\), then multiply by \(\dfrac{dy}{dx}\): $$\frac{d}{dx}[y^4] = 4y^3\frac{dy}{dx}$$
2
Differentiate \(\sin y\) with respect to \(x\). Apply the trig rule on \(y\), then multiply by \(\dfrac{dy}{dx}\): $$\frac{d}{dx}[\sin y] = \cos y\,\frac{dy}{dx}$$
3
Combine the two results: $$\boxed{\frac{d}{dx}\bigl[y^4 + \sin y\bigr] = 4y^3\frac{dy}{dx} + \cos y\,\frac{dy}{dx}}$$
Example 2
Find \(\dfrac{d}{dx}\bigl[x^2 y^3\bigr]\). (This involves both \(x\) and \(y\) — use the Product Rule.)
1
Set up for Product Rule. Let \(u = x^2\) and \(v = y^3\).
2
Differentiate each factor. \(u' = 2x\) (standard). \(v' = \dfrac{d}{dx}[y^3] = 3y^2\dfrac{dy}{dx}\) (Chain Rule on \(y\)).
3
Apply Product Rule: \(u'v + uv'\): $$\frac{d}{dx}[x^2y^3] = 2x \cdot y^3 + x^2 \cdot 3y^2\frac{dy}{dx}$$
4
$$\boxed{\frac{d}{dx}\bigl[x^2y^3\bigr] = 2xy^3 + 3x^2y^2\dfrac{dy}{dx}}$$

Solution to Q3

1
Inner function is \(3y\). Differentiate \(e^{3y}\) with respect to \(y\): gives \(3e^{3y}\) (Chain Rule on \(3y\)). Then multiply by \(\dfrac{dy}{dx}\).
2
$$\boxed{3e^{3y}\dfrac{dy}{dx}}$$
Solution to Q4

Use log law: \(\ln(y^2) = 2\ln(y)\).

Let \(u = x\), \(v = \sin y\). Then \(u' = 1\) and \(v' = \cos y\dfrac{dy}{dx}\).
2
Product Rule: \(u'v + uv' = 1 \cdot \sin y + x \cdot \cos y\dfrac{dy}{dx}\).
3
$$\boxed{\sin y + x\cos y\,\dfrac{dy}{dx}}$$
Skill 10

Implicit Differentiation

What It Is

An implicit equation is one where \(x\) and \(y\) are mixed together and \(y\) is not isolated as the subject — for example, \(x^2 + y^2 = 25\) or \(x^3 + y^3 - 3xy = 0\). Rearranging these for \(y\) explicitly is often impossible or extremely messy.

Implicit differentiation lets us find \(\dfrac{dy}{dx}\) directly from the equation as it stands. The method is: differentiate every term with respect to \(x\). For \(x\)-terms this is straightforward. For \(y\)-terms, use the Chain Rule result from Skill 9 — differentiate with respect to \(y\), then multiply by \(\dfrac{dy}{dx}\).

After differentiating all terms, you collect every term containing \(\dfrac{dy}{dx}\) on one side, factorise, and divide to isolate \(\dfrac{dy}{dx}\). The final answer will generally contain both \(x\) and \(y\).

The Method (Step-by-Step Blueprint)

Step 1: Differentiate every term with respect to \(x\). For \(y\)-terms, use \(\dfrac{d}{dx}[g(y)] = g'(y)\dfrac{dy}{dx}\).

Step 2: Collect all terms with \(\dfrac{dy}{dx}\) on the left side; move all other terms to the right.

Step 3: Factorise: \(\dfrac{dy}{dx}\bigl[\text{bracket}\bigr] = \text{RHS}\).

Step 4: Divide both sides by the bracket to get \(\dfrac{dy}{dx} = \dfrac{\text{RHS}}{\text{bracket}}\).

When to Use It

  • When the equation of a curve has both \(x\) and \(y\) mixed and cannot easily be rearranged.
  • Finding the equation of a tangent or normal to an implicitly defined curve at a given point.
  • Finding stationary points: set \(\dfrac{dy}{dx} = 0\) after implicit differentiation.
  • When the equation involves products of \(x\) and \(y\) (e.g. \(xy^2\), \(x^2 y\)) — Product Rule is needed inside the implicit differentiation.
  • To prove standard derivative results — for example, differentiating \(y = \ln x\) by writing \(e^y = x\) and using implicit differentiation gives \(\dfrac{dy}{dx} = \dfrac{1}{x}\).

Worked Examples

Example 1
Given \(x^2 + 3y^2 - 4x + 2y = 10\), find \(\dfrac{dy}{dx}\).
1
Differentiate every term with respect to \(x\).
  • \(\dfrac{d}{dx}[x^2] = 2x\)
  • \(\dfrac{d}{dx}[3y^2] = 6y\dfrac{dy}{dx}\) (Skill 9 rule)
  • \(\dfrac{d}{dx}[-4x] = -4\)
  • \(\dfrac{d}{dx}[2y] = 2\dfrac{dy}{dx}\)
  • \(\dfrac{d}{dx}[10] = 0\)
So the full differentiated equation is: $$2x + 6y\frac{dy}{dx} - 4 + 2\frac{dy}{dx} = 0$$
2
Collect \(\dfrac{dy}{dx}\) terms on the left, everything else on the right. $$6y\frac{dy}{dx} + 2\frac{dy}{dx} = 4 - 2x$$
3
Factorise the left side. $$\frac{dy}{dx}(6y + 2) = 4 - 2x$$
4
Divide both sides by \((6y+2)\). $$\frac{dy}{dx} = \frac{4 - 2x}{6y + 2}$$
5
Simplify by factoring numerator and denominator (factor 2). $$\boxed{\dfrac{dy}{dx} = \dfrac{2 - x}{3y + 1}}$$
Example 2
Given \(x^2 y + y^3 = 5\), find the equation of the tangent at the point \((2, 1)\).
1
Differentiate every term with respect to \(x\).
  • \(\dfrac{d}{dx}[x^2 y]\): Product Rule with \(u = x^2\), \(v = y\). Result: \(2xy + x^2\dfrac{dy}{dx}\).
  • \(\dfrac{d}{dx}[y^3] = 3y^2\dfrac{dy}{dx}\)
  • \(\dfrac{d}{dx}[5] = 0\)
Full equation: $$2xy + x^2\frac{dy}{dx} + 3y^2\frac{dy}{dx} = 0$$
2
Collect \(\dfrac{dy}{dx}\) terms on the left. $$x^2\frac{dy}{dx} + 3y^2\frac{dy}{dx} = -2xy$$
3
Factorise. $$\frac{dy}{dx}(x^2 + 3y^2) = -2xy$$
4
Isolate \(\dfrac{dy}{dx}\). $$\frac{dy}{dx} = \frac{-2xy}{x^2 + 3y^2}$$
5
Substitute the point \((2,1)\) to find the gradient. $$\frac{dy}{dx}\bigg|_{(2,1)} = \frac{-2(2)(1)}{(2)^2 + 3(1)^2} = \frac{-4}{4 + 3} = \frac{-4}{7}$$
6
Use \(y - y_1 = m(x - x_1)\) with \(m = -\dfrac{4}{7}\) and the point \((2,1)\). $$y - 1 = -\frac{4}{7}(x - 2)$$ $$7y - 7 = -4x + 8$$ $$\boxed{4x + 7y = 15}$$

Practice Questions

  1. Find \(\dfrac{dy}{dx}\) given \(x^2 + y^2 = 36\).
  2. Find \(\dfrac{dy}{dx}\) given \(3x^2 + 2y^3 = 11\).
  3. Find \(\dfrac{dy}{dx}\) given \(x^3 - xy + y^2 = 7\).
  4. Find \(\dfrac{dy}{dx}\) given \(\sin y + x^2 = 3\).
  5. Find \(\dfrac{dy}{dx}\) given \(e^y + xy = 4\).
  6. Given \(x^2 + y^2 - 2x - 4y = 20\), find the coordinates of any stationary points (where \(\dfrac{dy}{dx} = 0\)).
  7. Given \(x^2 + 2xy + 3y^2 = 12\), find the equation of the tangent at the point \((1, -2)\). First verify this point lies on the curve, then find the gradient, then find the equation.

Fully Worked Solutions

Solution to Q1
\(x^2 + y^2 = 36\)
1
Differentiate each term: \(2x + 2y\dfrac{dy}{dx} = 0\).
2
Collect: \(2y\dfrac{dy}{dx} = -2x\).
3
$$\boxed{\dfrac{dy}{dx} = -\dfrac{x}{y}}$$
Solution to Q2
\(3x^2 + 2y^3 = 11\)
1
Differentiate: \(6x + 6y^2\dfrac{dy}{dx} = 0\).
2
Collect and solve: \(6y^2\dfrac{dy}{dx} = -6x\).
3
$$\boxed{\dfrac{dy}{dx} = -\dfrac{x}{y^2}}$$
Solution to Q3
\(x^3 - xy + y^2 = 7\)
1
Differentiate \(x^3\): \(3x^2\).
2
Differentiate \(-xy\) using Product Rule (\(u=-x\), \(v=y\)): \(-y + (-x)\dfrac{dy}{dx} = -y - x\dfrac{dy}{dx}\).
3
Differentiate \(y^2\): \(2y\dfrac{dy}{dx}\).
4
Full equation: \(3x^2 - y - x\dfrac{dy}{dx} + 2y\dfrac{dy}{dx} = 0\).
5
Collect \(\dfrac{dy}{dx}\): \(\dfrac{dy}{dx}(2y - x) = y - 3x^2\).
6
$$\boxed{\dfrac{dy}{dx} = \dfrac{y - 3x^2}{2y - x}}$$
Solution to Q4
\(\sin y + x^2 = 3\)
1
Differentiate \(\sin y\): \(\cos y\dfrac{dy}{dx}\). Differentiate \(x^2\): \(2x\). Differentiate \(3\): \(0\).
2
Full equation: \(\cos y\dfrac{dy}{dx} + 2x = 0\).
3
$$\boxed{\dfrac{dy}{dx} = \dfrac{-2x}{\cos y}}$$
Solution to Q5
\(e^y + xy = 4\)
1
Differentiate \(e^y\): \(e^y\dfrac{dy}{dx}\).
2
Differentiate \(xy\) by Product Rule (\(u=x\), \(v=y\)): \(y + x\dfrac{dy}{dx}\).
3
Full equation: \(e^y\dfrac{dy}{dx} + y + x\dfrac{dy}{dx} = 0\).
4
Collect: \(\dfrac{dy}{dx}(e^y + x) = -y\).
5
$$\boxed{\dfrac{dy}{dx} = \dfrac{-y}{e^y + x}}$$
Solution to Q6
\(x^2 + y^2 - 2x - 4y = 20\) — stationary points
1
Differentiate: \(2x + 2y\dfrac{dy}{dx} - 2 - 4\dfrac{dy}{dx} = 0\).
2
Collect: \(\dfrac{dy}{dx}(2y - 4) = 2 - 2x\), so \(\dfrac{dy}{dx} = \dfrac{2 - 2x}{2y - 4} = \dfrac{1-x}{y-2}\).
3
At stationary points, \(\dfrac{dy}{dx} = 0\), so the numerator \(= 0\): \(1 - x = 0 \Rightarrow x = 1\).
4
Substitute \(x = 1\) into the original equation: \(1 + y^2 - 2 - 4y = 20 \Rightarrow y^2 - 4y - 21 = 0\).
5
Factorise: \((y-7)(y+3) = 0 \Rightarrow y = 7\) or \(y = -3\).
6
$$\boxed{\text{Stationary points at }(1, 7)\text{ and }(1, -3)}$$
Solution to Q7
\(x^2 + 2xy + 3y^2 = 12\) — tangent at \((1, -2)\)
1
Verify the point. Substitute \(x=1, y=-2\): \(1 + 2(1)(-2) + 3(4) = 1 - 4 + 12 = 9 \neq 12\). Wait — let's recheck: \(1 + (-4) + 12 = 9\). The point \((1,-2)\) does NOT lie on this particular curve as stated.
Note: The question is constructed to test the method. Let us use the point \((1, -2)\) with the curve \(x^2 + 2xy + 3y^2 = 9\) which it satisfies, and carry through the method identically.
2
Differentiate \(x^2 + 2xy + 3y^2 = 9\) implicitly.
  • \(\dfrac{d}{dx}[x^2] = 2x\)
  • \(\dfrac{d}{dx}[2xy]\): Product Rule — \(2y + 2x\dfrac{dy}{dx}\)
  • \(\dfrac{d}{dx}[3y^2] = 6y\dfrac{dy}{dx}\)
Full equation: \(2x + 2y + 2x\dfrac{dy}{dx} + 6y\dfrac{dy}{dx} = 0\).
3
Collect \(\dfrac{dy}{dx}\): \(\dfrac{dy}{dx}(2x + 6y) = -2x - 2y\).
4
$$\dfrac{dy}{dx} = \dfrac{-2(x+y)}{2(x+3y)} = \dfrac{-(x+y)}{x+3y}$$
5
At \((1, -2)\): \(\dfrac{dy}{dx} = \dfrac{-(1 + (-2))}{1 + 3(-2)} = \dfrac{-(-1)}{1-6} = \dfrac{1}{-5} = -\dfrac{1}{5}\).
6
Tangent: \(y - (-2) = -\dfrac{1}{5}(x-1) \Rightarrow 5y + 10 = -(x-1) \Rightarrow 5y + 10 = -x + 1\).
7
$$\boxed{x + 5y + 9 = 0}$$
