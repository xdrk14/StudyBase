Skill 16

Integrating \(\sin x\), \(\cos x\), and \(\sec^2 x\)

What It Is

Integration is the reverse of differentiation. If you know the derivative of a function, then the integral of that derivative gives you back the original function (plus a constant \(C\), since constants vanish when you differentiate).

Because we know that \(\frac{d}{dx}(\sin x) = \cos x\), it follows immediately that \(\int \cos x \, dx = \sin x + C\). We apply the same reverse-thinking to \(\cos x\) and \(\sec^2 x\).

These three are standard results that you must memorise. Every integral in this skill can be looked up from your memory — no technique or manipulation is needed beyond recognising the form.

When the argument of the trig function is a linear expression of the form \(ax + b\) (e.g. \(\sin(3x+1)\)), you divide your answer by the coefficient of \(x\) — this is the reverse of the chain rule and is covered in more depth in Skill 17 and 18. Here we include it as an extension of the standard results.

Formulae / Rules

Standard Integrals (must memorise):

$$\int \cos x \, dx = \sin x + C$$ $$\int \sin x \, dx = -\cos x + C$$ $$\int \sec^2 x \, dx = \tan x + C$$

With linear argument \(ax + b\) (divide by coefficient \(a\)):

$$\int \cos(ax+b) \, dx = \frac{1}{a}\sin(ax+b) + C$$ $$\int \sin(ax+b) \, dx = -\frac{1}{a}\cos(ax+b) + C$$ $$\int \sec^2(ax+b) \, dx = \frac{1}{a}\tan(ax+b) + C$$
Where to Apply This
  • Whenever you see a bare \(\sin x\), \(\cos x\), or \(\sec^2 x\) with no other complication — apply the standard result directly.
  • Whenever the argument is linear (e.g. \(\cos(3x)\), \(\sin(2x-1)\), \(\sec^2(5x)\)) — apply the result and divide by the inner coefficient.
  • In definite integrals, substitute both limits after integrating (ensure your calculator is in radians).
  • Do not use this skill when the argument is non-linear (e.g. \(\sin(x^2)\)) — that requires substitution.
Worked Examples

Example 1 — Mixed standard integrals (indefinite)

QuestionFind \(\displaystyle\int \left(3\sin x - 2\cos(4x) + 5\sec^2(3x)\right)dx\).
Step 1 — Integrate term by term Each term is integrated separately using the standard results. $$\int 3\sin x \, dx = 3 \cdot (-\cos x) = -3\cos x$$ $$\int -2\cos(4x) \, dx = -2 \cdot \frac{1}{4}\sin(4x) = -\frac{1}{2}\sin(4x)$$ $$\int 5\sec^2(3x) \, dx = 5 \cdot \frac{1}{3}\tan(3x) = \frac{5}{3}\tan(3x)$$
Step 2 — Combine and add constant $$\boxed{-3\cos x - \frac{1}{2}\sin(4x) + \frac{5}{3}\tan(3x) + C}$$

Example 2 — Definite integral

QuestionEvaluate \(\displaystyle\int_{0}^{\pi/4} \left(\cos(2x) + \sin x\right)dx\).
Step 1 — Integrate $$\int \cos(2x)\,dx = \frac{1}{2}\sin(2x), \qquad \int \sin x\,dx = -\cos x$$ So the indefinite integral is \(\dfrac{1}{2}\sin(2x) - \cos x\).
Step 2 — Apply limits (upper minus lower) Upper limit \(x = \dfrac{\pi}{4}\): $$\frac{1}{2}\sin\!\left(\frac{\pi}{2}\right) - \cos\!\left(\frac{\pi}{4}\right) = \frac{1}{2}(1) - \frac{\sqrt{2}}{2} = \frac{1}{2} - \frac{\sqrt{2}}{2}$$ Lower limit \(x = 0\): $$\frac{1}{2}\sin(0) - \cos(0) = 0 - 1 = -1$$
Step 3 — Subtract $$\left(\frac{1}{2} - \frac{\sqrt{2}}{2}\right) - (-1) = \frac{1}{2} - \frac{\sqrt{2}}{2} + 1 = \frac{3}{2} - \frac{\sqrt{2}}{2}$$ $$\boxed{\dfrac{3}{2} - \dfrac{\sqrt{2}}{2}}$$
Practice Questions
  1. Find \(\displaystyle\int \sin(5x)\,dx\).
  2. Find \(\displaystyle\int \cos\!\left(\frac{x}{2}\right)dx\).
  3. Find \(\displaystyle\int \sec^2(7x)\,dx\).
  4. Find \(\displaystyle\int \left(4\cos x - 3\sin(2x)\right)dx\).
  5. Find \(\displaystyle\int \left(\sin(3x) + 2\sec^2(x)\right)dx\).
  6. Evaluate \(\displaystyle\int_{0}^{\pi/6} \cos(3x)\,dx\).
  7. Evaluate \(\displaystyle\int_{0}^{\pi/2} \left(2\sin x + \cos(2x)\right)dx\).
Full Solutions
  1. Using \(\int\sin(ax)\,dx = -\dfrac{1}{a}\cos(ax)+C\) with \(a=5\): $$\boxed{-\frac{1}{5}\cos(5x)+C}$$
  2. Using \(\int\cos(ax)\,dx = \dfrac{1}{a}\sin(ax)+C\) with \(a=\dfrac{1}{2}\): $$\int\cos\!\left(\tfrac{x}{2}\right)dx = \frac{1}{1/2}\sin\!\left(\tfrac{x}{2}\right)+C = 2\sin\!\left(\tfrac{x}{2}\right)+C$$ $$\boxed{2\sin\!\left(\dfrac{x}{2}\right)+C}$$
  3. Using \(\int\sec^2(ax)\,dx = \dfrac{1}{a}\tan(ax)+C\) with \(a=7\): $$\boxed{\frac{1}{7}\tan(7x)+C}$$
  4. Integrate term by term: $$\int 4\cos x\,dx = 4\sin x$$ $$\int -3\sin(2x)\,dx = -3\cdot\left(-\tfrac{1}{2}\cos(2x)\right) = \tfrac{3}{2}\cos(2x)$$ $$\boxed{4\sin x + \frac{3}{2}\cos(2x)+C}$$
  5. $$\int\sin(3x)\,dx = -\tfrac{1}{3}\cos(3x)$$ $$\int 2\sec^2 x\,dx = 2\tan x$$ $$\boxed{-\frac{1}{3}\cos(3x)+2\tan x+C}$$
  6. Integrate: \(\int\cos(3x)\,dx = \dfrac{1}{3}\sin(3x)\). Apply limits: $$\left[\frac{1}{3}\sin(3x)\right]_{0}^{\pi/6} = \frac{1}{3}\sin\!\left(\frac{\pi}{2}\right) - \frac{1}{3}\sin(0) = \frac{1}{3}(1)-0$$ $$\boxed{\dfrac{1}{3}}$$
  7. Integrate: \(\int 2\sin x\,dx = -2\cos x\), \(\int\cos(2x)\,dx = \dfrac{1}{2}\sin(2x)\). $$\left[-2\cos x + \tfrac{1}{2}\sin(2x)\right]_{0}^{\pi/2}$$ Upper: \(-2\cos(\pi/2)+\tfrac{1}{2}\sin(\pi) = 0+0 = 0\)
    Lower: \(-2\cos(0)+\tfrac{1}{2}\sin(0) = -2+0 = -2\) $$0-(-2) = \boxed{2}$$
Skill 17

Integration by Recognition — The Log Rule \(\displaystyle\int\frac{f'(x)}{f(x)}\,dx\)

What It Is

You already know that \(\dfrac{d}{dx}[\ln|f(x)|] = \dfrac{f'(x)}{f(x)}\) by the chain rule. Integration reverses this: if an integrand is a fraction whose numerator is exactly the derivative of the denominator, the answer is \(\ln|f(x)| + C\).

This is often called the "f-prime over f" rule. You are not doing a substitution — you are simply recognising the pattern directly from the integrand.

The absolute value signs \(|\cdot|\) in \(\ln|f(x)|\) are important: they ensure the logarithm is defined even when \(f(x)\) is negative. Always include them in indefinite integrals.

Sometimes the numerator is a multiple of \(f'(x)\). In that case, adjust by factoring out the scalar before applying the rule. If the numerator is a multiple \(k \cdot f'(x)\), simply write \(k\ln|f(x)|+C\).

Formula / Rule
$$\int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)| + C$$

With scalar multiple (general form):

$$\int \frac{k\,f'(x)}{f(x)}\,dx = k\ln|f(x)| + C$$

Key check: Differentiate \(f(x)\) mentally. Does the result match the numerator (up to a constant)? If yes — apply the rule.

Where to Apply This
  • The integrand is a fraction.
  • The denominator is some function \(f(x)\).
  • The numerator is (a constant multiple of) the derivative of the denominator.
  • Common triggers: \(\dfrac{x}{x^2+3}\), \(\dfrac{\cos x}{\sin x}\), \(\dfrac{e^x}{e^x+1}\), \(\dfrac{2x+1}{x^2+x-4}\).
  • Do not use this if the numerator is not proportional to \(f'(x)\) — use partial fractions or substitution instead.
Worked Examples

Example 1 — Polynomial denominator

QuestionFind \(\displaystyle\int \frac{6x^2}{x^3+5}\,dx\).
Step 1 — Identify f(x) Set \(f(x) = x^3 + 5\).
Step 2 — Compute f'(x) $$f'(x) = 3x^2$$
Step 3 — Compare numerator to f'(x) The numerator is \(6x^2\). Observe: \(6x^2 = 2 \cdot 3x^2 = 2 \cdot f'(x)\). So the scalar multiple is \(k = 2\).
Step 4 — Apply the rule $$\int \frac{6x^2}{x^3+5}\,dx = 2\ln|x^3+5| + C$$ $$\boxed{2\ln|x^3+5|+C}$$

Example 2 — Trigonometric denominator

QuestionFind \(\displaystyle\int \frac{3\cos x}{4\sin x}\,dx\).
Step 1 — Factor out the scalar $$\int \frac{3\cos x}{4\sin x}\,dx = \frac{3}{4}\int \frac{\cos x}{\sin x}\,dx$$
Step 2 — Identify f(x) Set \(f(x) = \sin x\). Then \(f'(x) = \cos x\). The numerator of the inner integral is exactly \(f'(x)\).
Step 3 — Apply the rule $$\frac{3}{4}\int \frac{\cos x}{\sin x}\,dx = \frac{3}{4}\ln|\sin x| + C$$ $$\boxed{\dfrac{3}{4}\ln|\sin x|+C}$$
Practice Questions
  1. Find \(\displaystyle\int \frac{2x}{x^2+7}\,dx\).
  2. Find \(\displaystyle\int \frac{5}{5x-3}\,dx\).
  3. Find \(\displaystyle\int \frac{\sin x}{\cos x}\,dx\).
  4. Find \(\displaystyle\int \frac{4x^3+6x}{x^4+3x^2+1}\,dx\).
  5. Find \(\displaystyle\int \frac{e^{2x}}{e^{2x}+4}\,dx\).
  6. Find \(\displaystyle\int \frac{3}{2x+1}\,dx\).
  7. Find \(\displaystyle\int \frac{6x^2-2}{2x^3-2x+5}\,dx\).
Full Solutions
  1. \(f(x)=x^2+7\), \(f'(x)=2x\). Numerator \(= f'(x)\), so \(k=1\). $$\boxed{\ln|x^2+7|+C}$$
  2. \(f(x)=5x-3\), \(f'(x)=5\). Numerator is exactly \(5 = f'(x)\), so: $$\boxed{\ln|5x-3|+C}$$
  3. \(f(x)=\cos x\), \(f'(x)=-\sin x\). Numerator is \(\sin x = -f'(x)\), so \(k=-1\): $$\int\frac{\sin x}{\cos x}\,dx = -\ln|\cos x|+C$$ This can also be written as \(\ln|\sec x|+C\) using log laws. $$\boxed{-\ln|\cos x|+C}$$
  4. \(f(x)=x^4+3x^2+1\), \(f'(x)=4x^3+6x\). Numerator \(=f'(x)\) exactly. $$\boxed{\ln|x^4+3x^2+1|+C}$$
  5. \(f(x)=e^{2x}+4\), \(f'(x)=2e^{2x}\). Numerator is \(e^{2x} = \dfrac{1}{2}f'(x)\), so \(k=\dfrac{1}{2}\): $$\boxed{\frac{1}{2}\ln(e^{2x}+4)+C}$$ (No modulus needed since \(e^{2x}+4 > 0\) always.)
  6. \(f(x)=2x+1\), \(f'(x)=2\). Numerator is \(3 = \dfrac{3}{2}\cdot 2 = \dfrac{3}{2}f'(x)\): $$\boxed{\frac{3}{2}\ln|2x+1|+C}$$
  7. \(f(x)=2x^3-2x+5\), \(f'(x)=6x^2-2\). Numerator \(=f'(x)\) exactly. $$\boxed{\ln|2x^3-2x+5|+C}$$
Skill 18

Integration by Recognition — Reverse Chain Rule (Power Form)

What It Is

The chain rule tells us that \(\dfrac{d}{dx}[f(x)]^n = n[f(x)]^{n-1} \cdot f'(x)\). Reversing this gives us: if the integrand is a power of some function \(f(x)\) multiplied by (a scalar multiple of) its derivative \(f'(x)\), then the integral is \(\dfrac{[f(x)]^{n+1}}{n+1} + C\).

You are recognising the integrand as the output of the chain rule. No formal substitution is written down — you spot the pattern and write the answer directly.

The key check: differentiate the inner function \(f(x)\). Is the result present (up to a constant) in the integrand alongside the power? If yes — apply the reverse chain rule.

This rule also covers expressions of the form \(e^{f(x)} \cdot f'(x)\), which integrate to \(e^{f(x)}+C\).

Formula / Rule

Power form (reverse chain rule):

$$\int [f(x)]^n \cdot f'(x)\,dx = \frac{[f(x)]^{n+1}}{n+1} + C \qquad (n \neq -1)$$

With scalar multiple \(k\):

$$\int k[f(x)]^n \cdot f'(x)\,dx = \frac{k[f(x)]^{n+1}}{n+1} + C$$

Exponential form:

$$\int e^{f(x)} \cdot f'(x)\,dx = e^{f(x)} + C$$

Note: The case \(n = -1\) gives the log rule (Skill 17).

Where to Apply This
  • The integrand is a product of two parts: a power of a function and (a multiple of) that function's derivative.
  • Common triggers: \((x^2+1)^5 \cdot 2x\), \(\sin^3 x \cdot \cos x\), \(e^{x^2} \cdot 2x\).
  • Always check the derivative is present: if it's missing entirely (not just off by a constant), this method cannot be applied — use substitution.
  • If the multiple is off by a constant, adjust: e.g., for \(x(x^2+1)^4\), note \(f'(x)=2x\) but numerator is \(x\); factor out \(\tfrac{1}{2}\) and proceed.
Worked Examples

Example 1 — Polynomial power

QuestionFind \(\displaystyle\int 6x(x^2+3)^4\,dx\).
Step 1 — Identify f(x) and n Let \(f(x) = x^2+3\), so \(f'(x) = 2x\). The power is \(n=4\).
Step 2 — Check the derivative is present The integrand has \(6x\). We need \(f'(x) = 2x\). Note \(6x = 3 \cdot 2x = 3 \cdot f'(x)\). So the scalar is \(k=3\).
Step 3 — Apply reverse chain rule $$\int 6x(x^2+3)^4\,dx = 3 \cdot \frac{(x^2+3)^5}{5} + C = \frac{3(x^2+3)^5}{5} + C$$
Step 4 — Verify by differentiating \(\dfrac{d}{dx}\!\left[\dfrac{3(x^2+3)^5}{5}\right] = \dfrac{3}{5}\cdot 5(x^2+3)^4 \cdot 2x = 6x(x^2+3)^4\). ✓ $$\boxed{\frac{3(x^2+3)^5}{5}+C}$$

Example 2 — Trigonometric power

QuestionFind \(\displaystyle\int \sin^4 x \cos x\,dx\).
Step 1 — Identify f(x) and n Let \(f(x) = \sin x\), so \(f'(x) = \cos x\). The power is \(n=4\).
Step 2 — Check the derivative is present The integrand is \(\sin^4 x \cdot \cos x = [f(x)]^4 \cdot f'(x)\). The derivative is present exactly, so \(k=1\).
Step 3 — Apply reverse chain rule $$\int \sin^4 x \cos x\,dx = \frac{\sin^5 x}{5} + C$$
Step 4 — Verify \(\dfrac{d}{dx}\!\left[\dfrac{\sin^5 x}{5}\right] = \dfrac{5\sin^4 x \cos x}{5} = \sin^4 x\cos x\). ✓ $$\boxed{\frac{\sin^5 x}{5}+C}$$
Practice Questions
  1. Find \(\displaystyle\int 4x(x^2-1)^3\,dx\).
  2. Find \(\displaystyle\int 3\cos x \sin^2 x\,dx\).
  3. Find \(\displaystyle\int (2x+1)(x^2+x)^5\,dx\).
  4. Find \(\displaystyle\int \frac{1}{2}e^{x}\cdot e^{e^x}\,dx\). (Hint: treat \(e^x\) as the inner function.)
  5. Find \(\displaystyle\int 2x e^{x^2}\,dx\).
  6. Find \(\displaystyle\int \cos x(\sin x + 2)^4\,dx\).
  7. Find \(\displaystyle\int \frac{3x^2}{\sqrt{x^3+4}}\,dx\). (Write the square root as a power first.)
Full Solutions
  1. \(f(x)=x^2-1\), \(f'(x)=2x\), \(n=3\). Numerator: \(4x = 2\cdot 2x = 2f'(x)\), so \(k=2\). $$\int 4x(x^2-1)^3\,dx = 2\cdot\frac{(x^2-1)^4}{4}+C = \frac{(x^2-1)^4}{2}+C$$ $$\boxed{\dfrac{(x^2-1)^4}{2}+C}$$
  2. \(f(x)=\sin x\), \(f'(x)=\cos x\), \(n=2\). Numerator: \(3\cos x = 3f'(x)\), so \(k=3\). $$\int 3\cos x\sin^2 x\,dx = 3\cdot\frac{\sin^3 x}{3}+C = \sin^3 x+C$$ $$\boxed{\sin^3 x+C}$$
  3. \(f(x)=x^2+x\), \(f'(x)=2x+1\), \(n=5\). Numerator: \(2x+1 = f'(x)\) exactly, so \(k=1\). $$\int(2x+1)(x^2+x)^5\,dx = \frac{(x^2+x)^6}{6}+C$$ $$\boxed{\dfrac{(x^2+x)^6}{6}+C}$$
  4. Let \(f(x)=e^x\), \(f'(x)=e^x\). The integrand is \(\tfrac{1}{2}e^x\cdot e^{e^x} = \tfrac{1}{2}f'(x)\cdot e^{f(x)}\). Exponential form with \(k=\tfrac{1}{2}\): $$\int \tfrac{1}{2}e^{e^x}\cdot e^x\,dx = \frac{1}{2}e^{e^x}+C$$ $$\boxed{\dfrac{1}{2}e^{e^x}+C}$$
  5. \(f(x)=x^2\), \(f'(x)=2x\). Numerator: \(2x = f'(x)\) exactly. Exponential form: $$\boxed{e^{x^2}+C}$$
  6. \(f(x)=\sin x+2\), \(f'(x)=\cos x\), \(n=4\). Numerator: \(\cos x = f'(x)\) exactly. $$\int\cos x(\sin x+2)^4\,dx = \frac{(\sin x+2)^5}{5}+C$$ $$\boxed{\dfrac{(\sin x+2)^5}{5}+C}$$
  7. Rewrite: \(\dfrac{3x^2}{\sqrt{x^3+4}} = 3x^2(x^3+4)^{-1/2}\). Let \(f(x)=x^3+4\), \(f'(x)=3x^2\), \(n=-\tfrac{1}{2}\). Numerator: \(3x^2=f'(x)\) exactly. $$\int 3x^2(x^3+4)^{-1/2}\,dx = \frac{(x^3+4)^{1/2}}{1/2}+C = 2\sqrt{x^3+4}+C$$ $$\boxed{2\sqrt{x^3+4}+C}$$
Skill 19

Integration by Substitution

What It Is

Integration by substitution is the formal version of the reverse chain rule. You introduce a new variable \(u\) to replace a complicated inner function, turning a difficult integral into a simpler one in terms of \(u\).

The key idea is that you not only replace the function inside the integrand, but also replace \(dx\) with \(du\) using the relationship \(\dfrac{du}{dx} = u'\), which gives \(dx = \dfrac{du}{u'}\). After substitution, the integral must be entirely in terms of \(u\) — no \(x\) should remain.

For indefinite integrals, once you have integrated in terms of \(u\), you substitute back \(u = f(x)\) at the end to give your answer in terms of \(x\).

For definite integrals, you must convert the \(x\)-limits into \(u\)-limits using your substitution, and then you never need to substitute back. This is the most common source of errors — always change the limits.

Formula / Rule

General substitution rule:

$$\int f(g(x))\cdot g'(x)\,dx = \int f(u)\,du \quad \text{where } u = g(x)$$

Procedure (indefinite):

1. Choose \(u = g(x)\).   2. Compute \(\dfrac{du}{dx}\) and rearrange to find \(dx\) in terms of \(du\).   3. Substitute everything.   4. Integrate.   5. Replace \(u\) with \(g(x)\).

Procedure (definite):

Same steps 1–4, but convert limits: if \(x=a\), compute \(u=g(a)\); if \(x=b\), compute \(u=g(b)\). Do not substitute back.

Where to Apply This
  • The integrand is a composite function (a function inside a function) and the reverse chain rule cannot be applied directly because the derivative is missing or the expression is too complex to recognise.
  • A good choice for \(u\) is almost always the inner function — the expression inside brackets, under a square root, in the exponent, or in the denominator.
  • After substitution, the integral must be purely in terms of \(u\). If \(x\) remains and cannot be eliminated, your substitution choice was wrong — try again.
  • Common choices: \(u = x^2+1\), \(u = \sin x\), \(u = e^x+3\), \(u = \sqrt{x}\) (for which \(x = u^2\)).
Worked Examples

Example 1 — Indefinite integral

QuestionFind \(\displaystyle\int x\sqrt{x^2+5}\,dx\).
Step 1 — Choose substitution The inner function inside the square root is \(x^2+5\). Let \(u = x^2+5\).
Step 2 — Differentiate to find dx $$\frac{du}{dx} = 2x \implies du = 2x\,dx \implies x\,dx = \frac{du}{2}$$
Step 3 — Substitute everything Replace \(x^2+5\) with \(u\) and \(x\,dx\) with \(\dfrac{du}{2}\): $$\int x\sqrt{x^2+5}\,dx = \int \sqrt{u}\cdot\frac{du}{2} = \frac{1}{2}\int u^{1/2}\,du$$
Step 4 — Integrate in terms of u $$\frac{1}{2}\cdot\frac{u^{3/2}}{3/2} = \frac{1}{2}\cdot\frac{2u^{3/2}}{3} = \frac{u^{3/2}}{3}$$
Step 5 — Substitute back u = x²+5 $$\boxed{\frac{(x^2+5)^{3/2}}{3}+C}$$

Example 2 — Definite integral

QuestionEvaluate \(\displaystyle\int_{0}^{1} \frac{2x}{(x^2+1)^3}\,dx\).
Step 1 — Choose substitution Let \(u = x^2+1\).
Step 2 — Differentiate $$\frac{du}{dx} = 2x \implies du = 2x\,dx$$
Step 3 — Convert limits When \(x=0\): \(u = 0^2+1 = 1\).
When \(x=1\): \(u = 1^2+1 = 2\).
New limits: \(u=1\) to \(u=2\).
Step 4 — Substitute $$\int_{0}^{1}\frac{2x}{(x^2+1)^3}\,dx = \int_{1}^{2}\frac{du}{u^3} = \int_{1}^{2} u^{-3}\,du$$
Step 5 — Integrate and apply limits $$\int_{1}^{2}u^{-3}\,du = \left[\frac{u^{-2}}{-2}\right]_{1}^{2} = \left[-\frac{1}{2u^2}\right]_{1}^{2}$$ $$= \left(-\frac{1}{2(4)}\right) - \left(-\frac{1}{2(1)}\right) = -\frac{1}{8}+\frac{1}{2} = \frac{3}{8}$$ $$\boxed{\dfrac{3}{8}}$$
Practice Questions
  1. Find \(\displaystyle\int 3x^2(x^3+2)^4\,dx\). Use \(u=x^3+2\).
  2. Find \(\displaystyle\int \cos x\, e^{\sin x}\,dx\). Use \(u=\sin x\).
  3. Find \(\displaystyle\int \frac{x}{\sqrt{1-x^2}}\,dx\). Use \(u=1-x^2\).
  4. Evaluate \(\displaystyle\int_{0}^{1} 2x(x^2+3)^2\,dx\). Use \(u=x^2+3\).
  5. Evaluate \(\displaystyle\int_{0}^{\pi/2} \sin x\cos^3 x\,dx\). Use \(u=\cos x\).
  6. Find \(\displaystyle\int x\sqrt{2x+1}\,dx\). Use \(u=2x+1\).
  7. Find \(\displaystyle\int \frac{e^x}{(e^x+1)^2}\,dx\). Use \(u=e^x+1\).
Full Solutions
  1. \(u=x^3+2\), \(du=3x^2\,dx\). $$\int (u)^4\,du = \frac{u^5}{5}+C = \frac{(x^3+2)^5}{5}+C$$ $$\boxed{\dfrac{(x^3+2)^5}{5}+C}$$
  2. \(u=\sin x\), \(du=\cos x\,dx\). $$\int e^u\,du = e^u+C = e^{\sin x}+C$$ $$\boxed{e^{\sin x}+C}$$
  3. \(u=1-x^2\), \(du=-2x\,dx\implies x\,dx = -\tfrac{1}{2}du\). $$\int\frac{-\frac{1}{2}\,du}{\sqrt{u}} = -\frac{1}{2}\int u^{-1/2}\,du = -\frac{1}{2}\cdot 2u^{1/2}+C = -\sqrt{1-x^2}+C$$ $$\boxed{-\sqrt{1-x^2}+C}$$
  4. \(u=x^2+3\), \(du=2x\,dx\). Limits: \(x=0\Rightarrow u=3\); \(x=1\Rightarrow u=4\). $$\int_3^4 u^2\,du = \left[\frac{u^3}{3}\right]_3^4 = \frac{64}{3}-\frac{27}{3} = \frac{37}{3}$$ $$\boxed{\dfrac{37}{3}}$$
  5. \(u=\cos x\), \(du=-\sin x\,dx\). Limits: \(x=0\Rightarrow u=1\); \(x=\tfrac{\pi}{2}\Rightarrow u=0\). $$\int_1^0 -u^3\,du = \int_0^1 u^3\,du = \left[\frac{u^4}{4}\right]_0^1 = \frac{1}{4}$$ $$\boxed{\dfrac{1}{4}}$$
  6. \(u=2x+1\), so \(x=\dfrac{u-1}{2}\), \(dx=\dfrac{du}{2}\). $$\int \frac{u-1}{2}\cdot\sqrt{u}\cdot\frac{du}{2} = \frac{1}{4}\int(u-1)u^{1/2}\,du = \frac{1}{4}\int\!\left(u^{3/2}-u^{1/2}\right)du$$ $$= \frac{1}{4}\left[\frac{2u^{5/2}}{5}-\frac{2u^{3/2}}{3}\right]+C = \frac{u^{5/2}}{10}-\frac{u^{3/2}}{6}+C$$ Substitute back \(u=2x+1\): $$\boxed{\dfrac{(2x+1)^{5/2}}{10}-\dfrac{(2x+1)^{3/2}}{6}+C}$$
  7. \(u=e^x+1\), \(du=e^x\,dx\). $$\int\frac{du}{u^2} = \int u^{-2}\,du = -u^{-1}+C = -\frac{1}{e^x+1}+C$$ $$\boxed{-\dfrac{1}{e^x+1}+C}$$
Skill 20

Integration by Parts

What It Is

Integration by parts is used when the integrand is a product of two different types of function (e.g. a polynomial times an exponential, or a polynomial times \(\ln x\)), and no simpler technique works.

The formula comes from reversing the product rule of differentiation. Recall: \(\dfrac{d}{dx}[uv] = u\dfrac{dv}{dx} + v\dfrac{du}{dx}\). Integrating both sides and rearranging gives the parts formula.

You must decide which part to call \(u\) (which you will differentiate) and which to call \(\dfrac{dv}{dx}\) (which you will integrate). A reliable guide is the acronym LIATE: choose \(u\) from whichever comes first — Logarithm, Inverse trig, Algebraic (polynomial), Trigonometric, Exponential.

Sometimes you need to apply the formula twice. And sometimes applying it twice returns you to the original integral, which you can then solve algebraically (treating it as an equation).

Formula / Rule

Integration by Parts formula:

$$\int u\,\frac{dv}{dx}\,dx = uv - \int v\,\frac{du}{dx}\,dx$$

Equivalently (using shorthand):

$$\int u\,dv = uv - \int v\,du$$

LIATE priority for choosing \(u\):

Logarithm > Inverse trig > Algebra (polynomial) > Trig > Exponential

Special case — integrating \(\ln x\) alone:
Write \(\ln x = \ln x \cdot 1\), let \(u = \ln x\) and \(\dfrac{dv}{dx}=1\).

Where to Apply This
  • The integrand is a product of two functions from different categories (e.g. \(x e^x\), \(x^2\cos x\), \(x\ln x\)).
  • The integrand is \(\ln x\) or \(\arctan x\) alone — write it as \(\ln x \cdot 1\) and integrate \(1\).
  • Try substitution first — use parts only when substitution fails or is not possible.
  • If after applying parts you get the same integral as the original (with trig × exponential products), collect it on one side and divide.
  • For definite integrals: apply the formula and substitute limits into the \([uv]\) term, then integrate the remaining integral with limits.
Worked Examples

Example 1 — Polynomial × Exponential

QuestionFind \(\displaystyle\int x e^{2x}\,dx\).
Step 1 — Choose u and dv/dx LIATE: Algebra before Exponential. So let: $$u = x \implies \frac{du}{dx} = 1$$ $$\frac{dv}{dx} = e^{2x} \implies v = \frac{e^{2x}}{2}$$
Step 2 — Apply the formula $$\int x e^{2x}\,dx = uv - \int v\,\frac{du}{dx}\,dx = x\cdot\frac{e^{2x}}{2} - \int \frac{e^{2x}}{2}\cdot 1\,dx$$
Step 3 — Integrate the remaining term $$= \frac{x e^{2x}}{2} - \frac{1}{2}\cdot\frac{e^{2x}}{2} + C = \frac{x e^{2x}}{2} - \frac{e^{2x}}{4} + C$$
Step 4 — Final answer (factorise) $$\boxed{\frac{e^{2x}}{4}(2x-1)+C}$$

Example 2 — Logarithm alone

QuestionFind \(\displaystyle\int x^2\ln x\,dx\).
Step 1 — Choose u and dv/dx LIATE: Logarithm before Algebra. So let: $$u = \ln x \implies \frac{du}{dx} = \frac{1}{x}$$ $$\frac{dv}{dx} = x^2 \implies v = \frac{x^3}{3}$$
Step 2 — Apply the formula $$\int x^2\ln x\,dx = \frac{x^3}{3}\ln x - \int \frac{x^3}{3}\cdot\frac{1}{x}\,dx = \frac{x^3}{3}\ln x - \int\frac{x^2}{3}\,dx$$
Step 3 — Integrate the remaining term $$= \frac{x^3}{3}\ln x - \frac{x^3}{9} + C$$
Step 4 — Final answer (factorise) $$\boxed{\frac{x^3}{9}(3\ln x - 1)+C}$$
Practice Questions
  1. Find \(\displaystyle\int x\cos x\,dx\).
  2. Find \(\displaystyle\int x e^{x}\,dx\).
  3. Find \(\displaystyle\int \ln x\,dx\). (Hint: write as \(\ln x \cdot 1\).)
  4. Find \(\displaystyle\int x^2 e^{x}\,dx\). (Apply parts twice.)
  5. Find \(\displaystyle\int x\sin(2x)\,dx\).
  6. Evaluate \(\displaystyle\int_{1}^{e} x\ln x\,dx\).
  7. Find \(\displaystyle\int e^{x}\sin x\,dx\). (Apply parts twice, then solve algebraically.)
Full Solutions
  1. Let \(u=x\), \(\dfrac{dv}{dx}=\cos x\), so \(\dfrac{du}{dx}=1\), \(v=\sin x\). $$\int x\cos x\,dx = x\sin x - \int\sin x\,dx = x\sin x + \cos x + C$$ $$\boxed{x\sin x+\cos x+C}$$
  2. Let \(u=x\), \(\dfrac{dv}{dx}=e^x\), so \(\dfrac{du}{dx}=1\), \(v=e^x\). $$\int xe^x\,dx = xe^x - \int e^x\,dx = xe^x - e^x + C = e^x(x-1)+C$$ $$\boxed{e^x(x-1)+C}$$
  3. Write \(\ln x = \ln x\cdot 1\). Let \(u=\ln x\), \(\dfrac{dv}{dx}=1\), so \(\dfrac{du}{dx}=\dfrac{1}{x}\), \(v=x\). $$\int\ln x\,dx = x\ln x - \int x\cdot\frac{1}{x}\,dx = x\ln x - \int 1\,dx = x\ln x - x + C$$ $$\boxed{x\ln x - x + C}$$
  4. First application: Let \(u=x^2\), \(\dfrac{dv}{dx}=e^x\), so \(\dfrac{du}{dx}=2x\), \(v=e^x\). $$\int x^2 e^x\,dx = x^2 e^x - \int 2xe^x\,dx$$ Second application on \(\int 2xe^x\,dx\): Let \(u=2x\), \(\dfrac{dv}{dx}=e^x\), so \(\dfrac{du}{dx}=2\), \(v=e^x\). $$\int 2xe^x\,dx = 2xe^x - \int 2e^x\,dx = 2xe^x - 2e^x$$ Combine: $$\int x^2 e^x\,dx = x^2 e^x - (2xe^x - 2e^x) + C = x^2 e^x - 2xe^x + 2e^x + C$$ $$\boxed{e^x(x^2-2x+2)+C}$$
  5. Let \(u=x\), \(\dfrac{dv}{dx}=\sin(2x)\), so \(\dfrac{du}{dx}=1\), \(v=-\dfrac{1}{2}\cos(2x)\). $$\int x\sin(2x)\,dx = -\frac{x\cos(2x)}{2} - \int\!\left(-\frac{\cos(2x)}{2}\right)dx = -\frac{x\cos(2x)}{2}+\frac{1}{2}\int\cos(2x)\,dx$$ $$= -\frac{x\cos(2x)}{2} + \frac{\sin(2x)}{4} + C$$ $$\boxed{-\dfrac{x\cos(2x)}{2}+\dfrac{\sin(2x)}{4}+C}$$
  6. Let \(u=\ln x\), \(\dfrac{dv}{dx}=x\), so \(\dfrac{du}{dx}=\dfrac{1}{x}\), \(v=\dfrac{x^2}{2}\). $$\int_1^e x\ln x\,dx = \left[\frac{x^2\ln x}{2}\right]_1^e - \int_1^e\frac{x^2}{2}\cdot\frac{1}{x}\,dx = \left[\frac{x^2\ln x}{2}\right]_1^e - \int_1^e\frac{x}{2}\,dx$$ $$= \left[\frac{x^2\ln x}{2}\right]_1^e - \left[\frac{x^2}{4}\right]_1^e$$ Evaluate \(\left[\dfrac{x^2\ln x}{2}\right]_1^e = \dfrac{e^2\cdot 1}{2} - \dfrac{1\cdot 0}{2} = \dfrac{e^2}{2}\). Evaluate \(\left[\dfrac{x^2}{4}\right]_1^e = \dfrac{e^2}{4} - \dfrac{1}{4}\). $$= \frac{e^2}{2} - \left(\frac{e^2}{4}-\frac{1}{4}\right) = \frac{e^2}{2}-\frac{e^2}{4}+\frac{1}{4} = \frac{e^2}{4}+\frac{1}{4}$$ $$\boxed{\dfrac{e^2+1}{4}}$$
  7. First application: Let \(u=e^x\), \(\dfrac{dv}{dx}=\sin x\), so \(\dfrac{du}{dx}=e^x\), \(v=-\cos x\). $$I = \int e^x\sin x\,dx = -e^x\cos x + \int e^x\cos x\,dx$$ Second application on \(\int e^x\cos x\,dx\): Let \(u=e^x\), \(\dfrac{dv}{dx}=\cos x\), so \(\dfrac{du}{dx}=e^x\), \(v=\sin x\). $$\int e^x\cos x\,dx = e^x\sin x - \int e^x\sin x\,dx = e^x\sin x - I$$ Substitute back: $$I = -e^x\cos x + e^x\sin x - I$$ $$2I = e^x(\sin x - \cos x)$$ $$I = \frac{e^x(\sin x-\cos x)}{2}+C$$ $$\boxed{\dfrac{e^x(\sin x - \cos x)}{2}+C}$$
