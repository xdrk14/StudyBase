Skill 31

The \(R\sin(x+\alpha)\) Form (Harmonic Form)

What It Is

Any expression of the form \(a\sin x + b\cos x\), where \(a\) and \(b\) are constants, can always be rewritten as a single sinusoidal function \(R\sin(x + \alpha)\). This is called the harmonic form or R-form. The reason this is useful is that a single sine (or cosine) function is much easier to work with: you can immediately read off its maximum value, minimum value, and the angle at which these occur. This technique is essential for solving equations of the form \(a\sin x + b\cos x = c\), and for finding stationary points of such expressions without calculus.

The Formula / Rule

The core identity is:

$$a\sin x + b\cos x \equiv R\sin(x + \alpha)$$

where:

$$R = \sqrt{a^2 + b^2}, \qquad \tan\alpha = \frac{b}{a}, \quad R > 0,\ 0 < \alpha < \frac{\pi}{2}$$

Expanding the right-hand side using the addition formula \(\sin(x+\alpha) = \sin x\cos\alpha + \cos x\sin\alpha\):

$$R\sin(x+\alpha) = R\cos\alpha\,\sin x + R\sin\alpha\,\cos x$$

Comparing coefficients: \(R\cos\alpha = a\) and \(R\sin\alpha = b\). These two equations give \(R\) and \(\alpha\).

Also valid:

$$a\sin x + b\cos x \equiv R\cos(x - \beta), \quad R = \sqrt{a^2+b^2},\quad \tan\beta = \frac{a}{b}$$

Maximum value of \(R\sin(x+\alpha)\) is \(\boldsymbol{R}\), occurring when \(\sin(x+\alpha)=1\).
Minimum value is \(\boldsymbol{-R}\), occurring when \(\sin(x+\alpha)=-1\).

Where to Apply It

  • Solving equations of the form \(a\sin x + b\cos x = c\) over a given interval.
  • Finding the maximum or minimum value of \(a\sin x + b\cos x\) and the \(x\)-values at which they occur.
  • Simplifying expressions before integration.
  • Modelling periodic phenomena (sound waves, oscillations) where a combined sine and cosine must be written as a single wave.

Worked Examples

Example 1 — Write \(3\sin x + 4\cos x\) in the form \(R\sin(x+\alpha)\), giving \(\alpha\) in radians to 3 d.p.

Step 1: Identify \(a\) and \(b\).
Compare \(a\sin x + b\cos x\) with \(3\sin x + 4\cos x\): \(a = 3\), \(b = 4\).
Step 2: Find \(R\).
$$R = \sqrt{a^2 + b^2} = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$
Step 3: Find \(\alpha\).
$$\tan\alpha = \frac{b}{a} = \frac{4}{3}$$ $$\alpha = \arctan\!\left(\frac{4}{3}\right) = 0.927 \text{ rad (3 d.p.)}$$
Step 4: Write the answer.
$$\boxed{3\sin x + 4\cos x \equiv 5\sin(x + 0.927)}$$
Verification: Expand \(5\sin(x+0.927) = 5(\sin x\cos 0.927 + \cos x\sin 0.927)\).
\(\cos(0.927)\approx 0.6 = \tfrac{3}{5}\) and \(\sin(0.927)\approx 0.8 = \tfrac{4}{5}\).
So \(5\cdot\tfrac{3}{5}\sin x + 5\cdot\tfrac{4}{5}\cos x = 3\sin x + 4\cos x\). ✓

Example 2 — Solve \(3\sin x + 4\cos x = 2.5\) for \(0 \leq x \leq 2\pi\), giving answers in radians to 3 d.p.

Step 1: Use the result from Example 1.
\(3\sin x + 4\cos x \equiv 5\sin(x + 0.927)\). The equation becomes: $$5\sin(x + 0.927) = 2.5$$
Step 2: Isolate the sine function.
$$\sin(x + 0.927) = \frac{2.5}{5} = 0.5$$
Step 3: Adjust the interval for the compound angle.
Since \(0 \leq x \leq 2\pi\), we have \(0.927 \leq x + 0.927 \leq 2\pi + 0.927\), i.e., \(0.927 \leq x+0.927 \leq 7.210\).
Step 4: Find the principal value.
$$x + 0.927 = \arcsin(0.5) = \frac{\pi}{6} \approx 0.524$$ This is outside the interval \([0.927, 7.210]\), so we use the supplementary angle: \(\pi - 0.524 = 2.618\).
Step 5: Find all solutions in the adjusted interval.
\(\sin\theta = 0.5\) in \([0.927, 7.210]\):
— \(\theta = 2.618\) (in interval ✓)
— \(\theta = 2\pi + 0.524 = 6.807\) (in interval ✓)
Step 6: Solve for \(x\).
$$x = 2.618 - 0.927 = 1.691 \quad \text{and} \quad x = 6.807 - 0.927 = 5.880$$ $$\boxed{x \approx 1.691 \text{ rad} \quad \text{or} \quad x \approx 5.880 \text{ rad}}$$

Skill 32

Secant, Cosecant and Cotangent — Definitions and Graphs

What It Is

The three reciprocal trigonometric functions are \(\sec x\), \(\text{cosec}\, x\) (sometimes written \(\csc x\)), and \(\cot x\). Each is simply the reciprocal (i.e., one divided by) of one of the standard trig functions. A helpful memory trick: Sec goes with Cosine, Cosec goes with Sine, Cot goes with Tangent — notice each starts with the opposite letter. These functions arise naturally when solving equations, simplifying identities, and differentiating or integrating certain expressions. They have vertical asymptotes wherever the denominator function equals zero, and their graphs consist of repeated separate branches.

The Definitions and Key Identities

Definitions:

$$\sec x = \frac{1}{\cos x}, \qquad \text{cosec}\,x = \frac{1}{\sin x}, \qquad \cot x = \frac{\cos x}{\sin x} = \frac{1}{\tan x}$$

Pythagorean Identities (derived from \(\sin^2 x + \cos^2 x = 1\)):

$$1 + \tan^2 x \equiv \sec^2 x \qquad (\text{divide } \sin^2 x + \cos^2 x = 1 \text{ by } \cos^2 x)$$ $$1 + \cot^2 x \equiv \text{cosec}^2\, x \qquad (\text{divide by } \sin^2 x)$$

Graph properties:

  • \(\sec x\): Period \(2\pi\). Asymptotes at \(x = \frac{\pi}{2} + n\pi\). Range: \(|\sec x| \geq 1\), i.e., \((-\infty,-1]\cup[1,\infty)\).
  • \(\text{cosec}\,x\): Period \(2\pi\). Asymptotes at \(x = n\pi\). Range: \((-\infty,-1]\cup[1,\infty)\).
  • \(\cot x\): Period \(\pi\). Asymptotes at \(x = n\pi\). Range: all real numbers.

Where to Apply It

  • Solving equations involving squared trig terms: use \(\sec^2 x = 1 + \tan^2 x\) or \(\text{cosec}^2 x = 1 + \cot^2 x\) to convert a mixed equation into a single trig ratio.
  • Proving identities that involve reciprocal trig functions.
  • Differentiation: \(\frac{d}{dx}(\tan x) = \sec^2 x\) and \(\frac{d}{dx}(\cot x) = -\text{cosec}^2 x\).
  • Integration: \(\int \sec^2 x\,dx = \tan x + c\) and \(\int \text{cosec}^2 x\,dx = -\cot x + c\).

Worked Examples

Example 1 — Solve \(2\sec^2 x - 3\tan x - 4 = 0\) for \(0° \leq x \leq 360°\).

Step 1: Convert using the identity \(\sec^2 x = 1 + \tan^2 x\).
$$2(1 + \tan^2 x) - 3\tan x - 4 = 0$$ $$2 + 2\tan^2 x - 3\tan x - 4 = 0$$ $$2\tan^2 x - 3\tan x - 2 = 0$$
Step 2: Solve the quadratic. Let \(u = \tan x\).
$$2u^2 - 3u - 2 = 0$$ $$(2u + 1)(u - 2) = 0$$ $$\tan x = -\frac{1}{2} \quad \text{or} \quad \tan x = 2$$
Step 3: Solve \(\tan x = -\frac{1}{2}\) in \([0°, 360°]\).
Calculator gives \(\arctan(-0.5) = -26.57°\). In the range: \(180° - 26.57° = 153.43°\) and \(360° - 26.57° = 333.43°\).
Step 4: Solve \(\tan x = 2\) in \([0°, 360°]\).
Calculator gives \(63.43°\) and \(63.43° + 180° = 243.43°\).
Final answer: $$\boxed{x = 63.4°,\ 153.4°,\ 243.4°,\ 333.4°}$$

Example 2 — Prove that \(\dfrac{\sec^2 x}{\tan x} \equiv 2\,\text{cosec}\,2x\).

Step 1: Start with the left-hand side (LHS).
$$\text{LHS} = \frac{\sec^2 x}{\tan x} = \frac{\dfrac{1}{\cos^2 x}}{\dfrac{\sin x}{\cos x}} = \frac{1}{\cos^2 x} \cdot \frac{\cos x}{\sin x} = \frac{1}{\cos x \sin x}$$
Step 2: Use the double angle formula \(\sin 2x = 2\sin x\cos x\), so \(\sin x \cos x = \frac{1}{2}\sin 2x\).
$$\frac{1}{\cos x\sin x} = \frac{1}{\frac{1}{2}\sin 2x} = \frac{2}{\sin 2x} = 2\,\text{cosec}\,2x$$
Step 3: Conclude.
$$\boxed{\frac{\sec^2 x}{\tan x} \equiv 2\,\text{cosec}\,2x \quad \text{✓}}$$

Skill 33

Inverse Trigonometric Functions: \(\arcsin\), \(\arccos\), \(\arctan\)

What It Is

The inverse trigonometric functions undo the action of the standard trig functions. For example, \(\arcsin(0.5) = \frac{\pi}{6}\) because \(\sin\!\left(\frac{\pi}{6}\right) = 0.5\). The key complication is that sine, cosine, and tangent are not one-to-one functions — a single output value can come from many input angles. To define a proper inverse function (which must give exactly one output per input), we must restrict the domain of the original trig function. These restricted domains are fixed and must be memorised. The inverse functions are written \(\arcsin\), \(\arccos\), \(\arctan\) (or equivalently \(\sin^{-1}\), \(\cos^{-1}\), \(\tan^{-1}\)).

Domains, Ranges and Graphs

\(y = \arcsin x\):

$$\text{Domain: } -1 \leq x \leq 1 \qquad \text{Range: } -\frac{\pi}{2} \leq y \leq \frac{\pi}{2}$$

\(y = \arccos x\):

$$\text{Domain: } -1 \leq x \leq 1 \qquad \text{Range: } 0 \leq y \leq \pi$$

\(y = \arctan x\):

$$\text{Domain: } x \in \mathbb{R} \qquad \text{Range: } -\frac{\pi}{2} < y < \frac{\pi}{2}$$

(Note: the range for \(\arctan\) is an open interval — it never actually reaches \(\pm\frac{\pi}{2}\).)

Derivatives (for use in differentiation topics):

$$\frac{d}{dx}(\arcsin x) = \frac{1}{\sqrt{1-x^2}}, \qquad \frac{d}{dx}(\arccos x) = -\frac{1}{\sqrt{1-x^2}}, \qquad \frac{d}{dx}(\arctan x) = \frac{1}{1+x^2}$$

Graph property: Each inverse trig graph is the reflection of the corresponding restricted trig function in the line \(y = x\).

Where to Apply It

  • Evaluating exact values: e.g., \(\arcsin\!\left(\frac{\sqrt{3}}{2}\right) = \frac{\pi}{3}\).
  • Solving trig equations when you need the principal value (the unique answer in the restricted range).
  • Integration: the derivatives above lead to standard integrals, e.g., \(\displaystyle\int \frac{1}{\sqrt{1-x^2}}\,dx = \arcsin x + c\).
  • Whenever the range of arcsin/arccos/arctan must be carefully stated — exam questions often ask for the range explicitly.

Worked Examples

Example 1 — Find the exact value of \(\cos\!\left(\arcsin\!\left(\frac{3}{5}\right)\right)\).

Step 1: Let \(\theta = \arcsin\!\left(\frac{3}{5}\right)\), so \(\sin\theta = \frac{3}{5}\).
Since \(\arcsin\) has range \(\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\), we know \(\theta\) is in the first or fourth quadrant, and \(\cos\theta \geq 0\).
Step 2: Use the Pythagorean identity.
$$\cos^2\theta = 1 - \sin^2\theta = 1 - \frac{9}{25} = \frac{16}{25}$$ $$\cos\theta = \frac{4}{5} \quad (\text{positive because } \theta \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right])$$
Step 3: State the answer.
$$\boxed{\cos\!\left(\arcsin\!\left(\frac{3}{5}\right)\right) = \frac{4}{5}}$$

Example 2 — Solve \(2\arctan x = \arctan\!\left(\frac{3}{4}\right)\) and find \(x\) exactly.

Step 1: Isolate one arctan.
$$\arctan x = \frac{1}{2}\arctan\!\left(\frac{3}{4}\right)$$ Let \(\phi = \arctan\!\left(\frac{3}{4}\right)\), so \(\tan\phi = \frac{3}{4}\).
Step 2: Use the half-angle tangent formula. We want \(\tan\!\left(\frac{\phi}{2}\right)\).
We know: \(\tan\phi = \dfrac{2t}{1-t^2}\) where \(t = \tan\!\left(\frac{\phi}{2}\right)\). $$\frac{3}{4} = \frac{2t}{1 - t^2} \implies 3(1 - t^2) = 8t \implies 3t^2 + 8t - 3 = 0$$
Step 3: Solve the quadratic.
$$(3t - 1)(t + 3) = 0 \implies t = \frac{1}{3} \text{ or } t = -3$$ Since \(\phi = \arctan(3/4)\) is a small positive angle, \(\phi/2\) is also small and positive, so \(t = \frac{1}{3}\).
Final answer: $$x = \tan\!\left(\frac{\phi}{2}\right) = \frac{1}{3}$$ $$\boxed{x = \frac{1}{3}}$$

  • Solution to Q4

    \(\sin\!\left(\frac{7\pi}{6}\right) = \sin\!\left(\pi + \frac{\pi}{6}\right) = -\sin\!\left(\frac{\pi}{6}\right) = -\frac{1}{2}\).
    Now apply \(\arcsin\): \(\arcsin\!\left(-\frac{1}{2}\right) = -\frac{\pi}{6}\).
    The answer is not \(\frac{7\pi}{6}\) because \(\frac{7\pi}{6}\) is outside the range of \(\arcsin\), which is \(\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\).
    $$\boxed{\arcsin\!\left(\sin\!\left(\frac{7\pi}{6}\right)\right) = -\frac{\pi}{6}}$$

  • Solution to Q5

    Apply \(\tan\) to both sides:
    $$2x - 1 = \tan\!\left(\frac{\pi}{4}\right) = 1$$
    $$2x = 2 \implies x = 1$$
    $$\boxed{x = 1}$$

  • Solution to Q6

    Domain: \(\arcsin(x-1)\) requires \(-1 \leq x - 1 \leq 1\), i.e., \(0 \leq x \leq 2\).
    Range of \(\arcsin(x-1)\): \(-\frac{\pi}{2} \leq \arcsin(x-1) \leq \frac{\pi}{2}\).
    Multiply by 2: \(-\pi \leq 2\arcsin(x-1) \leq \pi\).
    Add \(\frac{\pi}{2}\): \(-\frac{\pi}{2} \leq f(x) \leq \frac{3\pi}{2}\).
    $$\boxed{\text{Domain: } 0 \leq x \leq 2, \quad \text{Range: } -\frac{\pi}{2} \leq f(x) \leq \frac{3\pi}{2}}$$

  • Solution to Q7

    Let \(\alpha = \arcsin x\). Then \(\sin\alpha = x\) and \(\alpha \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\).
    We want to show \(\arccos x = \frac{\pi}{2} - \alpha\), i.e., that \(\cos\!\left(\frac{\pi}{2} - \alpha\right) = x\).
    $$\cos\!\left(\frac{\pi}{2} - \alpha\right) = \sin\alpha = x \quad \checkmark$$
    Also, since \(\alpha \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\), we have \(\frac{\pi}{2} - \alpha \in [0, \pi]\), which is exactly the range of \(\arccos\). So \(\frac{\pi}{2} - \alpha = \arccos x\).
    Therefore \(\arcsin x + \arccos x = \alpha + \frac{\pi}{2} - \alpha = \frac{\pi}{2}\).
    $$\boxed{\arcsin x + \arccos x = \frac{\pi}{2} \quad \text{for } -1 \leq x \leq 1. \quad \checkmark}$$
Skill 34

Trigonometric Identities for Integration

What It Is

Many trigonometric functions cannot be integrated directly using the standard results. The key technique is to use a known identity to rewrite the integrand into a form that can be integrated. The most important transformations are: using the double-angle formula to handle \(\sin^2 x\) and \(\cos^2 x\); using the product-to-sum formulas to handle products like \(\sin mx\cos nx\); and using the Pythagorean identity \(\sin^2 x + \cos^2 x = 1\) to reduce mixed powers. The goal is always to convert the integrand into a sum of terms involving \(\sin(kx)\), \(\cos(kx)\), or constants, which are all straightforward to integrate.

Key Identity Substitutions for Integration

For \(\cos^2 x\) and \(\sin^2 x\) — use double angle:

$$\cos^2 x = \frac{1 + \cos 2x}{2}, \qquad \sin^2 x = \frac{1 - \cos 2x}{2}$$

For \(\sin^3 x\) or \(\cos^3 x\) — split off one factor:

$$\sin^3 x = \sin x(1 - \cos^2 x), \qquad \cos^3 x = \cos x(1 - \sin^2 x)$$

For products \(\sin A\cos B\), etc. — product-to-sum:

$$\sin A\cos B = \tfrac{1}{2}\left[\sin(A+B) + \sin(A-B)\right]$$ $$\cos A\cos B = \tfrac{1}{2}\left[\cos(A-B) + \cos(A+B)\right]$$ $$\sin A\sin B = \tfrac{1}{2}\left[\cos(A-B) - \cos(A+B)\right]$$

For \(\tan^2 x\) and \(\cot^2 x\) — use Pythagorean:

$$\tan^2 x = \sec^2 x - 1, \qquad \cot^2 x = \text{cosec}^2\, x - 1$$

Standard results to know:

$$\int \sin x\,dx = -\cos x + c, \quad \int \cos x\,dx = \sin x + c, \quad \int \sec^2 x\,dx = \tan x + c, \quad \int \text{cosec}^2 x\,dx = -\cot x + c$$

Where to Apply It

  • Whenever you see \(\sin^2 x\), \(\cos^2 x\), or \(\sin^2(ax)\) in an integrand — use the double angle formula immediately.
  • Whenever you see \(\sin^3 x\) or \(\cos^3 x\) — split off one power.
  • Whenever you see a product of two different trig functions, e.g., \(\sin 3x\cos x\) — use product-to-sum.
  • Whenever you see \(\tan^2 x\) — replace with \(\sec^2 x - 1\).
  • Definite integrals: always convert limits to radians if working with trig functions.

Worked Examples

Example 1 — Find \(\displaystyle\int \sin^2 x\cos^2 x\,dx\).

Step 1: Use the identity \(\sin 2x = 2\sin x\cos x\), so \(\sin x\cos x = \frac{1}{2}\sin 2x\).
$$\sin^2 x\cos^2 x = (\sin x\cos x)^2 = \left(\frac{1}{2}\sin 2x\right)^2 = \frac{1}{4}\sin^2 2x$$
Step 2: Apply the double angle formula to \(\sin^2 2x\).
$$\sin^2 2x = \frac{1 - \cos 4x}{2}$$
Step 3: Substitute and integrate.
$$\int \frac{1}{4}\cdot\frac{1 - \cos 4x}{2}\,dx = \frac{1}{8}\int (1 - \cos 4x)\,dx$$ $$= \frac{1}{8}\left(x - \frac{\sin 4x}{4}\right) + c$$
Final answer: $$\boxed{\int \sin^2 x\cos^2 x\,dx = \frac{x}{8} - \frac{\sin 4x}{32} + c}$$

Example 2 — Evaluate \(\displaystyle\int_0^{\pi/2} \cos^3 x\,dx\).

Step 1: Split off one cosine factor.
$$\cos^3 x = \cos x \cdot \cos^2 x = \cos x(1 - \sin^2 x)$$
Step 2: Expand.
$$\cos^3 x = \cos x - \sin^2 x\cos x$$
Step 3: Integrate each term. For \(\int \sin^2 x\cos x\,dx\), use the substitution \(u = \sin x\), \(du = \cos x\,dx\).
$$\int \sin^2 x\cos x\,dx = \int u^2\,du = \frac{u^3}{3} = \frac{\sin^3 x}{3}$$
Step 4: Combine and apply limits.
$$\int_0^{\pi/2}\cos^3 x\,dx = \left[\sin x - \frac{\sin^3 x}{3}\right]_0^{\pi/2}$$ $$= \left(1 - \frac{1}{3}\right) - (0 - 0) = \frac{2}{3}$$
Final answer: $$\boxed{\int_0^{\pi/2}\cos^3 x\,dx = \frac{2}{3}}$$

Practice Questions

  1. Find \(\displaystyle\int \cos^2 x\,dx\).
  2. Find \(\displaystyle\int \sin^2 3x\,dx\).
  3. Find \(\displaystyle\int \sin 5x\cos 3x\,dx\).
  4. Find \(\displaystyle\int \tan^2 x\,dx\).
  5. Evaluate \(\displaystyle\int_0^{\pi} \sin^2\!\left(\frac{x}{2}\right)\,dx\).
  6. Find \(\displaystyle\int \sin^3 x\,dx\).
  7. Evaluate \(\displaystyle\int_0^{\pi/4} \cos 2x\cos 4x\,dx\).

Full Solutions

  • Solution to Q1

    Use \(\cos^2 x = \dfrac{1 + \cos 2x}{2}\):
    $$\int \frac{1 + \cos 2x}{2}\,dx = \frac{1}{2}\left(x + \frac{\sin 2x}{2}\right) + c$$
    $$\boxed{\int \cos^2 x\,dx = \frac{x}{2} + \frac{\sin 2x}{4} + c}$$

  • Solution to Q2

    Use \(\sin^2 3x = \dfrac{1 - \cos 6x}{2}\):
    $$\int \frac{1 - \cos 6x}{2}\,dx = \frac{1}{2}\left(x - \frac{\sin 6x}{6}\right) + c$$
    $$\boxed{\int \sin^2 3x\,dx = \frac{x}{2} - \frac{\sin 6x}{12} + c}$$

  • Solution to Q3

    Product-to-sum: \(\sin 5x\cos 3x = \frac{1}{2}[\sin 8x + \sin 2x]\).
    $$\int \frac{1}{2}(\sin 8x + \sin 2x)\,dx = \frac{1}{2}\left(-\frac{\cos 8x}{8} - \frac{\cos 2x}{2}\right) + c$$
    $$\boxed{\int \sin 5x\cos 3x\,dx = -\frac{\cos 8x}{16} - \frac{\cos 2x}{4} + c}$$

  • Solution to Q4

    Replace \(\tan^2 x = \sec^2 x - 1\):
    $$\int (\sec^2 x - 1)\,dx = \tan x - x + c$$
    $$\boxed{\int \tan^2 x\,dx = \tan x - x + c}$$

  • Solution to Q5

    Use \(\sin^2\!\left(\frac{x}{2}\right) = \dfrac{1 - \cos x}{2}\):
    $$\int_0^{\pi} \frac{1 - \cos x}{2}\,dx = \frac{1}{2}\Big[x - \sin x\Big]_0^{\pi}$$
    $$= \frac{1}{2}\big[(\pi - 0) - (0 - 0)\big] = \frac{\pi}{2}$$
    $$\boxed{\int_0^{\pi} \sin^2\!\left(\frac{x}{2}\right)\,dx = \frac{\pi}{2}}$$

  • Solution to Q6

    Write \(\sin^3 x = \sin x(1 - \cos^2 x) = \sin x - \sin x\cos^2 x\).
    For \(\int \sin x\cos^2 x\,dx\): let \(u = \cos x\), \(du = -\sin x\,dx\), giving \(-\int u^2\,du = -\frac{u^3}{3} = -\frac{\cos^3 x}{3}\).
    $$\int \sin^3 x\,dx = -\cos x - \left(-\frac{\cos^3 x}{3}\right) + c = -\cos x + \frac{\cos^3 x}{3} + c$$
    $$\boxed{\int \sin^3 x\,dx = -\cos x + \frac{\cos^3 x}{3} + c}$$

  • Solution to Q7

    Product-to-sum: \(\cos 2x\cos 4x = \frac{1}{2}[\cos 2x + \cos 6x]\) (using \(A - B = -2x,\ A + B = 6x\)).
    $$\int_0^{\pi/4} \frac{1}{2}(\cos 2x + \cos 6x)\,dx = \frac{1}{2}\left[\frac{\sin 2x}{2} + \frac{\sin 6x}{6}\right]_0^{\pi/4}$$
    At \(x = \frac{\pi}{4}\): \(\sin\!\left(\frac{\pi}{2}\right) = 1\), \(\sin\!\left(\frac{3\pi}{2}\right) = -1\).
    $$= \frac{1}{2}\left(\frac{1}{2} + \frac{-1}{6}\right) - 0 = \frac{1}{2}\cdot\frac{2}{6} = \frac{1}{2}\cdot\frac{1}{3} = \frac{1}{6}$$
    $$\boxed{\int_0^{\pi/4}\cos 2x\cos 4x\,dx = \frac{1}{6}}$$
Skill 35

Parametric Equations → Cartesian Conversion

What It Is

A curve can be described parametrically by giving both \(x\) and \(y\) as separate functions of a third variable called the parameter, usually \(t\) or \(\theta\). For example, \(x = t^2,\ y = 2t\) describes a parabola. The Cartesian equation is a single equation in \(x\) and \(y\) only (no parameter). Converting between the two forms requires you to eliminate the parameter — either by rearranging one equation for the parameter and substituting into the other, or by using a trigonometric identity (most commonly \(\sin^2\theta + \cos^2\theta = 1\)) to combine two parametric equations into one. The domain of the Cartesian equation is always determined by the range of the \(x\)-parametric function over the allowed parameter values.

The Methods and Key Rules

Method 1 — Algebraic elimination:

Given \(x = f(t)\) and \(y = g(t)\), rearrange one equation to get \(t\) in terms of \(x\) (or \(y\)), then substitute into the other.

$$x = f(t) \implies t = f^{-1}(x) \implies y = g\!\left(f^{-1}(x)\right)$$

Method 2 — Trigonometric identity:

If the parametric equations involve \(\sin\theta\) and \(\cos\theta\), rearrange to isolate them, then use:

$$\sin^2\theta + \cos^2\theta = 1$$

Common scenarios:

$$x = r\cos\theta + a,\quad y = r\sin\theta + b \implies (x-a)^2 + (y-b)^2 = r^2 \quad \text{(circle)}$$ $$x = a\cos\theta,\quad y = b\sin\theta \implies \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad \text{(ellipse)}$$ $$x = a\sec\theta,\quad y = b\tan\theta \implies \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \quad \text{(hyperbola, using } \sec^2\theta - \tan^2\theta = 1)$$

Domain rule: The domain of the Cartesian equation equals the range of \(x = f(t)\) over all allowed values of the parameter \(t\).

Where to Apply It

  • Whenever you need to identify the type of curve (circle, ellipse, parabola, hyperbola) from its parametric form.
  • When solving for intersection points of a parametric curve with a line or another curve.
  • When finding the Cartesian equation to differentiate or integrate a parametric curve indirectly.
  • Exam questions often say: "Find the Cartesian equation of the curve, stating any restrictions on \(x\)."
  • If you see \(\sin\theta\) and \(\cos\theta\) together — always try \(\sin^2\theta + \cos^2\theta = 1\) first.

Worked Examples

Example 1 — A curve has parametric equations \(x = t^2 - 1\), \(y = \dfrac{2}{t}\), \(t \neq 0\). Find the Cartesian equation.

Step 1: Rearrange the simpler equation for the parameter \(t\).
From \(y = \dfrac{2}{t}\): $$t = \frac{2}{y}$$
Step 2: Substitute into the other parametric equation.
$$x = t^2 - 1 = \left(\frac{2}{y}\right)^2 - 1 = \frac{4}{y^2} - 1$$
Step 3: Rearrange into standard form.
$$x + 1 = \frac{4}{y^2}$$ $$y^2(x + 1) = 4$$ $$y^2 = \frac{4}{x + 1}$$
Step 4: Determine the domain.
From \(x = t^2 - 1\): since \(t^2 \geq 0\), we have \(x \geq -1\). Also \(t \neq 0\), so \(t^2 > 0\), hence \(x > -1\).
Final answer: $$\boxed{y^2 = \frac{4}{x+1}, \quad x > -1}$$

Example 2 — A curve has parametric equations \(x = 3 + 2\cos\theta\), \(y = -1 + 4\sin\theta\), \(0 \leq \theta \leq 2\pi\). Find the Cartesian equation and name the curve.

Step 1: Isolate \(\cos\theta\) and \(\sin\theta\).
$$\cos\theta = \frac{x - 3}{2}, \qquad \sin\theta = \frac{y + 1}{4}$$
Step 2: Apply the identity \(\sin^2\theta + \cos^2\theta = 1\).
$$\left(\frac{y+1}{4}\right)^2 + \left(\frac{x-3}{2}\right)^2 = 1$$
Step 3: Write in standard form.
$$\frac{(x-3)^2}{4} + \frac{(y+1)^2}{16} = 1$$
Step 4: Identify the curve.
This is an ellipse with centre \((3, -1)\), horizontal semi-axis \(a = 2\), vertical semi-axis \(b = 4\).
Final answer: $$\boxed{\frac{(x-3)^2}{4} + \frac{(y+1)^2}{16} = 1 \quad \text{(an ellipse with centre }(3,-1)\text{)}}$$

Practice Questions

  1. Find the Cartesian equation of the curve \(x = 3t - 1\), \(y = t^2 + 2\). State any restriction on \(x\) if the domain of \(t\) is all real numbers.
  2. Find the Cartesian equation of the curve \(x = 2\cos\theta\), \(y = 2\sin\theta\), \(0 \leq \theta \leq 2\pi\). Name the curve.
  3. Find the Cartesian equation of the curve \(x = \cos\theta + 1\), \(y = \sin\theta - 2\), \(0 \leq \theta < 2\pi\). Give the centre and radius.
  4. Find the Cartesian equation of the curve \(x = e^t\), \(y = e^{2t} - 3\). State the restriction on \(x\).
  5. A curve is defined by \(x = \sec\theta\), \(y = \tan\theta\). Show that the Cartesian equation is \(x^2 - y^2 = 1\).
  6. A curve has parametric equations \(x = 4t^2\), \(y = 8t\). Show that the Cartesian equation is \(y^2 = 16x\) and state the restriction on \(x\).
  7. Find the Cartesian equation of the curve \(x = 1 + \sin^2\theta\), \(y = 2\cos^2\theta - 1\). (Hint: use \(\sin^2\theta + \cos^2\theta = 1\).)

Full Solutions

  • Solution to Q1

    From \(x = 3t - 1\): \(t = \dfrac{x+1}{3}\).
    Substitute into \(y = t^2 + 2\): $$y = \left(\frac{x+1}{3}\right)^2 + 2 = \frac{(x+1)^2}{9} + 2$$
    Since \(t\in\mathbb{R}\), \(x\) can be any real value.
    $$\boxed{y = \frac{(x+1)^2}{9} + 2, \quad x \in \mathbb{R}}$$

  • Solution to Q2

    \(\cos\theta = \dfrac{x}{2}\), \(\sin\theta = \dfrac{y}{2}\).
    Apply identity: \(\left(\frac{x}{2}\right)^2 + \left(\frac{y}{2}\right)^2 = 1\).
    $$x^2 + y^2 = 4$$
    $$\boxed{x^2 + y^2 = 4 \quad \text{(a circle, centre }(0,0)\text{, radius }2)}$$

  • Solution to Q3

    \(\cos\theta = x - 1\), \(\sin\theta = y + 2\).
    Apply identity: \((x-1)^2 + (y+2)^2 = 1\).
    $$\boxed{(x-1)^2 + (y+2)^2 = 1 \quad \text{(circle, centre }(1,-2)\text{, radius }1)}$$

  • Solution to Q4

    From \(x = e^t\): \(e^t = x\), so \(e^{2t} = x^2\).
    Substitute: \(y = x^2 - 3\).
    Since \(e^t > 0\) for all real \(t\), we need \(x > 0\).
    $$\boxed{y = x^2 - 3, \quad x > 0}$$

  • Solution to Q5

    From \(x = \sec\theta\): \(\sec\theta = x\). From \(y = \tan\theta\): \(\tan\theta = y\).
    Use the identity \(\sec^2\theta - \tan^2\theta = 1\):
    $$x^2 - y^2 = \sec^2\theta - \tan^2\theta = 1$$
    $$\boxed{x^2 - y^2 = 1 \quad \checkmark}$$

  • Solution to Q6

    From \(y = 8t\): \(t = \dfrac{y}{8}\).
    Substitute into \(x = 4t^2\): \(x = 4\left(\dfrac{y}{8}\right)^2 = 4\cdot\dfrac{y^2}{64} = \dfrac{y^2}{16}\).
    So \(y^2 = 16x\). Since \(x = 4t^2 \geq 0\), the restriction is \(x \geq 0\).
    $$\boxed{y^2 = 16x, \quad x \geq 0 \quad \checkmark}$$

  • Solution to Q7

    From \(x = 1 + \sin^2\theta\): \(\sin^2\theta = x - 1\).
    Since \(\sin^2\theta + \cos^2\theta = 1\): \(\cos^2\theta = 1 - (x-1) = 2 - x\).
    From \(y = 2\cos^2\theta - 1\): \(\cos^2\theta = \dfrac{y+1}{2}\).
    Set the two expressions for \(\cos^2\theta\) equal: $$\frac{y+1}{2} = 2 - x \implies y + 1 = 4 - 2x \implies y = 3 - 2x$$
    Domain: \(\sin^2\theta \in [0,1]\) so \(x - 1 \in [0,1]\) giving \(x \in [1,2]\). Also \(\cos^2\theta = 2 - x \in [0,1]\) giving \(x \in [1,2]\).
    $$\boxed{y = 3 - 2x, \quad 1 \leq x \leq 2}$$
