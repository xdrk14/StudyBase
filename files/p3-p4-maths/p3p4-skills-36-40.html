Curve Sketching from Parametric Equations
What It Is

Parametric equations define a curve by expressing both \(x\) and \(y\) separately as functions of a third variable called the parameter, usually \(t\). Instead of having one equation linking \(x\) and \(y\), you have two: \(x = f(t)\) and \(y = g(t)\). To sketch the curve, you choose several values of \(t\), compute the corresponding \((x, y)\) coordinates, plot those points, and join them with a smooth curve. You must always pay attention to the domain of \(t\) — the allowed values — because this determines which part of the full curve is actually drawn. The direction of travel along the curve (as \(t\) increases) should also be noted.

Formula / Rule

Parametric curve:   \(x = f(t)\),   \(y = g(t)\),   for \(t\) in some domain.

Method:

  1. Choose a set of \(t\)-values spanning the entire given domain.
  2. Calculate \(x\) and \(y\) for each \(t\).
  3. Record results in a table.
  4. Plot the \((x, y)\) pairs on axes.
  5. Join with a smooth curve; mark endpoints if the domain is restricted.
  6. Indicate direction of travel with an arrow as \(t\) increases.

Key intersections to find:

  • \(y\)-axis: set \(x = 0\) and solve for \(t\), then find \(y\).
  • \(x\)-axis: set \(y = 0\) and solve for \(t\), then find \(x\).
Where to Apply It

Use this skill whenever a curve is given in parametric form and you are asked to sketch it (rather than find a Cartesian equation). Common in questions about ellipses, parabolas, and trigonometric curves. Also use it to identify key features: turning points (where \(\frac{dy}{dt}=0\) with \(\frac{dx}{dt}\neq 0\)), cusps, and asymptotic behaviour.

Worked Examples
Example 1 — Polynomial parametric curve

Sketch the curve with parametric equations \(x = t^2 - 1\), \(y = t^3 - t\), for \(-2 \le t \le 2\).

Step 1 — Build the table of values

Evaluate at \(t = -2,\,-1,\,0,\,1,\,2\):

\(t = -2\!:\; x = 4-1 = 3,\; y = -8-(-2) = -6\)  → point \((3,-6)\)

\(t = -1\!:\; x = 1-1 = 0,\; y = -1-(-1) = 0\)  → point \((0,0)\)

\(t = 0\!:\; x = 0-1 = -1,\; y = 0-0 = 0\)  → point \((-1,0)\)

\(t = 1\!:\; x = 1-1 = 0,\; y = 1-1 = 0\)  → point \((0,0)\)

\(t = 2\!:\; x = 4-1 = 3,\; y = 8-2 = 6\)  → point \((3,6)\)

Step 2 — Identify axis crossings

\(y = 0 \Rightarrow t^3 - t = t(t^2-1) = 0 \Rightarrow t = 0, \pm 1\).

At \(t=0\): \(x=-1\). At \(t=\pm 1\): \(x=0\). So the curve crosses the \(x\)-axis at \((-1,0)\) and \((0,0)\) (twice).

\(x = 0 \Rightarrow t^2=1 \Rightarrow t=\pm1\), giving \(y=0\). The curve passes through the origin twice.

Step 3 — Find stationary points on the curve

\(\frac{dy}{dt} = 3t^2 - 1 = 0 \Rightarrow t = \pm\frac{1}{\sqrt{3}}\)

At \(t = \frac{1}{\sqrt{3}}\!:\; x = \frac{1}{3}-1 = -\frac{2}{3},\; y = \frac{1}{3\sqrt{3}} - \frac{1}{\sqrt{3}} = -\frac{2}{3\sqrt{3}} \approx -0.385\)

At \(t = -\frac{1}{\sqrt{3}}\!:\; x = -\frac{2}{3},\; y \approx +0.385\)

These are the local maximum and minimum on the left portion of the curve.

Step 4 — Sketch description

The curve starts at \((3,-6)\) for \(t=-2\), passes through the origin twice (creating a loop around \((-1,0)\)), and ends at \((3,6)\) for \(t=2\). The direction arrow goes upward as \(t\) increases. The curve is symmetric about the \(x\)-axis since replacing \(t\) by \(-t\) negates \(y\) but keeps \(x\) the same.

Example 2 — Trigonometric parametric curve (ellipse)

Sketch the curve with \(x = 3\cos t\), \(y = 2\sin t\), for \(0 \le t \le 2\pi\).

Step 1 — Build the table

\(t=0\!:\; x=3,\; y=0\)

\(t=\tfrac{\pi}{2}\!:\; x=0,\; y=2\)

\(t=\pi\!:\; x=-3,\; y=0\)

\(t=\tfrac{3\pi}{2}\!:\; x=0,\; y=-2\)

\(t=2\pi\!:\; x=3,\; y=0\) (returns to start)

Step 2 — Find the Cartesian form to confirm shape

From \(x = 3\cos t \Rightarrow \cos t = \frac{x}{3}\) and \(y = 2\sin t \Rightarrow \sin t = \frac{y}{2}\).

Use \(\cos^2 t + \sin^2 t = 1\):

$$\frac{x^2}{9} + \frac{y^2}{4} = 1$$

This is an ellipse centred at the origin, with semi-axes \(a = 3\) (horizontal) and \(b = 2\) (vertical).

Step 3 — Key features

Rightmost point: \((3, 0)\). Leftmost: \((-3, 0)\). Top: \((0, 2)\). Bottom: \((0, -2)\).

The curve is traced anticlockwise as \(t\) increases from \(0\) to \(2\pi\).

Practice Questions
  1. A curve has parametric equations \(x = t + 1\), \(y = t^2 - 4\), \(-3 \le t \le 3\). Find the coordinates of the point where the curve crosses the \(x\)-axis and where it crosses the \(y\)-axis.
  2. Sketch the curve \(x = 2t\), \(y = \frac{4}{t}\), \(t > 0\). State the Cartesian equation.
  3. A curve is given by \(x = \cos t\), \(y = \sin 2t\), \(0 \le t \le 2\pi\). Find all points where the curve crosses the \(x\)-axis (set \(y=0\)) and give their coordinates.
  4. Show that the curve \(x = 4\cos t\), \(y = 3\sin t\) is an ellipse, and state the coordinates of the four vertices.
  5. A curve has \(x = t^2\), \(y = t^3\), \(-2 \le t \le 2\). Find: (a) the coordinates of the endpoints; (b) the value of \(t\) at the origin.
  6. The curve \(x = 1 + 3t\), \(y = 2 - t^2\), \(-2 \le t \le 2\). Find the maximum value of \(y\) on this curve and the corresponding \(x\)-coordinate.
  7. A curve is defined by \(x = e^t - 1\), \(y = e^{2t}\), \(t \ge 0\). Express \(y\) in terms of \(x\) and state the domain of the Cartesian equation.
Fully Worked Solutions
Q1 — x-axis and y-axis crossings

Crosses x-axis when \(y = 0\): \(t^2 - 4 = 0 \Rightarrow t = \pm 2\).

At \(t = 2\!:\; x = 3\). At \(t = -2\!:\; x = -1\). So the curve crosses the \(x\)-axis at \(\boxed{(3,0) \text{ and } (-1,0)}\).

Crosses y-axis when \(x = 0\): \(t + 1 = 0 \Rightarrow t = -1\).

At \(t = -1\!:\; y = 1 - 4 = -3\). So the \(y\)-intercept is \(\boxed{(0,-3)}\).

Q2 — Curve and Cartesian equation

From \(x = 2t \Rightarrow t = \frac{x}{2}\). Substitute into \(y = \frac{4}{t}\):

$$y = \frac{4}{\frac{x}{2}} = \frac{8}{x}$$

Since \(t > 0\), we have \(x > 0\). The Cartesian equation is \(\boxed{y = \dfrac{8}{x},\; x > 0}\). This is a rectangular hyperbola in the first quadrant.

Key points: \(t=1 \Rightarrow (2,4)\); \(t=2 \Rightarrow (4,2)\); as \(t\to\infty\), \(x\to\infty, y\to 0\); as \(t\to 0^+\), \(x\to 0, y\to\infty\).

Q3 — Crossings on x-axis

Set \(y = 0\): \(\sin 2t = 0 \Rightarrow 2t = 0, \pi, 2\pi, 3\pi, 4\pi \Rightarrow t = 0, \tfrac{\pi}{2}, \pi, \tfrac{3\pi}{2}, 2\pi\).

Corresponding \(x\)-values: \(x = \cos t\).

\(t=0 \Rightarrow x=1\); \(t=\tfrac{\pi}{2} \Rightarrow x=0\); \(t=\pi \Rightarrow x=-1\); \(t=\tfrac{3\pi}{2} \Rightarrow x=0\); \(t=2\pi \Rightarrow x=1\).

Distinct points: \(\boxed{(1,0),\;(0,0),\;(-1,0)}\). The origin is visited twice (\(t=\tfrac{\pi}{2}\) and \(t=\tfrac{3\pi}{2}\)).

Q4 — Ellipse verification and vertices

\(\cos t = \frac{x}{4}\), \(\sin t = \frac{y}{3}\). Apply \(\cos^2 t + \sin^2 t = 1\):

$$\frac{x^2}{16} + \frac{y^2}{9} = 1$$

This is the standard ellipse equation, confirming it is an ellipse. The four vertices are at the intercepts with the axes:

\(\boxed{(4,0),\;(-4,0),\;(0,3),\;(0,-3)}\).

Q5 — Endpoints and origin

(a) At \(t = 2\!:\; x = 4, y = 8\). At \(t = -2\!:\; x = 4, y = -8\). Endpoints: \(\boxed{(4,8) \text{ and } (4,-8)}\).

(b) The origin \((0,0)\) requires \(t^2 = 0\) and \(t^3 = 0\), both satisfied by \(\boxed{t = 0}\).

Note: The curve \(x = t^2 \ge 0\) always, so the curve lies entirely in \(x \ge 0\). The curve has a cusp at the origin.

Q6 — Maximum y-value

\(y = 2 - t^2\) is maximised when \(t^2\) is minimised, i.e., \(t = 0\).

Maximum \(y\) value: \(y = 2 - 0 = 2\).

At \(t = 0\!:\; x = 1 + 3(0) = 1\).

Maximum point: \(\boxed{(1,\, 2)}\).

Q7 — Cartesian equation and domain

From \(x = e^t - 1 \Rightarrow e^t = x + 1 \Rightarrow t = \ln(x+1)\).

\(y = e^{2t} = (e^t)^2 = (x+1)^2\).

Since \(t \ge 0\), we need \(e^t \ge 1\), so \(x + 1 \ge 1\), giving \(x \ge 0\).

Cartesian equation: \(\boxed{y = (x+1)^2,\;\; x \ge 0}\).

Vector Equation of a Line in 3D
What It Is

In three dimensions, a straight line is not described by a single Cartesian equation — instead, we use a vector equation. The idea is simple: to reach any point on the line, you start at a known point on the line and then move by any multiple of a direction vector (a vector parallel to the line). The scalar \(\lambda\) (lambda) acts as a "dial" — different values of \(\lambda\) give different points on the line. A line in 3D is uniquely determined by one point on it and one direction vector parallel to it. You can also write the line in Cartesian (symmetric) form by eliminating \(\lambda\).

Formula / Rule

Vector equation of a line:

$$\mathbf{r} = \mathbf{a} + \lambda\,\mathbf{d}$$

where:

  • \(\mathbf{r}\) is the position vector of a general point on the line
  • \(\mathbf{a}\) is the position vector of a known point on the line
  • \(\mathbf{d}\) is the direction vector (any vector parallel to the line)
  • \(\lambda \in \mathbb{R}\) is the scalar parameter

Finding the direction vector from two points:

If the line passes through \(A\) and \(B\), then \(\mathbf{d} = \overrightarrow{AB} = \mathbf{b} - \mathbf{a}\).

Cartesian (symmetric) form (when \(d_1, d_2, d_3 \ne 0\)):

$$\frac{x - a_1}{d_1} = \frac{y - a_2}{d_2} = \frac{z - a_3}{d_3} = \lambda$$

where \(\mathbf{a} = \begin{pmatrix}a_1\\a_2\\a_3\end{pmatrix}\) and \(\mathbf{d} = \begin{pmatrix}d_1\\d_2\\d_3\end{pmatrix}\).

Where to Apply It

Use whenever you need to write the equation of a 3D line (given a point and direction, or given two points), check whether a point lies on a line, find where a specific point occurs on a line, or set up equations to test for intersection (Skill 39). Also use to find the direction vector before computing dot products for angles (Skill 38).

Worked Examples
Example 1 — Line through one point with a given direction

Write the vector equation of the line passing through the point \(A(2, -1, 4)\) with direction vector \(\mathbf{d} = \begin{pmatrix}3\\0\\-2\end{pmatrix}\).

Step 1 — Identify \(\mathbf{a}\)

The position vector of \(A\) is \(\mathbf{a} = \begin{pmatrix}2\\-1\\4\end{pmatrix}\).

Step 2 — Write the vector equation

$$\mathbf{r} = \begin{pmatrix}2\\-1\\4\end{pmatrix} + \lambda\begin{pmatrix}3\\0\\-2\end{pmatrix}, \quad \lambda \in \mathbb{R}$$

Or equivalently in column form: \(\mathbf{r} = \begin{pmatrix}2+3\lambda\\-1\\4-2\lambda\end{pmatrix}\).

Step 3 — Write the Cartesian form

From the \(y\)-component: \(y = -1\) (constant, since \(d_2 = 0\), the line is parallel to the \(xz\)-plane at height \(y = -1\)).

From \(x\) and \(z\):

$$\frac{x-2}{3} = \frac{z-4}{-2}, \quad y = -1$$

Example 2 — Line through two given points

Find the vector equation of the line passing through \(P(1, 3, -2)\) and \(Q(4, 1, 0)\).

Step 1 — Find the direction vector

$$\overrightarrow{PQ} = \mathbf{q} - \mathbf{p} = \begin{pmatrix}4-1\\1-3\\0-(-2)\end{pmatrix} = \begin{pmatrix}3\\-2\\2\end{pmatrix}$$

Step 2 — Choose a point (use \(P\))

\(\mathbf{a} = \begin{pmatrix}1\\3\\-2\end{pmatrix}\)

Step 3 — Write the equation

$$\mathbf{r} = \begin{pmatrix}1\\3\\-2\end{pmatrix} + \lambda\begin{pmatrix}3\\-2\\2\end{pmatrix}, \quad \lambda \in \mathbb{R}$$

Step 4 — Verify: check that \(Q\) lies on the line

Set \(\mathbf{r} = \begin{pmatrix}4\\1\\0\end{pmatrix}\) and solve: \(1 + 3\lambda = 4 \Rightarrow \lambda = 1\).

Check \(y\): \(3 + (-2)(1) = 1\,\checkmark\). Check \(z\): \(-2 + 2(1) = 0\,\checkmark\). Verified.

Practice Questions
  1. Write the vector equation of the line passing through \(A(5, 0, -3)\) with direction \(\mathbf{d} = \begin{pmatrix}1\\-1\\2\end{pmatrix}\).
  2. Find the vector equation of the line through \(P(2, 4, 1)\) and \(Q(6, 2, 5)\).
  3. Determine whether the point \(R(8, -2, 5)\) lies on the line \(\mathbf{r} = \begin{pmatrix}2\\0\\1\end{pmatrix} + \lambda\begin{pmatrix}3\\-1\\2\end{pmatrix}\).
  4. The line \(L\) passes through \(A(1,2,3)\) and \(B(3,3,1)\). Find the coordinates of the point on \(L\) where \(x = 5\).
  5. Write the Cartesian (symmetric) form of the line \(\mathbf{r} = \begin{pmatrix}4\\-1\\2\end{pmatrix} + \lambda\begin{pmatrix}2\\3\\-1\end{pmatrix}\).
  6. Find the position vector of the point on the line \(\mathbf{r} = \begin{pmatrix}0\\1\\-2\end{pmatrix} + \lambda\begin{pmatrix}2\\-1\\3\end{pmatrix}\) when \(\lambda = -2\).
  7. A line passes through \((1,-1,0)\) and is parallel to the vector \(2\mathbf{i} - 3\mathbf{j} + \mathbf{k}\). Find the coordinates of two distinct points on the line (other than the given point).
Fully Worked Solutions
Q1

$$\boxed{\mathbf{r} = \begin{pmatrix}5\\0\\-3\end{pmatrix} + \lambda\begin{pmatrix}1\\-1\\2\end{pmatrix}}$$

Q2 — Direction from \(P\) to \(Q\)

$$\overrightarrow{PQ} = \begin{pmatrix}6-2\\2-4\\5-1\end{pmatrix} = \begin{pmatrix}4\\-2\\4\end{pmatrix}$$

We can simplify by dividing by 2: \(\mathbf{d} = \begin{pmatrix}2\\-1\\2\end{pmatrix}\) (any scalar multiple is valid).

$$\boxed{\mathbf{r} = \begin{pmatrix}2\\4\\1\end{pmatrix} + \lambda\begin{pmatrix}2\\-1\\2\end{pmatrix}}$$

Q3 — Does R lie on the line?

Set \(\begin{pmatrix}2+3\lambda\\-\lambda\\1+2\lambda\end{pmatrix} = \begin{pmatrix}8\\-2\\5\end{pmatrix}\).

From \(x\): \(2 + 3\lambda = 8 \Rightarrow \lambda = 2\).

Check \(y\): \(-\lambda = -2 \Rightarrow \lambda = 2\,\checkmark\).

Check \(z\): \(1 + 2(2) = 5\,\checkmark\).

\(\boxed{R \text{ lies on the line}}\) (at \(\lambda = 2\)).

Q4 — Point on line where \(x=5\)

Direction: \(\overrightarrow{AB} = \begin{pmatrix}2\\1\\-2\end{pmatrix}\). Line: \(\mathbf{r} = \begin{pmatrix}1\\2\\3\end{pmatrix} + \lambda\begin{pmatrix}2\\1\\-2\end{pmatrix}\).

Set \(x = 1 + 2\lambda = 5 \Rightarrow \lambda = 2\).

\(y = 2 + 1(2) = 4\). \(z = 3 + (-2)(2) = -1\).

Point: \(\boxed{(5,\,4,\,-1)}\).

Q5 — Cartesian form

\(\mathbf{a} = (4,-1,2)\), \(\mathbf{d} = (2,3,-1)\).

$$\boxed{\frac{x-4}{2} = \frac{y+1}{3} = \frac{z-2}{-1}}$$

Q6 — Point at \(\lambda = -2\)

\(\mathbf{r} = \begin{pmatrix}0+2(-2)\\1+(-1)(-2)\\-2+3(-2)\end{pmatrix} = \begin{pmatrix}-4\\3\\-8\end{pmatrix}\).

$$\boxed{\mathbf{r} = -4\mathbf{i} + 3\mathbf{j} - 8\mathbf{k}}$$

Q7 — Two points on the line

Line: \(\mathbf{r} = \begin{pmatrix}1\\-1\\0\end{pmatrix} + \lambda\begin{pmatrix}2\\-3\\1\end{pmatrix}\).

At \(\lambda = 1\!:\; (1+2,\,-1-3,\,0+1) = (3,-4,1)\).

At \(\lambda = -1\!:\; (1-2,\,-1+3,\,0-1) = (-1,2,-1)\).

Two points: \(\boxed{(3,-4,1) \text{ and } (-1,2,-1)}\).

Dot Product and Angle Between Vectors
What It Is

The scalar (dot) product of two vectors produces a single number (a scalar), not another vector. It combines information about both the magnitudes of the vectors and the angle between them. The dot product is enormously useful because it gives us a simple algebraic way to find the angle between two lines or vectors in 3D — something that would be geometrically very hard to see otherwise. Two vectors are perpendicular if and only if their dot product is zero. The dot product is commutative: \(\mathbf{a} \cdot \mathbf{b} = \mathbf{b} \cdot \mathbf{a}\). When working with lines, we use the direction vectors of the lines to find the angle between them, and we always report the acute angle (between \(0°\) and \(90°\)).

Formula / Rule

Component form (for computation):

$$\mathbf{a} \cdot \mathbf{b} = a_1 b_1 + a_2 b_2 + a_3 b_3$$

Geometric form (links to angle):

$$\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}|\,|\mathbf{b}|\cos\theta$$

Formula for the angle \(\theta\) between two vectors:

$$\cos\theta = \frac{\mathbf{a} \cdot \mathbf{b}}{|\mathbf{a}|\,|\mathbf{b}|}$$

Perpendicularity test:   \(\mathbf{a} \perp \mathbf{b} \iff \mathbf{a} \cdot \mathbf{b} = 0\)

Angle between two lines: Use the direction vectors \(\mathbf{d}_1\) and \(\mathbf{d}_2\). If \(\cos\theta < 0\), take \(|\cos\theta|\) to get the acute angle:

$$\cos\theta = \frac{|\mathbf{d}_1 \cdot \mathbf{d}_2|}{|\mathbf{d}_1|\,|\mathbf{d}_2|}$$

Where to Apply It

Use whenever you need to: find the angle between two vectors or two lines; test whether two vectors or lines are perpendicular; test whether a direction is parallel to a plane; or verify that a triangle has a right angle. In exam questions the phrase "find the acute angle between…" is the direct trigger for this skill.

Worked Examples
Example 1 — Angle between two vectors

Find the angle between \(\mathbf{a} = \begin{pmatrix}2\\-1\\3\end{pmatrix}\) and \(\mathbf{b} = \begin{pmatrix}1\\4\\-2\end{pmatrix}\).

Step 1 — Compute the dot product

$$\mathbf{a} \cdot \mathbf{b} = (2)(1) + (-1)(4) + (3)(-2) = 2 - 4 - 6 = -8$$

Step 2 — Compute the magnitudes

$$|\mathbf{a}| = \sqrt{2^2 + (-1)^2 + 3^2} = \sqrt{4 + 1 + 9} = \sqrt{14}$$

$$|\mathbf{b}| = \sqrt{1^2 + 4^2 + (-2)^2} = \sqrt{1 + 16 + 4} = \sqrt{21}$$

Step 3 — Apply the formula

$$\cos\theta = \frac{-8}{\sqrt{14}\cdot\sqrt{21}} = \frac{-8}{\sqrt{294}}$$

$$\sqrt{294} = \sqrt{49 \times 6} = 7\sqrt{6}$$

$$\cos\theta = \frac{-8}{7\sqrt{6}}$$

Step 4 — Find \(\theta\)

$$\theta = \cos^{-1}\!\left(\frac{-8}{7\sqrt{6}}\right) \approx \cos^{-1}(-0.4661) \approx 117.7°$$

If this were the angle between two lines, we would take the acute angle: \(180° - 117.7° \approx \boxed{62.3°}\).
Example 2 — Angle between two lines

Find the acute angle between the lines

$$L_1:\; \mathbf{r} = \begin{pmatrix}1\\0\\2\end{pmatrix}+\lambda\begin{pmatrix}2\\1\\-1\end{pmatrix} \quad \text{and} \quad L_2:\; \mathbf{r} = \begin{pmatrix}3\\1\\0\end{pmatrix}+\mu\begin{pmatrix}0\\1\\2\end{pmatrix}$$

Step 1 — Extract direction vectors

\(\mathbf{d}_1 = \begin{pmatrix}2\\1\\-1\end{pmatrix}\), \quad \mathbf{d}_2 = \begin{pmatrix}0\\1\\2\end{pmatrix}\).

Step 2 — Dot product

$$\mathbf{d}_1 \cdot \mathbf{d}_2 = (2)(0)+(1)(1)+(-1)(2) = 0+1-2 = -1$$

Step 3 — Magnitudes

$$|\mathbf{d}_1| = \sqrt{4+1+1} = \sqrt{6}, \quad |\mathbf{d}_2| = \sqrt{0+1+4} = \sqrt{5}$$

Step 4 — Acute angle (use absolute value)

$$\cos\theta = \frac{|\mathbf{d}_1 \cdot \mathbf{d}_2|}{|\mathbf{d}_1||\mathbf{d}_2|} = \frac{|-1|}{\sqrt{6}\cdot\sqrt{5}} = \frac{1}{\sqrt{30}}$$

$$\theta = \cos^{-1}\!\left(\frac{1}{\sqrt{30}}\right) \approx \cos^{-1}(0.1826) \approx \boxed{79.5°}$$

Practice Questions
  1. Find \(\mathbf{a} \cdot \mathbf{b}\) where \(\mathbf{a} = \begin{pmatrix}3\\-2\\1\end{pmatrix}\) and \(\mathbf{b} = \begin{pmatrix}-1\\4\\5\end{pmatrix}\).\
  2. Show that \(\mathbf{p} = \begin{pmatrix}2\\-3\\1\end{pmatrix}\) and \(\mathbf{q} = \begin{pmatrix}3\\1\\-3\end{pmatrix}\) are perpendicular.
  3. Find the angle between \(\mathbf{u} = \begin{pmatrix}1\\2\\2\end{pmatrix}\) and \(\mathbf{v} = \begin{pmatrix}0\\1\\0\end{pmatrix}\), giving your answer in degrees to 1 d.p.
  4. Find the acute angle between the lines \(\mathbf{r} = \mathbf{i} + 2\mathbf{j} + \mu(3\mathbf{i} - \mathbf{j} + 2\mathbf{k})\) and \(\mathbf{r} = \mathbf{k} + \lambda(\mathbf{i} + \mathbf{j} - \mathbf{k})\).
  5. Given \(|\mathbf{a}| = 4\), \(|\mathbf{b}| = 5\) and the angle between them is \(60°\), find \(\mathbf{a} \cdot \mathbf{b}\).
  6. Find the value of \(k\) such that \(\begin{pmatrix}k\\2\\-1\end{pmatrix}\) is perpendicular to \(\begin{pmatrix}3\\k\\4\end{pmatrix}\).
  7. The line \(L\) has equation \(\mathbf{r} = \begin{pmatrix}1\\-1\\2\end{pmatrix} + t\begin{pmatrix}2\\1\\-2\end{pmatrix}\). Find the acute angle that \(L\) makes with the positive \(x\)-axis.
Fully Worked Solutions
Q1

$$\mathbf{a} \cdot \mathbf{b} = (3)(-1)+(-2)(4)+(1)(5) = -3-8+5 = \boxed{-6}$$

Q2 — Perpendicularity proof

$$\mathbf{p} \cdot \mathbf{q} = (2)(3)+(-3)(1)+(1)(-3) = 6-3-3 = 0$$

Since \(\mathbf{p} \cdot \mathbf{q} = \boxed{0}\), the vectors are perpendicular. \(\square\)

Q3 — Angle between u and v

\(\mathbf{u} \cdot \mathbf{v} = (1)(0)+(2)(1)+(2)(0) = 2\).

\(|\mathbf{u}| = \sqrt{1+4+4} = 3\), \(|\mathbf{v}| = \sqrt{0+1+0} = 1\).

$$\cos\theta = \frac{2}{3 \times 1} = \frac{2}{3}$$

$$\theta = \cos^{-1}\!\left(\tfrac{2}{3}\right) \approx \boxed{48.2°}$$

Q4 — Acute angle between two lines

Direction vectors: \(\mathbf{d}_1 = \begin{pmatrix}3\\-1\\2\end{pmatrix}\), \(\mathbf{d}_2 = \begin{pmatrix}1\\1\\-1\end{pmatrix}\).

\(\mathbf{d}_1 \cdot \mathbf{d}_2 = 3-1-2 = 0\).

Since the dot product is zero, the direction vectors are perpendicular.

Acute angle = \(\boxed{90°}\). The lines are perpendicular.

Q5 — Using the geometric formula

$$\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}||\mathbf{b}|\cos 60° = 4 \times 5 \times \frac{1}{2} = \boxed{10}$$

Q6 — Finding k for perpendicularity

$$\begin{pmatrix}k\\2\\-1\end{pmatrix} \cdot \begin{pmatrix}3\\k\\4\end{pmatrix} = 3k + 2k - 4 = 5k - 4 = 0$$

$$k = \boxed{\frac{4}{5}}$$

Q7 — Angle with positive x-axis

The positive \(x\)-axis has direction \(\mathbf{i} = \begin{pmatrix}1\\0\\0\end{pmatrix}\). The line's direction is \(\mathbf{d} = \begin{pmatrix}2\\1\\-2\end{pmatrix}\).

\(\mathbf{d} \cdot \mathbf{i} = 2\).

\(|\mathbf{d}| = \sqrt{4+1+4} = 3\), \(|\mathbf{i}| = 1\).

$$\cos\theta = \frac{|2|}{3 \times 1} = \frac{2}{3}$$

$$\theta = \cos^{-1}\!\left(\tfrac{2}{3}\right) \approx \boxed{48.2°}$$

Intersection and Skew Lines
What It Is

In 3D, two lines can behave in three fundamentally different ways: they can be parallel (same direction, never meeting), they can intersect (meet at exactly one point), or they can be skew (not parallel and not meeting — only possible in 3D). To test whether two lines intersect, you set their vector equations equal and solve the resulting system. This gives you two parameters. You use two component equations to solve for the parameters, then substitute into the third component equation to check consistency. If it is consistent, the lines intersect at that point. If inconsistent, the lines are skew (assuming they are not parallel).

Formula / Rule

Setup: Given \(L_1: \mathbf{r} = \mathbf{a} + \lambda\,\mathbf{d}_1\) and \(L_2: \mathbf{r} = \mathbf{b} + \mu\,\mathbf{d}_2\), set \(\mathbf{a} + \lambda\,\mathbf{d}_1 = \mathbf{b} + \mu\,\mathbf{d}_2\).

This produces three scalar equations (one per component) in two unknowns \(\lambda\) and \(\mu\).

Procedure:

  1. Write out the three component equations.
  2. Solve any two of them simultaneously to find \(\lambda\) and \(\mu\).
  3. Substitute both values into the third equation.
  4. If the third equation is satisfied: lines intersect. Find the point by substituting \(\lambda\) into \(L_1\).
  5. If not satisfied: lines are skew (provided they are not parallel).

Parallel check: If \(\mathbf{d}_1 = k\,\mathbf{d}_2\) for some scalar \(k\), the lines are parallel (or identical).

Where to Apply It

Use this whenever an exam question asks: "Do the lines intersect? If so, find the point of intersection" or "Show that the lines are skew." Always perform the parallel check first (it is quick). Only proceed to the full three-equation system if the lines are not parallel.

Worked Examples
Example 1 — Lines that intersect

Show that the lines \(L_1: \mathbf{r} = \begin{pmatrix}1\\2\\3\end{pmatrix}+\lambda\begin{pmatrix}2\\-1\\1\end{pmatrix}\) and \(L_2: \mathbf{r} = \begin{pmatrix}3\\0\\5\end{pmatrix}+\mu\begin{pmatrix}0\\1\\-1\end{pmatrix}\) intersect, and find the point of intersection.

Step 1 — Parallel check

\(\mathbf{d}_1 = \begin{pmatrix}2\\-1\\1\end{pmatrix}\), \(\mathbf{d}_2 = \begin{pmatrix}0\\1\\-1\end{pmatrix}\). These are not scalar multiples of each other, so the lines are not parallel.

Step 2 — Set equations equal and write component equations

$$\begin{pmatrix}1+2\lambda\\2-\lambda\\3+\lambda\end{pmatrix} = \begin{pmatrix}3\\0+\mu\\5-\mu\end{pmatrix}$$

(i) \(1 + 2\lambda = 3\)

(ii) \(2 - \lambda = \mu\)

(iii) \(3 + \lambda = 5 - \mu\)

Step 3 — Solve (i) and (ii)

From (i): \(2\lambda = 2 \Rightarrow \lambda = 1\).

From (ii): \(\mu = 2 - 1 = 1\).

Step 4 — Check in equation (iii)

LHS: \(3 + 1 = 4\). RHS: \(5 - 1 = 4\). \(\checkmark\) Consistent.

The lines intersect.

Step 5 — Find the intersection point

Substitute \(\lambda = 1\) into \(L_1\): \(\mathbf{r} = \begin{pmatrix}1+2\\2-1\\3+1\end{pmatrix} = \begin{pmatrix}3\\1\\4\end{pmatrix}\).

Point of intersection: \(\boxed{(3,\,1,\,4)}\).

Example 2 — Showing lines are skew

Show that \(L_1: \mathbf{r} = \begin{pmatrix}2\\0\\1\end{pmatrix}+\lambda\begin{pmatrix}1\\1\\2\end{pmatrix}\) and \(L_2: \mathbf{r} = \begin{pmatrix}4\\3\\0\end{pmatrix}+\mu\begin{pmatrix}2\\-1\\1\end{pmatrix}\) are skew.

Step 1 — Parallel check

\(\mathbf{d}_1 = \begin{pmatrix}1\\1\\2\end{pmatrix}\), \(\mathbf{d}_2 = \begin{pmatrix}2\\-1\\1\end{pmatrix}\). If parallel, \(d_{1}/d_{2} = k\) for all components: \(\frac{1}{2} \ne \frac{1}{-1}\). Not parallel.

Step 2 — Set up component equations

(i) \(2 + \lambda = 4 + 2\mu\)  →  \(\lambda - 2\mu = 2\)

(ii) \(0 + \lambda = 3 - \mu\)  →  \(\lambda + \mu = 3\)

(iii) \(1 + 2\lambda = 0 + \mu\)  →  \(2\lambda - \mu = -1\)

Step 3 — Solve (i) and (ii)

Subtract (i) from (ii): \((\lambda + \mu) - (\lambda - 2\mu) = 3 - 2 \Rightarrow 3\mu = 1 \Rightarrow \mu = \frac{1}{3}\).

\(\lambda = 3 - \frac{1}{3} = \frac{8}{3}\).

Step 4 — Check in equation (iii)

LHS: \(2\left(\frac{8}{3}\right) - \frac{1}{3} = \frac{16}{3} - \frac{1}{3} = \frac{15}{3} = 5\).

RHS: \(-1\).

\(5 \ne -1\). The equations are inconsistent.

Since the lines are not parallel and do not intersect, they are \(\boxed{\text{skew}}\).

Practice Questions
  1. Determine whether the lines \(L_1: \mathbf{r} = \begin{pmatrix}0\\1\\2\end{pmatrix}+\lambda\begin{pmatrix}1\\-1\\1\end{pmatrix}\) and \(L_2: \mathbf{r} = \begin{pmatrix}2\\3\\0\end{pmatrix}+\mu\begin{pmatrix}-1\\1\\-1\end{pmatrix}\) are parallel, intersecting, or skew.
  2. Find the point of intersection of \(L_1: \mathbf{r} = \begin{pmatrix}1\\-1\\0\end{pmatrix}+\lambda\begin{pmatrix}2\\1\\3\end{pmatrix}\) and \(L_2: \mathbf{r} = \begin{pmatrix}5\\3\\6\end{pmatrix}+\mu\begin{pmatrix}0\\1\\-1\end{pmatrix}\).
  3. Show that the lines \(\mathbf{r} = \begin{pmatrix}1\\2\\0\end{pmatrix}+\lambda\begin{pmatrix}1\\0\\1\end{pmatrix}\) and \(\mathbf{r} = \begin{pmatrix}2\\1\\3\end{pmatrix}+\mu\begin{pmatrix}0\\1\\2\end{pmatrix}\) are skew.
  4. Two lines: \(L_1\) passes through \((0,0,0)\) with direction \(\begin{pmatrix}1\\2\\1\end{pmatrix}\); \(L_2\) passes through \((3,0,1)\) with direction \(\begin{pmatrix}1\\-1\\0\end{pmatrix}\). Find the point of intersection, if it exists.
  5. Lines \(L_1\) and \(L_2\) have equations \(\frac{x-1}{2} = \frac{y+1}{1} = \frac{z}{3}\) and \(\frac{x-3}{0} = \frac{y-2}{1} = \frac{z-2}{-1}\) respectively. Do they intersect?
  6. Three points \(A(1,0,2)\), \(B(3,2,0)\), \(C(0,1,5)\) define two lines: \(L_1\) through \(A\) and \(B\); \(L_2\) through \(A\) and \(C\). Are these lines the same, parallel, or intersecting? Justify.
  7. Show that the following lines are skew: \(L_1: \mathbf{r} = (2\mathbf{i}+\mathbf{k})+\lambda(\mathbf{i}+2\mathbf{j}+\mathbf{k})\) and \(L_2: \mathbf{r} = (3\mathbf{i}+\mathbf{j})+\mu(2\mathbf{i}+\mathbf{j}+3\mathbf{k})\).
Fully Worked Solutions
Q1 — Parallel check first

\(\mathbf{d}_1 = \begin{pmatrix}1\\-1\\1\end{pmatrix}\), \(\mathbf{d}_2 = \begin{pmatrix}-1\\1\\-1\end{pmatrix} = -1 \cdot \begin{pmatrix}1\\-1\\1\end{pmatrix}\).

\(\mathbf{d}_2 = -\mathbf{d}_1\), so the directions are antiparallel (i.e., parallel).

Check if they are the same line: Does \(A(0,1,2)\) lie on \(L_2\)? Set \((0,1,2) = (2-\mu, 3+\mu, -\mu)\): \(-\mu=2 \Rightarrow \mu=-2\); check \(3+\mu = 1 \Rightarrow \mu=-2\,\checkmark\); check \(-\mu=2\,\checkmark\). The point lies on \(L_2\), so the lines are \(\boxed{\text{identical (the same line)}}\).

Q2 — Intersection point

Component equations: (i) \(1+2\lambda = 5\), (ii) \(-1+\lambda = 3+\mu\), (iii) \(3\lambda = 6-\mu\).

From (i): \(\lambda = 2\). From (ii): \(\mu = -1+2-3 = -2\). Check (iii): \(6 = 6-(-2) = 8\). \(6 \ne 8\)...

Re-examine: From (i): \(1+2\lambda=5 \Rightarrow \lambda=2\). From (ii): \(-1+\lambda = 3+\mu \Rightarrow 1 = 3+\mu \Rightarrow \mu=-2\). Check (iii): LHS \(= 0+3\lambda = 6\). RHS \(= 6+\mu = 6-2=4\). \(6\ne4\).

The lines do not satisfy all three equations simultaneously. Check using (i) and (iii): from (i) \(\lambda=2\); from (iii) \(3(2)=6-\mu \Rightarrow \mu=0\). Check (ii): \(-1+2=1\) vs \(3+0=3\). \(1\ne3\).

The lines are \(\boxed{\text{skew}}\). (The problem as stated has skew lines — verify by all three pairs of equations being inconsistent.)

Q3 — Skew lines proof

Direction vectors \(\begin{pmatrix}1\\0\\1\end{pmatrix}\) and \(\begin{pmatrix}0\\1\\2\end{pmatrix}\) are not parallel (no scalar \(k\) satisfies all components).

Component equations: (i) \(1+\lambda = 2\), (ii) \(2 = 1+\mu\), (iii) \(\lambda = 3+2\mu\).

From (i): \(\lambda=1\). From (ii): \(\mu=1\). Check (iii): \(1 = 3+2 = 5\). \(1 \ne 5\). Inconsistent.

\(\therefore\) The lines are \(\boxed{\text{skew}}\). \(\square\)

Q4 — Intersection test

\(L_1: \mathbf{r} = \lambda\begin{pmatrix}1\\2\\1\end{pmatrix}\), \(L_2: \mathbf{r}=\begin{pmatrix}3\\0\\1\end{pmatrix}+\mu\begin{pmatrix}1\\-1\\0\end{pmatrix}\).

(i) \(\lambda = 3+\mu\); (ii) \(2\lambda = -\mu\); (iii) \(\lambda = 1\).

From (iii): \(\lambda=1\). From (ii): \(\mu = -2\). Check (i): \(1 = 3+(-2) = 1\,\checkmark\).

Intersection at \(\lambda=1\): \(\mathbf{r} = \begin{pmatrix}1\\2\\1\end{pmatrix}\). Point: \(\boxed{(1,2,1)}\).

Q5 — Cartesian to vector form then test

\(L_1\): \(\mathbf{r} = \begin{pmatrix}1\\-1\\0\end{pmatrix}+\lambda\begin{pmatrix}2\\1\\3\end{pmatrix}\). \(L_2\): direction \(\begin{pmatrix}0\\1\\-1\end{pmatrix}\), through \((3,2,2)\), so \(\mathbf{r}=\begin{pmatrix}3\\2\\2\end{pmatrix}+\mu\begin{pmatrix}0\\1\\-1\end{pmatrix}\).

(i) \(1+2\lambda=3\Rightarrow\lambda=1\). (ii) \(-1+\lambda=2+\mu\Rightarrow\mu=-2\). (iii) \(3\lambda=2-\mu \Rightarrow 3 = 2+2=4\). \(3\ne4\). Lines are \(\boxed{\text{skew}}\).

Q6 — Lines through A,B and A,C

Both lines share point \(A(1,0,2)\). Since they both pass through the same point, they intersect at \(A\).

Check if parallel: \(\overrightarrow{AB} = \begin{pmatrix}2\\2\\-2\end{pmatrix}\), \(\overrightarrow{AC}=\begin{pmatrix}-1\\1\\3\end{pmatrix}\). Not scalar multiples. They are distinct lines meeting at \(\boxed{A(1,0,2)}\).

Q7 — Skew proof

Direction vectors: \(\mathbf{d}_1=\begin{pmatrix}1\\2\\1\end{pmatrix}\), \(\mathbf{d}_2=\begin{pmatrix}2\\1\\3\end{pmatrix}\). Not parallel.

Component equations: (i) \(2+\lambda=3+2\mu\Rightarrow\lambda-2\mu=1\); (ii) \(2\lambda=1+\mu\); (iii) \(1+\lambda=3\mu\).

From (i): \(\lambda=1+2\mu\). Substitute into (ii): \(2+4\mu=1+\mu\Rightarrow 3\mu=-1\Rightarrow\mu=-\frac{1}{3}\), \(\lambda=1-\frac{2}{3}=\frac{1}{3}\).

Check (iii): LHS \(= 1+\frac{1}{3}=\frac{4}{3}\). RHS \(= 3(-\frac{1}{3})=-1\). \(\frac{4}{3}\ne-1\).

\(\therefore\) Lines are \(\boxed{\text{skew}}\). \(\square\)

Separation of Variables (Solving Differential Equations)
What It Is

A differential equation (DE) is an equation that contains a derivative, such as \(\frac{dy}{dx}\). Many real-world processes — population growth, radioactive decay, cooling — are modelled by DEs. The technique of separation of variables solves a first-order DE by rearranging it so that all terms involving \(y\) (including \(dy\)) are on one side, and all terms involving \(x\) (including \(dx\)) are on the other. You then integrate both sides independently. The result is a general solution — a family of curves, each corresponding to a different value of the arbitrary constant \(C\). If you are given a specific point that the curve passes through (a boundary condition), you substitute it to find the particular solution.

Formula / Rule

General method for \(\dfrac{dy}{dx} = f(x)\,g(y)\):

$$\frac{1}{g(y)}\,dy = f(x)\,dx$$

Integrate both sides:

$$\int \frac{1}{g(y)}\,dy = \int f(x)\,dx$$

Add a single constant of integration \(C\) (on one side only).

Particular solution: Substitute the known point \((x_0, y_0)\) into the general solution to find \(C\).

Common model forms:

  • Growth: \(\dfrac{dy}{dt} = ky \;\Rightarrow\; y = Ae^{kt}\)
  • Decay: \(\dfrac{dy}{dt} = -ky \;\Rightarrow\; y = Ae^{-kt}\)
Where to Apply It

Use this whenever you see a first-order DE of the form \(\frac{dy}{dx} = f(x)\,g(y)\) — that is, when the right-hand side can be factored into a product of a pure function of \(x\) and a pure function of \(y\). Common triggers in exam questions: "solve the differential equation", "given that \(y = \ldots\) when \(x = \ldots\)", "find the particular solution", "show that \(y = \ldots\) satisfies…".

Worked Examples
Example 1 — General and particular solution

Solve the differential equation \(\dfrac{dy}{dx} = 3x^2 y\), given that \(y = 2\) when \(x = 0\).

Step 1 — Separate variables

Divide both sides by \(y\) (assuming \(y \ne 0\)) and multiply both sides by \(dx\):

$$\frac{1}{y}\,dy = 3x^2\,dx$$

Step 2 — Integrate both sides

$$\int \frac{1}{y}\,dy = \int 3x^2\,dx$$

$$\ln|y| = x^3 + C$$

Step 3 — Exponentiate to solve for \(y\)

$$|y| = e^{x^3 + C} = e^C \cdot e^{x^3}$$

Write \(A = \pm e^C\) (an arbitrary non-zero constant):

$$y = A e^{x^3}$$

This is the general solution.

Step 4 — Apply the boundary condition \(y(0) = 2\)

$$2 = A e^{0^3} = A \cdot 1 \Rightarrow A = 2$$

Step 5 — State the particular solution

$$\boxed{y = 2e^{x^3}}$$

Example 2 — More complex separation

Solve \(\dfrac{dy}{dx} = \dfrac{x^2}{y+1}\), given that \(y = 0\) when \(x = 3\).

Step 1 — Separate variables

Multiply both sides by \((y+1)\,dx\):

$$(y+1)\,dy = x^2\,dx$$

Step 2 — Integrate both sides

$$\int (y+1)\,dy = \int x^2\,dx$$

$$\frac{y^2}{2} + y = \frac{x^3}{3} + C$$

Step 3 — Apply the boundary condition \(y = 0, x = 3\)

$$\frac{0}{2} + 0 = \frac{27}{3} + C$$

$$0 = 9 + C \Rightarrow C = -9$$

Step 4 — Write the particular solution

$$\boxed{\frac{y^2}{2} + y = \frac{x^3}{3} - 9}$$

This is an implicit solution (it is acceptable to leave it in this form unless the question requires explicit \(y\)).

Practice Questions
  1. Solve \(\dfrac{dy}{dx} = 2xy\), given \(y = 5\) when \(x = 0\). Express \(y\) explicitly.
  2. Find the general solution of \(\dfrac{dy}{dx} = \dfrac{x}{y}\).
  3. Solve \(\dfrac{dy}{dx} = \dfrac{y^2}{x}\), given \(y = 1\) when \(x = 1\).
  4. Solve \(\dfrac{dy}{dx} = 4y\), given \(y = 3\) when \(x = 0\). State the value of \(y\) when \(x = \frac{1}{2}\).
  5. The rate of decay of a radioactive substance is given by \(\dfrac{dN}{dt} = -kN\), where \(N\) is the number of particles and \(k\) is a positive constant. Given \(N = N_0\) at \(t = 0\), show that \(N = N_0 e^{-kt}\).
  6. Solve the differential equation \(\dfrac{dy}{dx} = \dfrac{\sin x}{y^2}\), given \(y = 1\) when \(x = 0\).
  7. A population \(P\) grows according to \(\dfrac{dP}{dt} = 0.03P\). If \(P = 500\) when \(t = 0\), find \(P\) when \(t = 10\), giving your answer to the nearest whole number.
Fully Worked Solutions
Q1

Separate: \(\dfrac{1}{y}\,dy = 2x\,dx\). Integrate: \(\ln|y| = x^2 + C\). Exponentiate: \(y = Ae^{x^2}\).

Boundary condition \(y(0)=5\): \(5 = Ae^0 = A \Rightarrow A = 5\).

$$\boxed{y = 5e^{x^2}}$$

Q2

Separate: \(y\,dy = x\,dx\). Integrate: \(\dfrac{y^2}{2} = \dfrac{x^2}{2} + C\).

Multiply through by 2: \(y^2 = x^2 + A\) where \(A = 2C\) is an arbitrary constant.

$$\boxed{y^2 = x^2 + A}$$

Q3

Separate: \(\dfrac{1}{y^2}\,dy = \dfrac{1}{x}\,dx\), i.e., \(y^{-2}\,dy = \dfrac{1}{x}\,dx\).

Integrate: \(\dfrac{y^{-1}}{-1} = \ln|x| + C\), so \(-\dfrac{1}{y} = \ln x + C\).

Boundary condition \(y(1)=1\): \(-1 = \ln 1 + C = 0 + C \Rightarrow C = -1\).

\(-\dfrac{1}{y} = \ln x - 1\), so \(\dfrac{1}{y} = 1 - \ln x\).

$$\boxed{y = \frac{1}{1 - \ln x}}$$

Q4

Separate: \(\dfrac{1}{y}\,dy = 4\,dx\). Integrate: \(\ln|y| = 4x + C\). Exponentiate: \(y = Ae^{4x}\).

Boundary condition \(y(0)=3\): \(A = 3\). General: \(y = 3e^{4x}\).

At \(x = \dfrac{1}{2}\): \(y = 3e^{4 \times \frac{1}{2}} = 3e^2\).

$$\boxed{y = 3e^2 \approx 22.17}$$

Q5 — Radioactive decay proof

Separate: \(\dfrac{1}{N}\,dN = -k\,dt\).

Integrate: \(\ln|N| = -kt + C\). Exponentiate: \(N = Ae^{-kt}\).

Boundary condition \(N(0) = N_0\): \(N_0 = Ae^0 = A\).

$$\boxed{N = N_0 e^{-kt}} \quad \square$$

Q6

Separate: \(y^2\,dy = \sin x\,dx\). Integrate: \(\dfrac{y^3}{3} = -\cos x + C\).

Boundary condition \(y(0) = 1\): \(\dfrac{1}{3} = -\cos 0 + C = -1 + C \Rightarrow C = \dfrac{4}{3}\).

\(\dfrac{y^3}{3} = -\cos x + \dfrac{4}{3}\). Multiply by 3: \(y^3 = 3 - 3\cos x\).

$$\boxed{y = \sqrt[3]{3 - 3\cos x}}$$

Q7 — Population model

Separate: \(\dfrac{1}{P}\,dP = 0.03\,dt\). Integrate: \(\ln P = 0.03t + C\). Exponentiate: \(P = Ae^{0.03t}\).

Boundary condition \(P(0) = 500\): \(A = 500\). So \(P = 500e^{0.03t}\).

At \(t = 10\): \(P = 500e^{0.3} = 500 \times 1.34986\ldots \approx 675\).

$$\boxed{P \approx 675}$$
