Skill 11

Parametric Differentiation

What it is

Sometimes a curve is described not by a single equation \(y = f(x)\), but by two separate equations, each written in terms of a third variable called the parameter (usually \(t\)). For example, \(x = t^2\) and \(y = 2t\) together describe a parabola.

To find the gradient \(\dfrac{dy}{dx}\) of such a curve at any point, we do not need to eliminate \(t\) and write \(y\) explicitly in terms of \(x\). Instead, we use the chain rule in a clever form that lets us work directly with the parametric equations.

The key idea is: differentiate \(x\) with respect to \(t\), differentiate \(y\) with respect to \(t\), then divide. The \(dt\) parts cancel out, leaving \(\dfrac{dy}{dx}\).

Once you have a formula for the gradient in terms of \(t\), you substitute the value of \(t\) at any specific point to find the numerical gradient there.

The Rule

Chain Rule in Parametric Form:

$$\frac{dy}{dx} = \frac{\,\dfrac{dy}{dt}\,}{\,\dfrac{dx}{dt}\,}$$

This is valid provided \(\dfrac{dx}{dt} \neq 0\).

Gradient of the normal at a point with gradient \(m\) is \(-\dfrac{1}{m}\).

Stationary points occur where \(\dfrac{dy}{dt} = 0\) (provided \(\dfrac{dx}{dt} \neq 0\)).

Where to Apply It

Use parametric differentiation whenever a curve is defined by \(x = f(t)\) and \(y = g(t)\) and you need: the gradient at a given point, the equation of a tangent or normal, or the location of stationary points — without first converting to a Cartesian equation.

Worked Examples
Example 1 — Find the gradient at a given parameter value

A curve is defined by \(x = t^3 - 3t\) and \(y = t^2 + 1\). Find the gradient of the curve at the point where \(t = 2\).

Step 1 — Differentiate \(x\) with respect to \(t\)

$$\frac{dx}{dt} = 3t^2 - 3$$

Step 2 — Differentiate \(y\) with respect to \(t\)

$$\frac{dy}{dt} = 2t$$

Step 3 — Apply the parametric gradient formula

$$\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{2t}{3t^2 - 3}$$

Step 4 — Substitute \(t = 2\)

$$\frac{dy}{dx}\bigg|_{t=2} = \frac{2(2)}{3(2)^2 - 3} = \frac{4}{12 - 3} = \frac{4}{9}$$

$$\boxed{\dfrac{dy}{dx} = \dfrac{4}{9}}$$

Example 2 — Find the equation of the tangent

A curve is given by \(x = 4\cos\theta\) and \(y = 3\sin\theta\). Find the equation of the tangent to the curve at the point where \(\theta = \dfrac{\pi}{6}\).

Step 1 — Differentiate both parametric equations

$$\frac{dx}{d\theta} = -4\sin\theta, \qquad \frac{dy}{d\theta} = 3\cos\theta$$

Step 2 — Find the gradient formula

$$\frac{dy}{dx} = \frac{3\cos\theta}{-4\sin\theta} = -\frac{3}{4}\cot\theta$$

Step 3 — Evaluate at \(\theta = \pi/6\)

$$\cot\!\left(\frac{\pi}{6}\right) = \frac{\cos(\pi/6)}{\sin(\pi/6)} = \frac{\sqrt{3}/2}{1/2} = \sqrt{3}$$

$$m = -\frac{3}{4}\cdot\sqrt{3} = -\frac{3\sqrt{3}}{4}$$

Step 4 — Find the coordinates at \(\theta = \pi/6\)

$$x = 4\cos\!\left(\frac{\pi}{6}\right) = 4\cdot\frac{\sqrt{3}}{2} = 2\sqrt{3}$$

$$y = 3\sin\!\left(\frac{\pi}{6}\right) = 3\cdot\frac{1}{2} = \frac{3}{2}$$

Step 5 — Write the equation of the tangent using \(y - y_1 = m(x - x_1)\)

$$y - \frac{3}{2} = -\frac{3\sqrt{3}}{4}\!\left(x - 2\sqrt{3}\right)$$

Expand: \(y = -\dfrac{3\sqrt{3}}{4}x + \dfrac{3\sqrt{3}}{4}\cdot 2\sqrt{3} + \dfrac{3}{2} = -\dfrac{3\sqrt{3}}{4}x + \dfrac{9}{2} + \dfrac{3}{2}\)

$$\boxed{y = -\dfrac{3\sqrt{3}}{4}x + 6}$$

\(\dfrac{dx}{dt} = 2t,\quad \dfrac{dy}{dt} = 3t^2\)

Gradient formula

$$\frac{dy}{dx} = \frac{3t^2}{2t} = \frac{3t}{2}$$

At \(t=3\)

$$\frac{dy}{dx} = \frac{3(3)}{2} = \boxed{\dfrac{9}{2}}$$

Solution to Q2
Differentiate

\(\dfrac{dx}{dt} = 2,\quad \dfrac{dy}{dt} = 2t - 4\)

Gradient formula

$$\frac{dy}{dx} = \frac{2t-4}{2} = t - 2$$

At \(t=1\)

$$\frac{dy}{dx} = 1-2 = \boxed{-1}$$

Differentiate

\(\dfrac{dx}{dt} = e^t,\quad \dfrac{dy}{dt} = 2e^{2t}\)

Gradient in terms of \(t\)

$$\frac{dy}{dx} = \frac{2e^{2t}}{e^t} = 2e^t$$

Since \(x = e^t\), we have \(e^t = x\)

$$\boxed{\dfrac{dy}{dx} = 2x}$$

Solution to Q4
Differentiate (recall \(\cos 2\theta\) differentiates to \(-2\sin 2\theta\))

\(\dfrac{dx}{d\theta} = \cos\theta,\quad \dfrac{dy}{d\theta} = -2\sin 2\theta\)

Use double-angle: \(\sin 2\theta = 2\sin\theta\cos\theta\)

$$\frac{dy}{dx} = \frac{-2(2\sin\theta\cos\theta)}{\cos\theta} = -4\sin\theta$$

At \(\theta = \pi/3\)

$$\frac{dy}{dx} = -4\sin\!\left(\frac{\pi}{3}\right) = -4\cdot\frac{\sqrt{3}}{2} = \boxed{-2\sqrt{3}}$$

Solution to Q5
Differentiate

\(\dfrac{dx}{dt} = 2t,\quad \dfrac{dy}{dt} = 6t^2 - 3\)

Stationary points: set \(\dfrac{dy}{dt} = 0\)

$$6t^2 - 3 = 0 \implies t^2 = \frac{1}{2} \implies t = \pm\frac{1}{\sqrt{2}}$$

Check \(\dfrac{dx}{dt} \neq 0\): \(\dfrac{dx}{dt} = 2t\). At \(t = \pm\dfrac{1}{\sqrt{2}}\), \(\dfrac{dx}{dt} \neq 0\). ✓

$$\boxed{t = \dfrac{1}{\sqrt{2}} \text{ and } t = -\dfrac{1}{\sqrt{2}}}$$

Solution to Q6
Differentiate

\(\dfrac{dx}{dt} = 3,\quad \dfrac{dy}{dt} = -\dfrac{6}{t^2}\)

Gradient formula

$$\frac{dy}{dx} = \frac{-6/t^2}{3} = -\frac{2}{t^2}$$

At \(t=2\): gradient \(m = -\dfrac{2}{4} = -\dfrac{1}{2}\)
Coordinates at \(t=2\): \(x = 6,\; y = 3\)
Tangent equation

$$y - 3 = -\frac{1}{2}(x - 6) \implies y = -\frac{1}{2}x + 3 + 3$$

$$\boxed{y = -\dfrac{1}{2}x + 6}$$

Solution to Q7
Differentiate

\(\dfrac{dx}{d\theta} = -\sin\theta,\quad \dfrac{dy}{d\theta} = \cos\theta\)

Gradient of tangent

$$\frac{dy}{dx} = \frac{\cos\theta}{-\sin\theta} = -\cot\theta$$

At \(\theta = \pi/4\): \(-\cot(\pi/4) = -1\). So tangent gradient \(= -1\).
Normal gradient = negative reciprocal

$$\text{Normal gradient} = -\frac{1}{-1} = \boxed{1}$$

Skill 12

Rates of Change

What it is

A rate of change is a derivative — it tells you how fast one quantity is changing with respect to another. In many real-world problems, two or more quantities are both changing with time, and they are connected by a geometric or physical formula.

For example, if a balloon is being inflated, its radius \(r\) and its volume \(V\) both change with time \(t\). The volume formula \(V = \tfrac{4}{3}\pi r^3\) links the two quantities. If we know how fast the volume changes \(\bigl(\tfrac{dV}{dt}\bigr)\), we can find how fast the radius changes \(\bigl(\tfrac{dr}{dt}\bigr)\).

The method is to chain the derivatives together. If you know \(\tfrac{dV}{dt}\) and you can find \(\tfrac{dV}{dr}\), the chain rule lets you calculate \(\tfrac{dr}{dt}\) by dividing.

A decreasing quantity always has a negative rate of change. Always check signs match the physical context of the problem.

The Rule

Connected Rates of Change (Chain Rule):

$$\frac{dy}{dt} = \frac{dy}{dx}\cdot\frac{dx}{dt}$$

More generally, for any chain of related quantities:

$$\frac{dA}{dt} = \frac{dA}{dr}\cdot\frac{dr}{dt}$$

Inverse rate:

$$\frac{dr}{dt} = \frac{1}{\,\dfrac{dt}{dr}\,} \quad\Longrightarrow\quad \frac{dr}{dt} = \frac{\dfrac{dV}{dt}}{\dfrac{dV}{dr}}$$

Useful geometric formulas to memorise:

Circle: \(A = \pi r^2,\; C = 2\pi r\)

Sphere: \(V = \tfrac{4}{3}\pi r^3,\; S = 4\pi r^2\)

Where to Apply It

Use this technique whenever a question tells you the rate at which one quantity changes and asks for the rate at which a related quantity changes. Look for phrases like "the rate of increase of the radius", "the rate at which the area is growing", or "find \(\tfrac{dh}{dt}\) given \(\tfrac{dV}{dt}\)".

Worked Examples
Example 1 — Expanding sphere

A spherical balloon is being inflated so that its volume increases at a constant rate of \(50\text{ cm}^3\text{s}^{-1}\). Find the rate at which the radius is increasing when the radius is \(5\text{ cm}\).

Step 1 — Write down what is known and what is needed

\(\dfrac{dV}{dt} = 50\), need \(\dfrac{dr}{dt}\) when \(r = 5\).

Step 2 — Write the volume formula and differentiate with respect to \(r\)

$$V = \frac{4}{3}\pi r^3 \implies \frac{dV}{dr} = 4\pi r^2$$

Step 3 — Apply the chain rule

$$\frac{dr}{dt} = \frac{dV/dt}{dV/dr} = \frac{50}{4\pi r^2}$$

Step 4 — Substitute \(r = 5\)

$$\frac{dr}{dt} = \frac{50}{4\pi(25)} = \frac{50}{100\pi} = \frac{1}{2\pi}$$

$$\boxed{\frac{dr}{dt} = \frac{1}{2\pi} \approx 0.159 \text{ cm s}^{-1}}$$

Example 2 — Area of a circle

The radius of a circle is decreasing at a rate of \(0.4\text{ cm s}^{-1}\). Find the rate at which the area is decreasing when the radius is \(8\text{ cm}\).

Step 1 — State knowns: \(\dfrac{dr}{dt} = -0.4\) (negative because decreasing), need \(\dfrac{dA}{dt}\)
Step 2 — Differentiate the area formula

$$A = \pi r^2 \implies \frac{dA}{dr} = 2\pi r$$

Step 3 — Chain rule

$$\frac{dA}{dt} = \frac{dA}{dr}\cdot\frac{dr}{dt} = 2\pi r \cdot (-0.4) = -0.8\pi r$$

Step 4 — Substitute \(r = 8\)

$$\frac{dA}{dt} = -0.8\pi(8) = -6.4\pi$$

$$\boxed{\frac{dA}{dt} = -6.4\pi \approx -20.1 \text{ cm}^2\text{s}^{-1}}$$

The negative sign confirms the area is decreasing.

  4. Q4. The area of a circle is increasing at \(10\text{ cm}^2\text{s}^{-1}\). Find the rate at which the radius is increasing when the area is \(25\pi\text{ cm}^2\).
  5. Q5. Water is poured into a conical tank at \(5\text{ cm}^3\text{s}^{-1}\). The volume of water is \(V = \dfrac{1}{3}\pi r^2 h\). Given that \(r = 2h\) always, find \(\dfrac{dh}{dt}\) when \(h = 4\text{ cm}\).
  6. Q6. A variable \(y\) is related to \(x\) by \(y = x^3 + 2x\). If \(x\) is increasing at \(3\text{ units s}^{-1}\), find the rate of change of \(y\) when \(x = 2\).
  7. Q7. A particle moves so that its displacement is \(s = t^3 - 6t^2 + 9t\). Find the rate of change of \(s\) with respect to \(t\) at \(t = 3\), and state whether \(s\) is increasing or decreasing at that moment.

Solution to Q1
Volume of cube

\(V = x^3 \implies \dfrac{dV}{dx} = 3x^2\)

Chain rule

\(\dfrac{dx}{dt} = \dfrac{dV/dt}{dV/dx} = \dfrac{12}{3x^2}\)

At \(x=3\)

$$\frac{dx}{dt} = \frac{12}{27} = \boxed{\frac{4}{9} \approx 0.444 \text{ cm s}^{-1}}$$

Solution to Q2
Circumference \(C = 2\pi r\)

\(\dfrac{dC}{dr} = 2\pi\)

Chain rule

\(\dfrac{dC}{dt} = 2\pi \cdot \dfrac{dr}{dt} = 2\pi \cdot 2 = \boxed{4\pi \approx 12.6 \text{ cm s}^{-1}}\)

Solution to Q3
Known: \(\dfrac{dS}{dt} = -2\)
Differentiate \(S = 4\pi r^2\)

\(\dfrac{dS}{dr} = 8\pi r\)

Chain rule

\(\dfrac{dr}{dt} = \dfrac{dS/dt}{dS/dr} = \dfrac{-2}{8\pi r}\)

At \(r = 1.5\)

$$\frac{dr}{dt} = \frac{-2}{12\pi} = \boxed{-\frac{1}{6\pi} \approx -0.053 \text{ mm s}^{-1}}$$

Solution to Q4
When \(A = 25\pi\): \(\pi r^2 = 25\pi \implies r = 5\)
\(\dfrac{dA}{dr} = 2\pi r = 10\pi\)
Chain rule

\(\dfrac{dr}{dt} = \dfrac{10}{10\pi} = \boxed{\dfrac{1}{\pi} \approx 0.318 \text{ cm s}^{-1}}\)

Substitute \(r = 2h\) into volume formula

\(V = \tfrac{1}{3}\pi(2h)^2 h = \tfrac{4}{3}\pi h^3\)

\(\dfrac{dV}{dh} = 4\pi h^2\)

\(\dfrac{dh}{dt} = \dfrac{5}{4\pi h^2}\)

At \(h=4\)

$$\frac{dh}{dt} = \frac{5}{64\pi} = \boxed{\frac{5}{64\pi} \approx 0.0249 \text{ cm s}^{-1}}$$

Differentiate \(y\) with respect to \(x\)

\(\dfrac{dy}{dx} = 3x^2 + 2\)

\(\dfrac{dy}{dt} = (3x^2+2)\cdot 3\)

Skill 13

Reverse Power Rule (Integrating \(x^n\))

What it is

Integration is the reverse of differentiation. The reverse power rule tells you how to integrate any power of \(x\). When you differentiate \(x^n\), you multiply by the power and reduce it by one. To reverse that process, you increase the power by one and divide by the new power.

This works for any value of \(n\) — positive, negative, or fractional — except \(n = -1\) (which would require dividing by zero). The case \(n = -1\) is handled separately using the natural logarithm (Skill 15).

Because differentiation destroys any constant (the derivative of a constant is zero), every indefinite integral must include an arbitrary constant \(+ C\). Without it, your answer is incomplete.

For definite integrals (with limits), you evaluate the antiderivative at the upper limit and subtract its value at the lower limit. The \(C\) always cancels in this case.

The Rule

Reverse Power Rule:

$$\int x^n \, dx = \frac{x^{n+1}}{n+1} + C \qquad (n \neq -1)$$

Linear argument (very common extension):

$$\int (ax + b)^n \, dx = \frac{(ax+b)^{n+1}}{a(n+1)} + C$$

Divide by the coefficient of \(x\) inside the bracket — this is the "reverse chain rule" adjustment.

Definite integral:

$$\int_a^b f(x)\,dx = \Bigl[F(x)\Bigr]_a^b = F(b) - F(a)$$
Where to Apply It

Apply the reverse power rule to integrate any term of the form \(kx^n\), including negative powers like \(x^{-3}\) and fractional powers like \(x^{1/2}\). For expressions like \(\dfrac{3}{x^2}\), rewrite as \(3x^{-2}\) first, then integrate. Always rewrite roots as fractional powers before integrating.

Worked Examples
Example 1 — Indefinite integral with multiple terms

Find \(\displaystyle\int \left(4x^3 - \frac{2}{x^2} + \sqrt{x}\right) dx\).

Step 1 — Rewrite using index notation

$$\int \left(4x^3 - 2x^{-2} + x^{1/2}\right) dx$$

Step 2 — Integrate each term using \(\frac{x^{n+1}}{n+1}\)

Term 1: \(\displaystyle\int 4x^3\,dx = \frac{4x^4}{4} = x^4\)

Term 2: \(\displaystyle\int -2x^{-2}\,dx = \frac{-2x^{-1}}{-1} = 2x^{-1} = \frac{2}{x}\)

Term 3: \(\displaystyle\int x^{1/2}\,dx = \frac{x^{3/2}}{3/2} = \frac{2}{3}x^{3/2}\)

Step 3 — Combine with \(+C\)

$$\boxed{x^4 + \frac{2}{x} + \frac{2}{3}x^{3/2} + C}$$

Example 2 — Definite integral

Evaluate \(\displaystyle\int_1^4 \left(3x^2 - \frac{1}{2\sqrt{x}}\right) dx\).

Step 1 — Rewrite

$$\int_1^4 \left(3x^2 - \frac{1}{2}x^{-1/2}\right) dx$$

Step 2 — Integrate each term

$$\left[x^3 - \frac{1}{2}\cdot\frac{x^{1/2}}{1/2}\right]_1^4 = \left[x^3 - x^{1/2}\right]_1^4$$

Step 3 — Evaluate at upper limit \(x=4\)

$$4^3 - 4^{1/2} = 64 - 2 = 62$$

Step 4 — Evaluate at lower limit \(x=1\)

$$1^3 - 1^{1/2} = 1 - 1 = 0$$

Step 5 — Subtract

$$62 - 0 = \boxed{62}$$

\(2\cdot\dfrac{x^{3/2}}{3/2} - 4\cdot\dfrac{x^{1/2}}{1/2} = \dfrac{4}{3}x^{3/2} - 8x^{1/2}\)

Skill 14

Integrating \(e^x\) and \(e^{ax}\)

What it is

The exponential function \(e^x\) is unique in mathematics: it is its own derivative. This means \(\dfrac{d}{dx}(e^x) = e^x\). Because integration is the reverse of differentiation, integrating \(e^x\) gives back \(e^x\) (plus the constant \(C\)).

When the exponent contains a linear function — for example \(e^{3x}\) or \(e^{-2x+1}\) — differentiation introduces an extra factor (the coefficient of \(x\)) by the chain rule. To reverse this, we must divide by that coefficient when integrating.

This is the same compensating adjustment used in the reverse power rule for linear arguments. Think of it as "undoing" what the chain rule would have added during differentiation.

Always check your answer by differentiating it — you should recover the original integrand.

The Rules

Basic exponential:

$$\int e^x\,dx = e^x + C$$

Linear exponent:

$$\int e^{ax+b}\,dx = \frac{1}{a}e^{ax+b} + C \qquad (a \neq 0)$$

Scaled version:

$$\int k\,e^{ax+b}\,dx = \frac{k}{a}e^{ax+b} + C$$

The key: divide by the coefficient of \(x\) in the exponent.

Where to Apply It

Use these results whenever the integrand is an exponential function with a linear exponent. If the exponent is not linear (e.g., \(e^{x^2}\)), these rules do not apply directly — you would need a substitution. For all Edexcel P3/P4 questions, the exponent will be linear.

Worked Examples
Example 1 — Indefinite integral

Find \(\displaystyle\int \left(3e^{4x} - 2e^{-x} + e^{2x+1}\right) dx\).

Step 1 — Integrate term 1: \(3e^{4x}\)

Exponent is \(4x\), coefficient of \(x\) is \(4\). Divide by \(4\):

$$\int 3e^{4x}\,dx = \frac{3}{4}e^{4x}$$

Step 2 — Integrate term 2: \(-2e^{-x}\)

Exponent is \(-x\), coefficient is \(-1\). Divide by \(-1\):

$$\int -2e^{-x}\,dx = \frac{-2}{-1}e^{-x} = 2e^{-x}$$

Step 3 — Integrate term 3: \(e^{2x+1}\)

Exponent is \(2x+1\), coefficient of \(x\) is \(2\). Divide by \(2\):

$$\int e^{2x+1}\,dx = \frac{1}{2}e^{2x+1}$$

Step 4 — Combine

$$\boxed{\frac{3}{4}e^{4x} + 2e^{-x} + \frac{1}{2}e^{2x+1} + C}$$

Verification (differentiate term 1)

\(\dfrac{d}{dx}\!\left(\dfrac{3}{4}e^{4x}\right) = \dfrac{3}{4}\cdot 4\cdot e^{4x} = 3e^{4x}\) ✓

Example 2 — Definite integral

Evaluate \(\displaystyle\int_0^1 (4e^{2x} - e^{-x})\,dx\).

Step 1 — Find the antiderivative

$$\int(4e^{2x} - e^{-x})\,dx = \frac{4}{2}e^{2x} - \frac{1}{-1}e^{-x} = 2e^{2x} + e^{-x}$$

Step 2 — Evaluate at upper limit \(x = 1\)

$$2e^{2} + e^{-1}$$

Step 3 — Evaluate at lower limit \(x = 0\)

$$2e^{0} + e^{0} = 2(1) + 1 = 3$$

Step 4 — Subtract

$$\left(2e^2 + e^{-1}\right) - 3$$

$$\boxed{2e^2 + e^{-1} - 3} \approx 14.75 + 0.368 - 3 \approx 12.12$$

Skill 15

Integrating \(\dfrac{1}{x}\) and \(\dfrac{1}{ax+b}\) — The Natural Logarithm

What it is

Recall that the reverse power rule breaks down when \(n = -1\): you cannot write \(\dfrac{x^0}{0}\) because division by zero is undefined. This is the one exception to the power rule, and it requires a completely different result.

Because \(\dfrac{d}{dx}(\ln|x|) = \dfrac{1}{x}\), the integral of \(\dfrac{1}{x}\) is the natural logarithm. Notice the absolute value bars: \(\ln|x|\) instead of \(\ln x\). This is necessary because \(\ln\) is only defined for positive inputs, yet \(\dfrac{1}{x}\) can be integrated over intervals that include negative values of \(x\). The modulus ensures the argument is always positive.

When integrating \(\dfrac{1}{ax+b}\), the chain rule adjustment applies: differentiation of \(\ln|ax+b|\) produces an extra factor of \(a\), so when integrating we divide by \(a\).

Definite integrals of this type produce exact logarithmic values — simplify using log laws where possible.

The Rules

Basic logarithmic integral:

$$\int \frac{1}{x}\,dx = \ln|x| + C$$

Linear denominator:

$$\int \frac{1}{ax+b}\,dx = \frac{1}{a}\ln|ax+b| + C \qquad (a \neq 0)$$

Scaled version:

$$\int \frac{k}{ax+b}\,dx = \frac{k}{a}\ln|ax+b| + C$$

Reverse chain rule (fraction form):

$$\int \frac{f'(x)}{f(x)}\,dx = \ln|f(x)| + C$$

Recognise this: if the numerator is (or is a multiple of) the derivative of the denominator, the integral is a logarithm.

Where to Apply It

Use this rule whenever the integrand is \(\dfrac{1}{x}\), \(\dfrac{k}{ax+b}\), or any fraction where the numerator is a constant multiple of the derivative of the denominator. If the denominator is quadratic or higher, first try partial fractions (a later skill) to reduce to linear denominators.

Worked Examples
Example 1 — Indefinite integral with mixed terms

Find \(\displaystyle\int \left(\frac{3}{x} + \frac{4}{2x-1} - \frac{1}{3x+5}\right) dx\).

Step 1 — Identify each term as a logarithmic integral

Each fraction has a linear denominator, so we use \(\dfrac{k}{ax+b} \to \dfrac{k}{a}\ln|ax+b|\).

Step 2 — Integrate term 1: \(\dfrac{3}{x}\)

Here \(a=1,\, k=3\): \(\displaystyle\int \dfrac{3}{x}\,dx = 3\ln|x|\)

Step 3 — Integrate term 2: \(\dfrac{4}{2x-1}\)

Here \(a=2,\, k=4\): \(\displaystyle\int \dfrac{4}{2x-1}\,dx = \dfrac{4}{2}\ln|2x-1| = 2\ln|2x-1|\)

Step 4 — Integrate term 3: \(-\dfrac{1}{3x+5}\)

Here \(a=3,\, k=-1\): \(\displaystyle\int \dfrac{-1}{3x+5}\,dx = -\dfrac{1}{3}\ln|3x+5|\)

Step 5 — Combine

$$\boxed{3\ln|x| + 2\ln|2x-1| - \frac{1}{3}\ln|3x+5| + C}$$

Example 2 — Definite integral and exact simplification

Evaluate \(\displaystyle\int_1^5 \frac{2}{3x+2}\,dx\), giving your answer as an exact logarithm.

Step 1 — Find the antiderivative: \(a=3,\, k=2\)

$$\int \frac{2}{3x+2}\,dx = \frac{2}{3}\ln|3x+2|$$

Step 2 — Evaluate at \(x=5\)

$$\frac{2}{3}\ln|15+2| = \frac{2}{3}\ln 17$$

Step 3 — Evaluate at \(x=1\)

$$\frac{2}{3}\ln|3+2| = \frac{2}{3}\ln 5$$

Step 4 — Subtract and simplify using log laws

$$\frac{2}{3}\ln 17 - \frac{2}{3}\ln 5 = \frac{2}{3}\left(\ln 17 - \ln 5\right) = \frac{2}{3}\ln\!\left(\frac{17}{5}\right)$$

$$\boxed{\frac{2}{3}\ln\!\left(\frac{17}{5}\right)}$$
