Skill 1

The Chain Rule

What It Is

The Chain Rule is used to differentiate composite functions — that is, a function inside another function, written as \(f(g(x))\). For example, \((3x+1)^5\) is a composite function because the inner function \(3x+1\) is raised to a power by the outer function. You cannot simply differentiate the bracket and leave it; you must account for the inner function too. The Chain Rule tells you to differentiate the outside function first (leaving the inside alone), then multiply by the derivative of the inside function. This "chain" of multiplication is where the rule gets its name.

The Rule

If \(y = f(u)\) where \(u = g(x)\), then:

$$\frac{dy}{dx} = \frac{dy}{du} \times \frac{du}{dx}$$

Equivalently, for a function of a function:

$$\frac{d}{dx}\bigl[f(g(x))\bigr] = f'(g(x)) \cdot g'(x)$$

Quick pattern: differentiate the outer function (keeping inner unchanged), then multiply by the derivative of the inner function.

When to Apply It
  • Any function raised to a power where the base is itself a function of \(x\), e.g. \((x^2+1)^6\)
  • Trigonometric functions with a non-trivial argument, e.g. \(\sin(3x^2)\)
  • Exponential or logarithmic functions of a function, e.g. \(e^{x^2}\) or \(\ln(5x+1)\)
  • Any time you see a function plugged inside another function — ask: "is there something more complex than just \(x\) inside?"
Worked Examples
Example 1 — Differentiate \(y = (3x^2 + 5)^4\)
Identify the structureOuter function: \((\,\cdot\,)^4\).   Inner function: \(u = 3x^2 + 5\).
Differentiate the outer\(\dfrac{dy}{du} = 4u^3\)  (power rule on the outer function, inner left unchanged).
Differentiate the inner\(\dfrac{du}{dx} = 6x\)
Apply Chain Rule\(\dfrac{dy}{dx} = 4u^3 \times 6x = 4(3x^2+5)^3 \times 6x\)
Simplify$$\boxed{\dfrac{dy}{dx} = 24x(3x^2+5)^3}$$
Example 2 — Differentiate \(y = \sin(5x^3 - 2x)\)
Identify the structureOuter function: \(\sin(\,\cdot\,)\).   Inner function: \(u = 5x^3 - 2x\).
Differentiate the outer\(\dfrac{dy}{du} = \cos(u)\)
Differentiate the inner\(\dfrac{du}{dx} = 15x^2 - 2\)
Apply Chain Rule\(\dfrac{dy}{dx} = \cos(u) \times (15x^2 - 2)\)
Substitute back$$\boxed{\dfrac{dy}{dx} = (15x^2 - 2)\cos(5x^3 - 2x)}$$

Q2 — \(y = (x^2+3x)^5\)
Inner\(u = x^2+3x\), so \(\dfrac{du}{dx} = 2x+3\)
Outer differentiated\(\dfrac{dy}{du} = 5u^4 = 5(x^2+3x)^4\)

Q3 — \(y = \sqrt{2x^3+1} = (2x^3+1)^{1/2}\)
Inner\(u = 2x^3+1\), so \(\dfrac{du}{dx} = 6x^2\)
Outer differentiated\(\dfrac{dy}{du} = \dfrac{1}{2}u^{-1/2} = \dfrac{1}{2}(2x^3+1)^{-1/2}\)

Write neatly$$\boxed{\dfrac{dy}{dx} = \dfrac{3x^2}{\sqrt{2x^3+1}}}$$
Q4 — \(y = \cos(4x+1)\)
Inner\(u = 4x+1\), so \(\dfrac{du}{dx} = 4\)

Q5 — \(y = \tan(x^2)\)
Inner\(u = x^2\), so \(\dfrac{du}{dx} = 2x\)
Outer differentiated\(\dfrac{dy}{du} = \sec^2(u)\)

Q6 — \(y = (x^3-2x+1)^{-3}\)
Inner\(u = x^3-2x+1\), so \(\dfrac{du}{dx} = 3x^2-2\)

Inner\(u = \sin x\), so \(\dfrac{du}{dx} = \cos x\)
Outer differentiated\(\dfrac{dy}{du} = 4u^3 = 4\sin^3 x\)

Skill 2

The Product Rule

What It Is

The Product Rule is used when you need to differentiate an expression that is the product (multiplication) of two separate functions of \(x\). A common mistake is to differentiate each part separately and multiply — this is wrong. For example, \(\dfrac{d}{dx}[u \cdot v] \ne \dfrac{du}{dx} \cdot \dfrac{dv}{dx}\). The correct method accounts for the fact that both parts are changing simultaneously. You label the two parts \(u\) and \(v\), differentiate each one, and then combine them using the formula below.

The Rule

If \(y = u \cdot v\), where \(u\) and \(v\) are both functions of \(x\), then:

$$\frac{dy}{dx} = u\frac{dv}{dx} + v\frac{du}{dx}$$

Memory aid: "first times derivative of second, plus second times derivative of first"

When to Apply It
  • Whenever the expression is a product of two distinct functions, e.g. \(x^2 \sin x\) or \(e^x \ln x\)
  • When neither factor can be simplified away or combined into one
  • Watch for hidden products — \(x\cos x\) is a product even though it looks simple
  • Often combined with the Chain Rule when one of \(u\) or \(v\) is itself composite
Worked Examples
Example 1 — Differentiate \(y = x^3 \sin x\)
Label the parts\(u = x^3\)    \(v = \sin x\)
Differentiate each\(\dfrac{du}{dx} = 3x^2\)    \(\dfrac{dv}{dx} = \cos x\)
Apply Product Rule\(\dfrac{dy}{dx} = u\dfrac{dv}{dx} + v\dfrac{du}{dx} = x^3 \cos x + \sin x \cdot 3x^2\)
Simplify (factorise)$$\boxed{\dfrac{dy}{dx} = x^2(x\cos x + 3\sin x)}$$
Example 2 — Differentiate \(y = (2x+1)^3 \ln x\)
Label the parts\(u = (2x+1)^3\)    \(v = \ln x\)
Differentiate \(u\) — Chain Rule needed\(\dfrac{du}{dx} = 3(2x+1)^2 \times 2 = 6(2x+1)^2\)
Differentiate \(v\)\(\dfrac{dv}{dx} = \dfrac{1}{x}\)
Apply Product Rule\(\dfrac{dy}{dx} = (2x+1)^3 \cdot \dfrac{1}{x} + \ln x \cdot 6(2x+1)^2\)
Factorise$$\boxed{\dfrac{dy}{dx} = (2x+1)^2\!\left[\frac{2x+1}{x} + 6\ln x\right]}$$
Practice Questions
  1. Differentiate \(y = x^4 \cos x\)
  2. Differentiate \(y = x^2 e^x\)
  3. Differentiate \(y = \sqrt{x}\, \ln x\)
  4. Differentiate \(y = (x^2+1)\sin x\)
  5. Differentiate \(y = x^3(3x-1)^4\)
  6. Differentiate \(y = e^x \cos x\)
  7. Differentiate \(y = x \ln x\)
Full Solutions
Q1 — \(y = x^4\cos x\)
Set up\(u=x^4,\; v=\cos x\)
Derivatives\(u'=4x^3,\; v'=-\sin x\)
Product Rule$$\boxed{\dfrac{dy}{dx} = -x^4\sin x + 4x^3\cos x = x^3(4\cos x - x\sin x)}$$
Q2 — \(y = x^2 e^x\)
Set up\(u=x^2,\; v=e^x\)
Derivatives\(u'=2x,\; v'=e^x\)
Product Rule$$\boxed{\dfrac{dy}{dx} = x^2 e^x + 2xe^x = xe^x(x+2)}$$
Q3 — \(y = \sqrt{x}\,\ln x = x^{1/2}\ln x\)
Set up\(u=x^{1/2},\; v=\ln x\)
Derivatives\(u'=\dfrac{1}{2}x^{-1/2},\; v'=\dfrac{1}{x}\)
Product Rule\(\dfrac{dy}{dx} = x^{1/2}\cdot\dfrac{1}{x} + \ln x\cdot\dfrac{1}{2}x^{-1/2} = x^{-1/2} + \dfrac{\ln x}{2\sqrt{x}}\)
Factorise$$\boxed{\dfrac{dy}{dx} = \dfrac{1}{\sqrt{x}}\!\left(1 + \dfrac{\ln x}{2}\right) = \dfrac{2 + \ln x}{2\sqrt{x}}}$$
Q4 — \(y = (x^2+1)\sin x\)
Set up\(u=x^2+1,\; v=\sin x\)
Derivatives\(u'=2x,\; v'=\cos x\)
Product Rule$$\boxed{\dfrac{dy}{dx} = (x^2+1)\cos x + 2x\sin x}$$
Q5 — \(y = x^3(3x-1)^4\)
Set up\(u=x^3,\; v=(3x-1)^4\)
Derivatives\(u'=3x^2\); for \(v\) use Chain Rule: \(v'=4(3x-1)^3\times 3 = 12(3x-1)^3\)
Product Rule\(\dfrac{dy}{dx} = x^3\cdot 12(3x-1)^3 + (3x-1)^4\cdot 3x^2\)
Factorise\(= 3x^2(3x-1)^3\bigl[4x + (3x-1)\bigr] = 3x^2(3x-1)^3(7x-1)\)
$$\boxed{\dfrac{dy}{dx} = 3x^2(7x-1)(3x-1)^3}$$
Q6 — \(y = e^x\cos x\)
Set up\(u=e^x,\; v=\cos x\)
Derivatives\(u'=e^x,\; v'=-\sin x\)
Product Rule$$\boxed{\dfrac{dy}{dx} = e^x\cos x - e^x\sin x = e^x(\cos x - \sin x)}$$
Q7 — \(y = x\ln x\)
Set up\(u=x,\; v=\ln x\)
Derivatives\(u'=1,\; v'=\dfrac{1}{x}\)
Product Rule\(\dfrac{dy}{dx} = x\cdot\dfrac{1}{x} + \ln x\cdot 1 = 1 + \ln x\)
$$\boxed{\dfrac{dy}{dx} = 1 + \ln x}$$
Skill 3

The Quotient Rule

What It Is

The Quotient Rule is used to differentiate a fraction where both the numerator and denominator are functions of \(x\). Just as you cannot differentiate a product by multiplying the separate derivatives, you cannot differentiate a fraction by dividing them. The Quotient Rule gives the correct formula. A critical warning: the order of terms in the numerator matters because of the minus sign — always write it as "denominator times derivative of numerator minus numerator times derivative of denominator", never the other way around.

The Rule

If \(y = \dfrac{u}{v}\), where \(u\) and \(v\) are both functions of \(x\), then:

$$\frac{dy}{dx} = \frac{v\dfrac{du}{dx} - u\dfrac{dv}{dx}}{v^2}$$

Memory aid: "vdu minus udv, all over v squared"

When to Apply It
  • Whenever \(y\) is written as a fraction \(\dfrac{f(x)}{g(x)}\) and both numerator and denominator depend on \(x\)
  • Examples: \(\dfrac{\sin x}{x^2}\), \(\dfrac{e^x}{x+1}\), \(\dfrac{\ln x}{\cos x}\)
  • Note: if the denominator is a constant, you do not need this rule — just differentiate normally
  • You can also re-write some quotients as negative powers and use the Product Rule instead — both methods give the same answer
Worked Examples
Example 1 — Differentiate \(y = \dfrac{x^2}{x+3}\)
Label the parts\(u = x^2\)    \(v = x+3\)
Differentiate each\(\dfrac{du}{dx} = 2x\)    \(\dfrac{dv}{dx} = 1\)
Apply Quotient Rule\(\dfrac{dy}{dx} = \dfrac{(x+3)(2x) - x^2(1)}{(x+3)^2}\)
Expand numerator\(= \dfrac{2x^2 + 6x - x^2}{(x+3)^2} = \dfrac{x^2 + 6x}{(x+3)^2}\)
Factorise numerator$$\boxed{\dfrac{dy}{dx} = \dfrac{x(x+6)}{(x+3)^2}}$$
Example 2 — Differentiate \(y = \dfrac{\cos x}{e^x}\)
Label the parts\(u = \cos x\)    \(v = e^x\)
Differentiate each\(\dfrac{du}{dx} = -\sin x\)    \(\dfrac{dv}{dx} = e^x\)
Apply Quotient Rule\(\dfrac{dy}{dx} = \dfrac{e^x(-\sin x) - \cos x\cdot e^x}{(e^x)^2}\)
Simplify denominator\((e^x)^2 = e^{2x}\)
Factor numerator\(= \dfrac{-e^x(\sin x + \cos x)}{e^{2x}} = \dfrac{-(\sin x + \cos x)}{e^x}\)
$$\boxed{\dfrac{dy}{dx} = -\dfrac{\sin x + \cos x}{e^x}}$$
Practice Questions
  1. Differentiate \(y = \dfrac{3x}{x^2-1}\)
  2. Differentiate \(y = \dfrac{\sin x}{x}\)
  3. Differentiate \(y = \dfrac{e^x}{x^3}\)
  4. Differentiate \(y = \dfrac{x^2+1}{2x-3}\)
  5. Differentiate \(y = \dfrac{\ln x}{x^2}\)
  6. Differentiate \(y = \dfrac{\tan x}{x}\)
  7. Differentiate \(y = \dfrac{x}{\sqrt{x^2+4}}\)   (Hint: write the square root as a power)
Full Solutions
Q1 — \(y = \dfrac{3x}{x^2-1}\)
Set up\(u=3x,\; v=x^2-1\); \(u'=3,\; v'=2x\)
Quotient Rule\(\dfrac{dy}{dx} = \dfrac{(x^2-1)(3) - 3x(2x)}{(x^2-1)^2} = \dfrac{3x^2-3-6x^2}{(x^2-1)^2} = \dfrac{-3x^2-3}{(x^2-1)^2}\)
$$\boxed{\dfrac{dy}{dx} = \dfrac{-3(x^2+1)}{(x^2-1)^2}}$$
Q2 — \(y = \dfrac{\sin x}{x}\)
Set up\(u=\sin x,\; v=x\); \(u'=\cos x,\; v'=1\)
Quotient Rule$$\boxed{\dfrac{dy}{dx} = \dfrac{x\cos x - \sin x}{x^2}}$$
Q3 — \(y = \dfrac{e^x}{x^3}\)
Set up\(u=e^x,\; v=x^3\); \(u'=e^x,\; v'=3x^2\)
Quotient Rule\(\dfrac{dy}{dx} = \dfrac{x^3 e^x - e^x\cdot 3x^2}{x^6} = \dfrac{e^x x^2(x-3)}{x^6}\)
$$\boxed{\dfrac{dy}{dx} = \dfrac{e^x(x-3)}{x^4}}$$
Q4 — \(y = \dfrac{x^2+1}{2x-3}\)
Set up\(u=x^2+1,\; v=2x-3\); \(u'=2x,\; v'=2\)
Quotient Rule\(\dfrac{dy}{dx} = \dfrac{(2x-3)(2x)-(x^2+1)(2)}{(2x-3)^2} = \dfrac{4x^2-6x-2x^2-2}{(2x-3)^2} = \dfrac{2x^2-6x-2}{(2x-3)^2}\)
$$\boxed{\dfrac{dy}{dx} = \dfrac{2(x^2-3x-1)}{(2x-3)^2}}$$
Q5 — \(y = \dfrac{\ln x}{x^2}\)
Set up\(u=\ln x,\; v=x^2\); \(u'=\dfrac{1}{x},\; v'=2x\)
Quotient Rule\(\dfrac{dy}{dx} = \dfrac{x^2\cdot\dfrac{1}{x} - \ln x\cdot 2x}{x^4} = \dfrac{x - 2x\ln x}{x^4} = \dfrac{x(1-2\ln x)}{x^4}\)
$$\boxed{\dfrac{dy}{dx} = \dfrac{1-2\ln x}{x^3}}$$
Q6 — \(y = \dfrac{\tan x}{x}\)
Set up\(u=\tan x,\; v=x\); \(u'=\sec^2 x,\; v'=1\)
Quotient Rule$$\boxed{\dfrac{dy}{dx} = \dfrac{x\sec^2 x - \tan x}{x^2}}$$
Q7 — \(y = \dfrac{x}{\sqrt{x^2+4}} = \dfrac{x}{(x^2+4)^{1/2}}\)
Set up\(u=x,\; v=(x^2+4)^{1/2}\); \(u'=1\)
Differentiate \(v\) — Chain Rule\(v' = \dfrac{1}{2}(x^2+4)^{-1/2}\cdot 2x = \dfrac{x}{(x^2+4)^{1/2}}\)
Quotient Rule\(\dfrac{dy}{dx} = \dfrac{(x^2+4)^{1/2}\cdot1 - x\cdot\dfrac{x}{(x^2+4)^{1/2}}}{x^2+4}\)
Multiply numerator and denominator by \((x^2+4)^{1/2}\)\(= \dfrac{(x^2+4) - x^2}{(x^2+4)^{3/2}} = \dfrac{4}{(x^2+4)^{3/2}}\)
$$\boxed{\dfrac{dy}{dx} = \dfrac{4}{(x^2+4)^{3/2}}}$$
Skill 4

Differentiating \(x^n\), Constants, and Polynomials

What It Is

This is the most fundamental differentiation skill — the Power Rule. It applies to any term of the form \(ax^n\), where \(a\) is a constant and \(n\) is any real number (positive integer, negative integer, or fraction). To differentiate, you bring the power down and multiply it by the coefficient, then reduce the power by one. A constant term (a number with no \(x\)) always differentiates to zero, because a horizontal line has no slope. A polynomial is simply a sum of power terms, so you differentiate it term by term.

The Rules
$$\frac{d}{dx}\bigl[ax^n\bigr] = nax^{n-1}$$
$$\frac{d}{dx}\bigl[c\bigr] = 0 \quad \text{(for any constant } c\text{)}$$
$$\frac{d}{dx}\bigl[f(x) + g(x)\bigr] = f'(x) + g'(x) \quad \text{(differentiate term by term)}$$
When to Apply It
  • Any term of the form \(ax^n\), regardless of whether \(n\) is positive, negative, or fractional
  • Before applying, rewrite roots and fractions as powers: \(\sqrt{x} = x^{1/2}\), \(\dfrac{1}{x^3} = x^{-3}\)
  • Polynomials: differentiate each term separately
  • Standalone constants always give zero when differentiated
Worked Examples
Example 1 — Differentiate \(y = 5x^4 - 3x^2 + 7x - 9\)
Differentiate \(5x^4\)Bring down the 4, multiply: \(4 \times 5 = 20\). Reduce power: \(20x^3\)
Differentiate \(-3x^2\)Bring down the 2: \(2\times(-3)=-6\). Reduce power: \(-6x\)
Differentiate \(7x\)\(7x = 7x^1\). Bring down the 1: \(1\times 7=7\). Reduce power: \(7x^0 = 7\)
Differentiate \(-9\)Constant → \(0\)
Combine$$\boxed{\dfrac{dy}{dx} = 20x^3 - 6x + 7}$$
Example 2 — Differentiate \(y = 3x^{-2} + 4\sqrt{x} - \dfrac{5}{x^3}\)
Rewrite all terms as powers\(y = 3x^{-2} + 4x^{1/2} - 5x^{-3}\)
Differentiate \(3x^{-2}\)\((-2)\times 3 = -6\). Power becomes \(-3\): gives \(-6x^{-3}\)
Differentiate \(4x^{1/2}\)\(\tfrac{1}{2}\times 4 = 2\). Power becomes \(-\tfrac{1}{2}\): gives \(2x^{-1/2}\)
Differentiate \(-5x^{-3}\)\((-3)\times(-5)=15\). Power becomes \(-4\): gives \(15x^{-4}\)
Write in tidy form$$\boxed{\dfrac{dy}{dx} = -\dfrac{6}{x^3} + \dfrac{2}{\sqrt{x}} + \dfrac{15}{x^4}}$$
Practice Questions
  1. Differentiate \(y = 7x^5 - 4x^3 + 2x - 11\)
  2. Differentiate \(y = 6x^{-3} + 5x^2 - 8\)
  3. Differentiate \(y = \sqrt[3]{x^4}\)   (write as a power first)
  4. Differentiate \(y = \dfrac{4}{x^2} - \dfrac{3}{x} + 9x\)
  5. Differentiate \(y = 2x^{3/2} - 6x^{1/3} + 4\)
  6. Differentiate \(y = (x+3)(x-2)\)   (expand first)
  7. Differentiate \(y = \dfrac{x^3 + 5x^2 - 2}{x}\)   (divide each term by \(x\) first)
Full Solutions
Q1 — \(y = 7x^5 - 4x^3 + 2x - 11\)
Term by term\(7x^5 \to 35x^4\); \(-4x^3\to -12x^2\); \(2x\to 2\); \(-11\to 0\)
$$\boxed{\dfrac{dy}{dx} = 35x^4 - 12x^2 + 2}$$
Q2 — \(y = 6x^{-3} + 5x^2 - 8\)
Term by term\(6x^{-3}\to -18x^{-4}\); \(5x^2\to 10x\); \(-8\to 0\)
$$\boxed{\dfrac{dy}{dx} = -\dfrac{18}{x^4} + 10x}$$
Q3 — \(y = \sqrt[3]{x^4} = x^{4/3}\)
Power rule\(\dfrac{4}{3}\times 1 = \dfrac{4}{3}\). Power becomes \(\dfrac{4}{3}-1 = \dfrac{1}{3}\)
$$\boxed{\dfrac{dy}{dx} = \dfrac{4}{3}x^{1/3} = \dfrac{4}{3}\sqrt[3]{x}}$$
Q4 — \(y = \dfrac{4}{x^2} - \dfrac{3}{x} + 9x = 4x^{-2} - 3x^{-1} + 9x\)
Term by term\(4x^{-2}\to -8x^{-3}\); \(-3x^{-1}\to 3x^{-2}\); \(9x\to 9\)
$$\boxed{\dfrac{dy}{dx} = -\dfrac{8}{x^3} + \dfrac{3}{x^2} + 9}$$
Q5 — \(y = 2x^{3/2} - 6x^{1/3} + 4\)
Term by term\(2x^{3/2}\to 3x^{1/2}\); \(-6x^{1/3}\to -2x^{-2/3}\); \(4\to 0\)
$$\boxed{\dfrac{dy}{dx} = 3\sqrt{x} - \dfrac{2}{x^{2/3}}}$$
Q6 — \(y = (x+3)(x-2)\)
Expand\(y = x^2 - 2x + 3x - 6 = x^2 + x - 6\)
Differentiate$$\boxed{\dfrac{dy}{dx} = 2x + 1}$$
Q7 — \(y = \dfrac{x^3 + 5x^2 - 2}{x}\)
Divide each term by \(x\)\(y = x^2 + 5x - 2x^{-1}\)
Differentiate\(x^2\to 2x\); \(5x\to 5\); \(-2x^{-1}\to 2x^{-2}\)
$$\boxed{\dfrac{dy}{dx} = 2x + 5 + \dfrac{2}{x^2}}$$
Skill 5

Differentiating \(e^x\) and \(e^{f(x)}\)

What It Is

The exponential function \(e^x\) has a remarkable and unique property: its derivative is itself. No other function has this property. This means differentiating \(e^x\) always gives back \(e^x\). When the exponent is more complex — a function of \(x\) rather than just \(x\) itself — you treat it as a composite function and apply the Chain Rule. The "outer" function is the exponential, and the "inner" function is the exponent. The rule is simply: copy the exponential down unchanged, then multiply by the derivative of the exponent.

The Rules
$$\frac{d}{dx}\bigl[e^x\bigr] = e^x$$
$$\frac{d}{dx}\bigl[e^{f(x)}\bigr] = f'(x)\cdot e^{f(x)}$$

Pattern: the exponential stays, multiply by the derivative of the exponent (Chain Rule).

For the special linear case \(e^{ax+b}\):

$$\frac{d}{dx}\bigl[e^{ax+b}\bigr] = a\,e^{ax+b}$$
When to Apply It
  • Any expression of the form \(e^{(\text{anything involving }x)}\)
  • If the exponent is just \(x\), the answer is simply \(e^x\) again
  • If the exponent is a linear function \(ax+b\), multiply by \(a\)
  • If the exponent is a more complex function (quadratic, trig, etc.), apply the Chain Rule: multiply by its derivative
  • The exponential \(e^{f(x)}\) itself never disappears — it always appears in the answer
Worked Examples
Example 1 — Differentiate \(y = e^{4x^3 - 2x}\)
Identify the structureThis is \(e^{f(x)}\) where the exponent \(f(x) = 4x^3 - 2x\)
Differentiate the exponent\(f'(x) = 12x^2 - 2\)
Apply the ruleCopy down the exponential unchanged, multiply by \(f'(x)\):
Final answer$$\boxed{\dfrac{dy}{dx} = (12x^2 - 2)\,e^{4x^3 - 2x}}$$
Example 2 — Differentiate \(y = 5e^{\sin x}\)
Identify the structureThis is \(5e^{f(x)}\) where the exponent \(f(x) = \sin x\)
Differentiate the exponent\(f'(x) = \cos x\)
Apply the ruleMultiply the constant \(5\) by the result:
Final answer$$\boxed{\dfrac{dy}{dx} = 5\cos x\, e^{\sin x}}$$

  1. Differentiate \(y = e^{7x}\)
  2. Differentiate \(y = e^{3x^2 + 1}\)
  3. Differentiate \(y = 4e^{-5x}\)
  4. Differentiate \(y = e^{x^3 - x}\)
  5. Differentiate \(y = e^{\cos x}\)
  6. Differentiate \(y = e^{\sqrt{x}} = e^{x^{1/2}}\)

Full Solutions
Q1 — \(y = e^{7x}\)
Exponent is \(7x\), its derivative is \(7\)
$$\boxed{\dfrac{dy}{dx} = 7e^{7x}}$$
Q2 — \(y = e^{3x^2+1}\)
Exponent \(f(x) = 3x^2+1\), so \(f'(x) = 6x\)
$$\boxed{\dfrac{dy}{dx} = 6x\,e^{3x^2+1}}$$
Q3 — \(y = 4e^{-5x}\)
Exponent \(f(x) = -5x\), so \(f'(x) = -5\)
Multiply constant \(4\) by \(-5\)\(4\times(-5)=-20\)
$$\boxed{\dfrac{dy}{dx} = -20e^{-5x}}$$
Q4 — \(y = e^{x^3-x}\)
Exponent \(f(x) = x^3-x\), so \(f'(x) = 3x^2-1\)
$$\boxed{\dfrac{dy}{dx} = (3x^2-1)\,e^{x^3-x}}$$
Q5 — \(y = e^{\cos x}\)
Exponent \(f(x) = \cos x\), so \(f'(x) = -\sin x\)

Q6 — \(y = e^{x^{1/2}}\)
Exponent \(f(x) = x^{1/2}\), so \(f'(x) = \dfrac{1}{2}x^{-1/2} = \dfrac{1}{2\sqrt{x}}\)
$$\boxed{\dfrac{dy}{dx} = \dfrac{1}{2\sqrt{x}}\,e^{\sqrt{x}}}$$
Q7 — \(y = x^2 e^{3x}\) (Product Rule)
Set up\(u = x^2,\; v = e^{3x}\)
Derivatives\(u' = 2x\); for \(v\): exponent is \(3x\), derivative is \(3\), so \(v' = 3e^{3x}\)
Product Rule\(\dfrac{dy}{dx} = x^2\cdot 3e^{3x} + e^{3x}\cdot 2x = 3x^2 e^{3x} + 2xe^{3x}\)
Factorise$$\boxed{\dfrac{dy}{dx} = xe^{3x}(3x+2)}$$
