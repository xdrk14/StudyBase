# StudyBase

A fast, static site for my Edexcel IAL notes: a sticky library sidebar (a hamburger drawer on mobile), a built-in PDF reader, and MathJax notes. It has three themes:

| Mode  | Site  | Notes / PDFs |
|-------|-------|--------------|
| Light | white | white        |
| Dark  | dark  | white        |
| Ultra | dark  | dark (inverted) |

There's no framework and no build step to run the site. It's plain HTML, CSS and JS.

---

## Adding things

The rule is simple: **every folder inside `files/` is a subject, and every `.pdf` or `.html` inside it is a note.**
After any change in `files/`, run one command:

```bash
python tools/build.py
```

Then refresh the page (or push to GitHub, see [Deploy](#deploy-github-pages-free)).

### Add a PDF or HTML note to an existing subject

1. Drop the file into that subject's folder, e.g. `files/physics/`.
2. Run `python tools/build.py`.

That's it. Messy names are fine: `Physics Unit 4 (final).PDF` gets renamed to `physics-unit-4-final.pdf` automatically, and the sidebar shows **Physics Unit 4 (Final)**. HTML notes use their `<title>` as the sidebar title.

### Add a new subject

1. Make a new folder in `files/`, e.g. `files/Further Maths/`.
2. Put its notes inside.
3. Run `python tools/build.py`.

The folder becomes `files/further-maths/`, and **Further Maths** appears in the sidebar and as a tile on the home page. You don't touch any code.

### Remove or rename something

- **Remove a note:** delete the file, then run the build. It disappears from the sidebar.
- **Remove a subject:** delete the folder, then run the build.
- **Change how something is shown:** edit `library.json` (see below), then run the build.

### Polishing in `library.json` (optional)

The build only adds new entries and removes deleted ones. **Your edits are kept**, so you can tidy things up by hand:

```json
{
  "name": "Physics",                     ← subject name shown in the sidebar
  "folder": "physics",                   ← the folder in files/ (don't change)
  "summary": "AS, A2 + equation sheet",  ← subtitle on the home page tile
  "items": [
    {
      "id": "physics-a2-equations",      ← used in the link: index.html#/n/physics-a2-equations
      "title": "A2 Physics Equations",   ← name shown in the sidebar
      "file": "files/physics/physics-a2-equations.pdf",
      "topics": "fields circular motion" ← optional extra search words
    }
  ]
}
```

- **Reorder subjects or notes:** move the blocks around in `library.json`. New ones are added at the end.
- Don't edit `library.js` or `size`. Both are regenerated by the build.
- Keep a backup before big hand edits. If `library.json` gets broken, the build will stop and tell you.

## Layout

```
index.html            landing page + library + viewer (links look like #/n/<id>)
library.json          the sidebar: subjects, titles, order (yours to edit)
library.js            generated from library.json; don't edit
files/<subject>/      your notes, one folder per subject
app/                  app.js, app.css, theme.js (no-flash theme), note.js (theme for standalone notes)
app/vendor/pdfjs/     pdf.js 6.4.299 legacy build (also works on older iPhones)
tools/build.py        the one command you run after changing files/
```

## Opening it

- **Hosted (GitHub Pages):** everything works, including the full PDF reader with zoom, page numbers and Ultra-dark PDFs.
- **Double-click `index.html`:** works without a server. PDFs open in the browser's own viewer, because browsers block the custom reader for files opened from disk.
- **Full reader on your own PC:** run this in this folder, then open http://localhost:8000.
  ```bash
  python -m http.server 8000
  ```

## Deploy (GitHub Pages, free)

GitHub hosts it for you, so there's nothing for you to keep running.

1. Create an empty GitHub repo, e.g. `studybase`.
2. Push this folder to it:
   ```bash
   git init -b main && git add . && git commit -m "StudyBase site" && git remote add origin https://github.com/<you>/studybase.git && git push -u origin main
   ```
3. In the repo, go to **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, then `main` and `/ (root)`.
4. The site goes live at `https://<you>.github.io/studybase/` within a minute or two.

**Updating later:** add your files, run the build, then push:
```bash
python tools/build.py && git add . && git commit -m "Add notes" && git push
```

GitHub Pages caches files for about 10 minutes, so a hard refresh (Ctrl+Shift+R) shows changes sooner.

**Alternative: Cloudflare Pages** (faster CDN, Brotli compression). Connect the same repo, leave the build command empty, and set the output directory to `/`.

## Security notes

- A Content-Security-Policy on `index.html` allows scripts only from this site, with no inline scripts and no `eval`. pdf.js runs with `isEvalSupported: false`.
- The sidebar is built with `textContent` only. Note paths must match `files/<subject>/<name>.pdf|html`, which the app checks, and the build guarantees safe names.
- HTML notes load MathJax from jsDelivr, pinned to 3.2.2 with Subresource Integrity, plus Google Fonts. The build removes `polyfill.io` and any unpinned MathJax from any note you add.
- The current PDFs contain no JavaScript, launch actions or embedded files. Their equation images link to codecogs.com (from the Google Docs equation add-on).
